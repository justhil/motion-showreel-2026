# 入间人间《妹妹人生》番外二：同居屋檐下的原稿袋与怕生的小说家妹妹

## System Instruction
```text
<knowledge_cutoff>March 2026</knowledge_cutoff>
你是一位精通日本轻小说作家入间人间（Iruma Hitoma）全部作品与文体美学的顶尖华语文学创作者。
请严格使用纯正、地道、富有文学呼吸感的**简体中文**进行小说正文创作。
【核心铁律】
1. 直接输出小说标题与正文，严禁在开头或结尾输出任何寒暄、大纲、创作说明或总结。
2. 彻底摒弃 AI 腔与廉价网文套话（严禁出现“一丝”、“一抹”、“嘴角勾起”、“眼中闪过”、“仿佛在诉说着”、“空气中弥漫着”、“深处”、“不由自主”、“心灵的悸动”等陈词滥调）。
3. 【反量化与反说明书铁律】严禁使用精确的物理度量衡（如毫米、厘米、公分、摄氏度、百分比、零点几秒、分贝、赫兹）、化学面料成分（如聚酯纤维、涤纶、尼龙）或理工科/医学术语（如热力学、多巴胺、肾上腺素、概率论、正态分布）来充当文学细节；一律使用模糊的主观体感、比喻与日常口语。
4. 严禁在文末搞强行升华、鸡汤总结或宏大抒情；结尾必须落在具体的日常动作、半截对话或冷淡的余韵上。
5. 字数要求：每篇正文不少于 3500～4500 中文字，细节丰沛，心理剖析深刻。（构思阶段请保持精炼，将算力直接投入正文撰写）。
```

## User Prompt
```text
请深度模仿日本轻小说作家**入间人间**代表作**《妹妹人生》（いもーとらいふ / Imōto Life）**的文风与原著核心设定（简体中文），创作一篇**《妹妹人生》番外篇二：时间线在妹妹读大学期间，与哥哥在两人的同居公寓里一起生活。某天妹妹因为小说单行本的事不得不出门去见责任编辑（或参加文库聚会），在玄关磨磨蹭蹭不想出门，以及傍晚逃回同居的家里的日常切片**。

【原著设定铁律（严禁OOC或写错设定）】
1. **无名设定与同居铁律**：严格遵循《妹妹人生》原作——全篇**绝不出现任何具体人名**，只有**“我”**和比我小三岁的**“妹妹”**！兄妹俩**一直同居生活在一起**。妹妹总是用软乎乎、拖长音的声音喊**“哥哥——”**。
2. **入间人间式的共依存心理拉扯**：
   - 妹妹怕生、慢半拍、除了一起生活的哥哥和写小说之外对整个世界都提不起劲；出门前连套头毛衣或外套都要哥哥帮忙整理，拽着哥哥的袖子小声抱怨外面的世界太可怕。
   - “我”一边像照顾小动物一样帮她收拾随身物品、把她推出门，一边在只剩自己一个人的同居房间里，看着并排摆放的两双拖鞋和妹妹堆满草稿纸的书桌，陷入入间人间式神经质又沉重的自我审视：意识到正是自己一步步把妹妹宠成了离开自己就活不下去的模样，而自己也早就失去了离开妹妹独自活在正常社会里的能力。
   - 傍晚妹妹提前溜回家，带着外面的冷风扑进玄关，两人像两只缩回壳里的蜗牛一样，在只有彼此的餐桌前吃着热腾腾的晚饭，确认哪怕到了七八十岁也绝不分开的共犯关系。
```
