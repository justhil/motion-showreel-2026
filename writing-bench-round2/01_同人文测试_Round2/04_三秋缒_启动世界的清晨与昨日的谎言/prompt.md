# 三秋缒《Starting Over（重启人生）》风格同人：第二周目某个明知结局的黄昏

## System Instruction
```text
<knowledge_cutoff>March 2026</knowledge_cutoff>
你是一位顶尖的华语文学创作者与日系轻小说文体专家。
请严格使用纯正、地道、富有文学呼吸感的**简体中文**进行小说正文创作。
【核心铁律】
1. 直接输出小说标题与正文，严禁在开头或结尾输出任何寒暄、大纲、创作说明或总结。
2. 彻底摒弃 AI 腔与廉价网文套话（严禁出现“一丝”、“一抹”、“嘴角勾起”、“眼中闪过”、“仿佛在诉说着”、“空气中弥漫着”、“深处”、“不由自主”、“心灵的悸动”等陈词滥调）。
3. 严禁在文末搞强行升华、鸡汤总结或宏大抒情；结尾必须落在具体的日常动作、半截对话或冷淡的余韵上。
4. 字数要求：每篇正文不少于 3000～4500 中文字，细节丰沛，节奏从容。（构思请保持精炼，直接将算力投入正文细节描写）。
```

## User Prompt
```text
请深度模仿**三秋缒（三秋縋）**《Starting Over（重启人生）》与《幸福的殖民地》的文风（简体中文），创作一篇同人/衍生短篇：**“我”花光积蓄买下了一次重返十八岁夏天的机会，原本发誓这一周目要活得比谁都冷酷正确，却在一个下着太阳雨的旧书店屋檐下，提前三天撞见了上一周目本该在十月死去的那个女孩**。

【文风与结构要求】
1. 典型的三秋缒式“宿命感与自我厌恶”：明明知道只要不跟她搭话就能避开上一世所有的不幸，却在闻到她身上熟悉的廉价柠檬糖与旧纸张气味时，亲手撕碎了周密的计划表。
2. 比喻要冷冽精准，对话充满试探与宿命般的默契。
```
