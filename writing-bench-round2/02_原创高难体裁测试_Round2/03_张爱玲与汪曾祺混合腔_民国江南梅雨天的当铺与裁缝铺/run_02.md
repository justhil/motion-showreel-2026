# 半寸肥瘦

民国二十六年五月尾，苏州城的黄梅天来得早。

悬桥巷里的青石板终日湿漉漉的，石缝里攒着隔年的黑泥与绿苔，踩上去脚底发腻。天色从早到晚都是死鱼肚皮似的一片白，不高不低地压在粉墙黛瓦上头。巷子中段那家“沈记成衣铺”卸了四块门板，里头黑洞洞的，只靠天井里漏下来的一点天光，照着一张油光水滑的楠木大裁床。

沈长生站在裁床后头，手里提着把铜嘴喷水壶，往铺平的一匹黑胶绸香云纱上喷水。他不用嘴吹，大拇指按住壶肚上的气孔，手腕子一抖，水雾便极均匀地落下来，在乌黑发亮的纱面上结成一层白茫茫的细珠子。旁边泥炉子里的白炭烧得通红，他垫着厚蓝布抓起那只鸡公头的生铁烙铁，往湿布上头一试，再落到香云纱上。

“刺啦——”

一股子白烟贴着裁床蹿起来，屋里顿时腾起香云纱特有的味儿，像是晒干的河塘泥混着陈年桑叶的焦香。这料子是东头顾家大小姐拿来做夏衫的，广东佛山来的正宗晒莨纱，娇贵得很，烙铁重一分就焦，轻一分又吃不住水，穿在身上洗两水就往横里懈。

巷子口远远地传过来叫卖声，先是卖花婆子拖长了调子的吴音：“栀子花——白兰花——”声音脆生生的，像浸在井水里的白瓷片。隔不多久，又是挑担子卖茶食的，木梆子敲得笃笃响，喊的是：“熏青豆咧——新出的牛皮糖——”

沈长生把烙铁放回铁架子上，摘下鼻梁上那副拿红头绳缠着腿儿的玳瑁花镜，捏起衣角揩了揩眼角。前两天，店里那个昆山乡下来的小学徒阿四被他娘接回去了。阿四他娘挑着一担新麦来城里，坐在门槛上哭天抹泪，说上海滩的东洋兵天天穿了大皮靴在街上操练，北边也在闹兵灾，怕是又要打仗，死活要把儿子领回乡下种田。阿四一走，店里连个打浆糊、撤粉线的人都没了，冷清得只剩下墙上那台老挂钟，滴答滴答，走得慢吞吞的。

街面上响起一阵急促的雨点声，起初是铜钱大的雨滴砸在瓦楞上，转眼间就连成了线，顺着滴水瓦往街沿石上挂水帘子。

雨幕里走过来一把紫竹骨的明油纸伞。

撑伞的人走得很慢，脚上一双浅灰实地纱的绣花鞋，鞋尖已经叫石板路上的雨水溅湿了一块，变成了深灰色。到了沈记成衣铺门口，那把油纸伞往后一仰，露出一张扑了水粉的鹅蛋脸。

沈长生手里的喷水壶顿了顿，连忙把花镜重新架回鼻梁上，绕过裁床迎出去：“三太太？外头落大雨，怎么不叫黄包车直接拉到门前？”

来人是同德里陆公馆的三姨太翠生。她左手挽着个黑布包袱，包袱皮四角打着结，里头方方正正的是一只小木箱。她把油纸伞收拢，伞面上桐油混着雨水的腥气扑面而来。

“巷子口修阴沟，掘开了三块石板，车子进不来。”三太太喘了口气，声音有点沙，像是早起刚抽过两口水烟，“我让车夫在巷口等着了，横竖就几步路。”

沈长生接过她手里的伞，撑开一半，斜支在门板后头沥水，又转身去搬那张擦得干净的红木靠背椅，拿块碎布头在椅面上掸了掸：“三太太坐。阿四前日回乡下去了，店里也没个泡茶的人，热茶都在竹壳水瓶里焖着，怕是发了黄，吃不得。”

“我不吃茶，刚在家里喝了一碗燕窝汤出来，肚子里还晃荡着呢。”

三太太说着，在椅子上坐下。她今日穿了一件半旧的湖色暗花绸旗袍，领口滚着一分宽的琵琶襟黑缎边，耳垂上坠着两粒成色极好的翠玉耳环。只是人看着有些浮肿，眼皮底下青黑一片，脸上的鹅蛋粉大约是受了潮，在鼻翼两侧积了一层白腻子。

沈长生打量了她一眼，心里暗暗算了算日子。他上回去陆公馆，还是前年冬天，给陆老爷做狐狸皮袍面子，在廊下远远见过她一回。那时候她手里捧着个紫铜手炉，站在廊柱底下骂丫头，声音清脆，下巴颏儿还是尖的。才一年多光景，那点子水葱似的利落劲儿就全卸了下去，肩膀头子塌着，连耳垂上那两粒翠玉都显得沉甸甸的，坠得肉疼。

三太太把膝盖上的黑布包袱解开，露出一只黄澄澄的小樟木箱子，铜锁扣已经有些发乌了。她咔哒一声拨开锁扣，掀开箱盖，一股子浓烈的洋樟脑丸味儿混着陈年木头香，直冲脑门。

箱子里头叠着一件墨绿织锦缎的旗袍，上头用暗金线织着满地折枝梅。

沈长生只看了一眼那布料，手指头就在掌心里摩挲了一下：“这件衣裳，有些年头了。”

“可不是么，”三太太把旗袍拎出来，抖落开，顺手搁在楠木裁床上，“民国十六年开春，我刚进陆家门那会儿，你带着个徒弟到后堂来给我量的身。那时候杭州刚时兴这种暗金线的织锦缎，老爷托人从上海永安公司捎回来的，一共两匹，大太太拣了匹酱紫的，剩这匹墨绿的赏了我。”

墨绿色的缎面铺在乌黑的香云纱旁边，像是一汪见不着底的深潭水，那些暗金色的梅花瓣子在阴雨天的暗光里，泛着一点冷幽幽的陈旧金光。那会儿的旗袍还是老式样，倒大袖，衣身宽博，长只到小腿肚，大襟上钉着一排七粒捷克水钻纽扣。

沈长生低下头，凑近了去看那排纽扣。水钻是八角形的，镶在银托子里，过了十年，底下的锡箔背儿受了潮，有两粒已经发了黑，不像早先那样一晃眼就闪白光了。

“这么好的料子，一直压在箱底？”沈长生伸出两根手指，捻了捻旗袍的下摆。他手背上全是青筋，拇指肚和食指肚因为常年握大剪刀、捏绣花针，结了一层黄亮亮的硬茧，摸在缎面上，连一丝丝织线的钩挂都没有。

“那年做出来，拢共也没穿过两回。后来大太太嫌这颜色显老气，不叫我穿，再往后就时兴长旗袍了，这短撅撅的穿出去，人家要笑话是乡下人进城。”三太太从袖口里抽出一块麻纱手帕，按了按嘴角，“沈师傅，你看看，这件衣裳还能不能改？把袖子改窄些，两边开衩再往上挑两寸，领子……领子倒不用动，我现在脖子短了，穿不得如今那种顶到下巴颏的高领。”

沈长生把旗袍翻过来，看里头的缝头：“改是能改。当年给你做这身衣裳的时候，大太太交代过，说是新进门的人，身条还没长定，让我在两边腋下和腰身里头，都多留了八分宽的缝头。只是这衣裳原本短，如今时兴长到脚面，这下摆就是把折边全放下来，也顶多到脚踝骨上头。”

“到脚踝骨就够了，”三太太看着门外的雨帘子，语气淡淡的，“又不是去吃花酒、听堂会，要那么长做什么。赶路的时候，短两寸反倒利索，免得踩一脚泥。”

沈长生停下手里的活计，抬头看了她一眼：“三太太要出远门？”

屋里静了一会儿，只有门外屋檐水滴在石板上的声音，啪嗒，啪嗒。巷子深处那个卖熏青豆的担子又转回来了，木梆子敲得比刚才还慢。

“老爷前几日从上海回来，跟大太太关在房里商量了一宿。”三太太把声音压低了些，手指头在樟木箱子的铜包角上抠着，“说是外头风声紧，闸北那边天天有人搬家，华界里的有钱人都往法租界里钻。老爷在汉口有两间栈房，打算过了端阳节，就带大太太和四姨太坐轮船去汉口避一避。”

沈长生没接话，只低着头，用指甲盖去刮织锦缎缝头里残留的一点白粉线印子。陆公馆里的那点子事，他在街面上听人嚼舌根也听了个七七八八。那个四姨太是前年刚讨进门的苏州本地评弹女先生，会唱一口极糯的《珍珠塔》，去年秋上刚给陆老爷生了个小少爷。这乱世里头，老爷们逃难，金条、细软、姨太太，总归是要挑拣着带的。

“老爷给了我三百块钱，还有常熟乡下的十亩水田契纸，让我先回常熟娘家去住一阵子，等太平了再接我回来。”三太太笑了笑，脸上的白粉随着笑纹裂开两条细细的缝，“我娘家那个兄弟，是个吃白面儿的，我这一回去，若是穿得寒酸了，连门房都要给我脸子看；若是穿得太扎眼，他又该算计我箱子底下的体己钱。我想来想去，还是把这件老衣裳翻出来改一改。料子是好料子，样式改得收拢些，外头套一件黑纱背心，既不丢陆家的体面，看着也不像是刚从金窝里出来的。”

“三太太想得周全。”沈长生从裁床底下的抽屉里摸出一把黄油布软尺，“那还是得重走一遍尺寸。十年的工夫，人的骨架子虽不变，肉头总归是有增减的。”

三太太站起身来，走到天井边亮堂些的地方，把下巴微微抬起来，两只手臂自然地垂在身侧。

这是她年轻时做衣裳养成的老规矩。那时候她才十九岁，还没学会抽水烟，身上带着一股子常熟乡下菱角塘里的水草气，站在陆公馆后堂的穿衣镜前头，也是这么抬着下巴。

沈长生把软尺搭在脖子上，走到她跟前。

雨气从天井上头直灌下来，带着一股子青苔的冷腥味，可三太太身上却有一股子热烘烘的香气，是刨花水、白兰花、水烟膏子，还有樟木箱子混在一处的味儿。沈长生屏了屏气，扯下软尺的一头，捏在左手指尖，右手拉着尺身，先从她后颈窝的骨头凸起处按下去，顺着脊梁骨往下量背长。

油布软尺用得久了，边角已经磨起了毛，贴在那件半旧的湖色绸旗袍上，发出极轻的一声“沙”。

三太太的后背猛地绷紧了一下，肩胛骨往里缩了缩。

“别端着肩膀，三太太，”沈长生的声音隔着花镜落下来，平平淡淡的，跟十年前一模一样，“端着肩，量出来的背宽就窄了，回头腋下要吊筋，抬手拿东西就不灵便了。”

三太太吐出一口气，肩膀慢慢垮了下来。她盯着墙角一只正在结网的喜蛛，轻声说：“沈师傅，我是不是背上长肉了？这两年老觉得后背发紧，夜里睡不好，起来总要让丫头拿拳头捶半天。”

“没长肉，是骨头架子往下坠了些。”

沈长生把软尺绕到她身前，量胸围，再往下，绕过她的腰身。他的手指头极有分寸，大拇指垫在软尺里头，隔开衣料和她的皮肉，只用指背轻轻抵着尺码。

三太太本能地把肚子往里吸了吸。

“松开吧，三太太。”沈长生低着头看尺上的黑字，“穿衣裳是为了自己舒坦，又不是给别人看的。紧那半寸，吃碗汤面都要喘大气。”

三太太的脸皮在阴暗的天光里微微泛起一点红晕，把那口提着的气松了开来。腰身上的软尺便顺着她的动作，往外滑出了小半寸。

沈长生掐住尺头，心里头那个搁了十年的数字，冷不丁地就翻了上来。

民国十六年，她腰围是一尺六寸二。那时候他半跪在脚踏上给她量臀围和衣长，她低着头看他头顶的发旋，趁着大太太转身去吩咐婆子端茶的空当，小声问了他一句：“沈师傅，这墨绿色，我穿了真不显老么？”他那时候才三十出头，老婆刚死了一年，手里的软尺抖了一下，没敢抬头，只闷声回了一句：“三太太皮色白，压得住。”

如今软尺上的刻度停在一尺七寸半上头。倒不是真胖了，是人到了三十岁往后，年轻时那股子绷得紧紧的精气神散了，皮肉便跟着松懈下来，像洗过了几水的丝绸，失了筋骨。

“腰围放一寸二分，臀围放八分。”沈长生收回软尺，重新挂回脖子上，走到裁床前，拿起一块白粉片，在账本背面记下几个数字，“袖笼倒是要收进去半寸，你这两条胳膊比早先细了。”

“天天在屋里闷着，连麻将都凑不齐一桌人，可不就瘦了么。”三太太走回椅子边坐下，看着沈长生把那件墨绿织锦缎旗袍重新铺平，“前儿个四姨太房里的丫头来借我的翡翠麻将牌，说是四姨太害喜，闻不得骨头牌的腥气，要拿玉牌去摸两圈。我没给，回头老爷就过来说了我两句，说是一家人，何必那么小气。”

沈长生从针线匾里挑出一把拆线用的小刀，刀尖磨得雪亮。他左手捏起旗袍的腋下接缝，右手刀尖轻轻一挑，那些藏在缎子底下的陈年棉线便“嘣、嘣”地断开了。

“老棉线脆了，本来也该拆了重缝。”沈长生低着头，一刀一刀挑得极稳，“我这儿还有一轴德国进口的墨绿丝线，韧性足，给三太太用双线密针缉上去，再穿十年也脱不了线。”

三太太看着他头顶那片花白的头发，忽然问：“沈师傅，这仗要是真打起来，你往哪儿去？也回乡下去么？”

沈长生手里的刀尖停了停，把拆下来的一撮旧线头捻成一团，扔进脚边的竹篓里：“我老家在无锡乡下，早没地了，回去喝西北风？我就守着这间铺子。不管是东洋人来，还是什么人来，总归是要穿衣裳的。实在没新衣裳做，给人家缝补浆洗、改肥改瘦，也能混口饭吃。”

他说完，转身走到靠墙的那个五斗橱前，拉开最上头一个分了三十六个小格子的木抽屉。那里面存着他攒了半辈子的零碎物件：成对的盘金扣、单只的碧玺坠子、西洋来的玻璃珠、各色丝绦。他在角落那个格子里翻拣了一阵，拈出两粒八角形的捷克水钻纽扣，走回来放在裁床上。

“你这大襟上的水钻扣子，第三粒和第五粒底托发黑了。我这儿正好还剩两粒当年同批买的货，拿棉花裹着收在盒子里，没见过风，还亮堂着呢，一并给你换上。”

三太太凑过去看。那两粒新扣子搁在发黑的旧扣子旁边，切面齐整，在暗沉沉的屋里折射出两点清亮的白光。她伸出手指头，轻轻碰了碰那粒水钻，冰凉的。

“你还留着呢？”她声音很轻。

“做裁缝的，最怕客人回头来配扣子配不着。好衣裳掉了一粒扣，就跟美人缺了一颗门牙似的，全毁了。”沈长生拿起粉线袋，扯出里面的棉线，在旗袍腰身的反面“啪”地弹出一道笔直的白印子，“后天下午，雨要是停了，我让人给你送到公馆后门去。”

“不用送，”三太太把空了的樟木箱子重新拿黑布包好，挽在胳膊肘上，“后天我自己来取。这几天公馆里乱糟糟的，都在打点箱笼，门房上的人眼睛长在头顶上，你送过去，指不定给你搁在哪张冷板凳上，落一身灰。”

她走到门口，去拿那把紫竹骨的明油纸伞。

沈长生送出去两步，站在门槛里头：“外头石板滑，三太太留神脚下。”

三太太撑开伞，伞骨发出“咔”的一声轻响。她站在滴水檐下，回过头看了看铺子里头。楠木裁床上，那件拆开了一半的墨绿织锦缎旗袍软塌塌地摊着，像是一张刚蜕下来的蛇皮，那些暗金色的折枝梅在半明半暗的光影里，显出一种近乎妖异的艳丽来。

“沈师傅，”她站在雨雾里，半张脸遮在油纸伞底下，“腰身……还是按一尺七寸二做吧。到了常熟乡下，吃不到燕窝汤，总归还要再瘦下去一点的。”

沈长生隔着花镜看了她一会儿，点了点头：“好，听三太太的，收进去三分。”

三太太没再说话，转过身，撑着那把明油纸伞，一步一步走进了悬桥巷湿漉漉的雨雾里。浅灰实地纱的绣花鞋踩在青石板上，避开一处积水，又踩进另一处水洼里，很快就被巷子口拐角处的粉墙挡住了。

巷子里那个卖茶食的小贩正好挑着担子从铺子门前经过，见沈长生站在门口，便歇下担子，掀开盖在竹匾上的油布，笑道：“沈师傅，称两角钱的熏青豆吃茶？今天刚用柏树锯末烘出来的，香得很。”

沈长生在围裙上擦了擦手，从兜里摸出几个铜板递过去，用一张裁剩下的旧报纸包了一小包熏青豆。

他捧着纸包回到裁床后头，拈起一粒青豆扔进嘴里。豆子皮烘得微皱，带着一股子浓重的烟熏气，嚼起来极有韧劲，咸津津的，过后又有一点回甘。

泥炉子里的白炭已经蒙上了一层白灰，那只鸡公头的生铁烙铁也凉透了。沈长生慢条斯理地嚼着豆子，拿起那块白粉片，把刚才在墨绿织锦缎反面弹出来的那道白线擦掉，将油布软尺往里挪了三分，重新画了一道白印子，随后抓起那把一尺二寸长的大铁剪刀，顺着白印子剪了下去。
