# 封窗之后的阁楼留声

喂，喂。红灯亮了，应该已经在录了吧。

裴医生，下午好。今天是我的康复训练第……抱歉，我又忘了今天是第几天了。早上八点醒来的时候，我照例看着天花板发了很久的呆，直到看见用红绳系在左手腕上的这支银色录音笔，以及贴在床头柜上的便签。便签上写着：“按下播放键，听完第001号文件，不要惊慌，有人深爱着你。”

那是温言的字迹。清秀、工整，末尾还画了一个小小的笑脸。

听完那段二十分钟的001号录音，我才拼凑起自己的身份。原来我叫沈嘉树，今年三十四岁，八个月前在环海高速上遭遇了严重的连环追尾。挡风玻璃碎裂伤到了我的脸，方向盘撞击和脑部淤血损伤了海马体，让我患上顺行性遗忘症。每睡一觉，大脑就会彻底清空前一天的记忆。

裴医生，您提出的这套“晨间二十听、午后一记录”的脱敏疗法真的很管用。现在是下午三点刚过，我刚刚按照001号录音里的嘱咐，把卧室打扫了一遍。趁着温言去花店进货还没回来，我把录音笔揣在衬衫口袋里，一边叠衣服，一边向您汇报我今天的身体状况与心绪。

说实话，今天早上刚按下播放键的时候，我还是被自己的声音吓了一跳。

001号录音里的我嗓音极哑，每说两三句话就得停下来剧烈喘息。背景音里一直有很响的“滴答、滴答”声，水滴规律地砸在空旷的石板上，偶尔还能听见铁管震动的嗡鸣。

幸好我在录音刚开头不久就向自己解释清楚了：那是我在拔掉气管插管后的第二天录下的，当时医院住院部老楼的暖气管道刚好在漏水。最让我愧疚的是进度条快推到中段的地方，那时候我正在提醒自己“绝对不要去碰门锁，也不要试图拉开窗帘”，话音刚落，背景里突然炸开沉闷的撞击响动，紧接着是一阵电流滋啦作响的杂音，夹杂着我自己带着哭腔的惨叫。

那时候我肯定是因为刚做完开颅手术，四肢肌肉萎缩没拿稳麦克风，不小心从病床上摔下来，还撞翻了心电监护仪吧。我听见温言在录音背景里轻轻叹了口气，走过来用高跟鞋踩住地板，温柔地说了句“重念”。

她一定是为了让我留下最清晰、最准确的康复指令，才忍着心疼逼我把那段话重新录完的。那二十分钟里，我一共说了十七次“我很幸福”，十二次“温言对我很好”。听着过去的自己用那么颤抖却笃定的语气反复强调这两句话，我原本空荡荡的胸口一下子就被填满了。

您听，这是我折衣服的声音。温言晒衣服的时候大概加了柠檬味的柔顺剂，闻起来很清爽。

不过这场车祸给我的身体留下的后遗症，比我想象中还要古怪一些。我刚刚把衣柜最下层的抽屉整理了一遍，发现我的体型在昏迷的这八个月里变化得太夸张了。

我身上这件深灰色法兰绒睡衣大得离谱，袖口挽了好几道还会滑下来盖住手背，裤腰得用粗麻绳死死系着才不会掉。可抽屉里那件米白色高领毛衣却很小，我拿出来比划了一下，肩线窄得连胳肢窝都套不进去。门口鞋架上还摆着三双尺码不一的男士皮鞋，从小到大都有。我随便挑了双差不多的穿在脚上，在屋里走动时，脚后跟还是空出一截，哐当哐当地响。

001号录音里说，这是因为我在重症监护室里打过大量激素，身体一度水肿到两百多斤，出院后又因为营养不良迅速消瘦，连骨骼接缝处都缩水了。温言为了照顾我，只能按照不同阶段的体型给我买衣服。

她真是个粗心又可爱的女人，连买回来的旧衣服口袋都没掏干净。我刚才在整理那件XXL码的藏青色风衣时，从内袋里摸出了一个磨砂黑框眼镜盒。

我以为那是车祸前戴的眼镜，打开一看，鼻托歪在一边，左镜片裂了道长缝，边缘沾着发黑变脆的暗褐色污渍。我把眼镜架上鼻梁试了试——天哪，裴医生，刚睁开眼，整个房间瞬间天旋地转，晃得我胃里翻江倒海，差点当场吐出来。镜片极厚，度数很深，还带着重影严重的散光。

我赶紧把眼镜摘下来塞回口袋里。看来您在诊疗方案里写的“视神经压迫已完全解除”是真的。我现在不戴眼镜，连墙角地板缝里的灰尘都能看清。我决定等会儿把这副旧眼镜藏进床底，要是让温言看见我乱翻东西，她又要担心我的脑神经恢复情况了。

对了，裴医生，我的洗漱习惯也保持得很好。

午后我去洗手间洗了把脸。里面的布置和第一条录音说的不差：洗手池上方没有镜子，只有一块刮掉水银背漆的毛玻璃，上面用白乳胶糊了厚厚的牛皮纸。连不锈钢水龙头和吃饭用的铁勺，表面也全用粗砂纸打磨成了毫无反光的哑光灰。

我在录音里警告过自己，千万不能找任何反光物看脸。车祸时挡风玻璃在我脸上留下大片撕裂伤，出院那天我无意间瞥见镜子，当场发病，抓起碎玻璃差点割破喉咙。温言怕再刺激我，把家里所有能照出人影的东西都封死了。

可是裴医生，你们医院的整形外科技术是不是已经达到世界顶尖水平了？

刚才洗脸时，我闭着眼，用指腹摸了摸额头、眼角和鼻梁，一直顺到下颌。除了短短的胡茬和不见阳光的松弛皮肤，脸上平滑得很，摸不到半点凸起的疤痕，连针脚的痕迹都没有。我用舌尖顶了顶腮帮子内侧，只有左边缺了一颗后槽牙，大概是撞上方向盘时磕掉的。

植皮手术能做到看不出半点接缝，肯定花光了家里的积蓄。床头柜的结婚照上，新郎的脸也被温言贴了块印着小熊图案的医用胶布。照片里穿西装的男人肩膀很宽，脖子粗壮，站在穿白婚纱的温言身边格外魁梧。温言怕我看到车祸前的样子会有落差，连照片都仔细遮住了。

想到这里，我就觉得手腕上一阵阵发紧。

我低头看了一眼自己的双手手腕。在尺骨突出的位置，左右手各有一圈一指宽、已经结痂脱落的紫红色凹痕，皮肤异常粗糙。脚踝上也有同样的一圈印子，哪怕隔着厚棉袜，走路时还是磨得生疼。

这是我在重症监护室胡闹时，护工怕我拔管，用约束带绑出来的印子。可车祸过去大半年了，手腕上的血痂前两天又裂开过，渗出淡黄色的水，闻着有股铁锈味。右手食指也没了指甲，暗红色的甲床软绵绵的，一碰就钻心地疼。

001号录音里说，这是因为我每天吃的抗癫痫药物会严重抑制表皮细胞的代谢，导致伤口愈合极慢。裴医生，下次复诊的时候，能不能帮我把药量稍微减一点点？没有指甲的话，我连给温言剥橘子皮都使不上劲。

我把叠好的衣服放进衣柜，顺手拿起扫帚，开始清扫窗台下面的角落。

我们家住在十四楼，这是001号录音里特意交代的。因为我有严重的脑外伤梦游症，好几次半夜走到窗边想要往下跳，再加上我的眼睛有畏光后遗症，见不得太阳，所以温言请木工把卧室的两扇窗户全都封死了。

封窗用的根本不是普通窗帘，是两指厚的松木板。木板从窗外钉死在墙体上，用的是比中指还长的粗铁钉。大概因为外墙木板不够厚，十几根铁钉直接穿透了内侧窗框，尖锐的钉头戳进房间里。今天早上我起床时没站稳，手掌差点按在那一排钉尖上。

温言一个身形单薄娇小的女人，为了防止我在梦游时从里面用羊角锤把钉子撬开坠楼，居然系着安全绳爬到十四楼的空调外机上，从外面一锤一锤地把这些大铁钉砸了进来。每次想到那个画面，我都恨不得抽自己两耳光。

不过十四楼的隔音好像不太好，而且今年春天的雨水未免太多了。

我蹲在窗台下扫地的时候，头顶上方突然传来一阵轰隆隆的巨响，震得松木板簌簌落灰，听声音像是一辆满载泥土的重型拖拉机紧贴着窗户上方碾了过去，连地面都在跟着微微发抖。紧接着，我闻到了一股极其浓郁的、混合着腐烂树叶和化肥的腥味。

我看见窗框最底下的水泥缝隙正往里渗黑褐色的泥水。两条筷子粗的红褐色蚯蚓从湿漉漉的木板缝里钻进来，在地板上扭动，身后拖出两道水迹。

十四楼怎么会有拖拉机和蚯蚓呢？我盯着地面怔忡了片刻，很快又想通了。

温言本身就是开花店的，她一定在窗外的防盗网花槽里铺了厚厚的营养土，种满了需要蚯蚓松土的绿植。刚才那阵轰鸣声，八成是对面楼栋在用吊车搞外墙翻新，声波在楼宇间产生回音，听着才让人误以为在头顶开车。

我用废纸包起两条蚯蚓扔进垃圾桶，拿抹布擦净泥水。

干完这些活，我的后背已经出了一层薄汗，太阳穴也开始一跳一跳地发胀。我看了眼墙上的挂钟——挂钟的玻璃罩也被拆掉了，指针是用软塑料做的——现在是三点半刚过，到了该喝药的时间了。

桌子上放着一个粉色的保温杯，那是温言每天早上出门前为我炖的冰糖杏仁露。我拧开盖子，一股浓烈的苦杏仁味混着甜腻的糖精味扑面而来。

我端起杯子喝了一大口。温言放了很多冰糖，甜得发齁，但咽下去后，舌根和喉咙立刻泛起强烈的金属苦涩味。喝到最后一口时，杯底沉淀着厚厚一层没化开的白色粉末，嚼在嘴里沙沙作响，满嘴都是药片碎渣的质感。

裴医生，您开的这种安神中药粉确实难以下咽，而且药效来得太快了。我刚把空杯子放回桌上，手脚就已经发软，眼皮沉重得抬不起来，连握着录音笔的手指都在发麻。

这就是001号录音里说的“正常药理反应”吧。只有在下午四点前进入深度睡眠，我的海马体才能在夜间得到充分的修复。

趁着最后一点清醒的时间，我决定把房间角落里那个大冰柜底下的灰尘擦一擦。

那是一台商用的卧式白铁皮大冰柜，宽大得能塞进整个人，高度直抵腰腹，就摆在离我床头不到两步远的地方。冰柜的压缩机日夜不停地运转，低沉而单调地“嗡——嗡——”作响。为了防止我梦游时乱翻东西冻伤自己，温言用两条小臂粗的铁链把冰柜死死缠了三圈，接口处挂着一把黄铜大挂锁。

001号录音里千叮咛万嘱咐，说那里面冻着温言从荷兰进口的珍稀郁金香种球和高级动物黄油，必须严严实实地冻在最冷的档位里，半点回温都受不得。如果我好奇去撬锁，冷气跑出来，那几万块钱的货就全毁了，我们这个为了给我治病已经负债累累的家，根本承受不起这样的损失。

我当然不会去碰那把锁。我只是觉得压缩机这几天的声音有点不对劲，而且冰柜右下角的排水孔好像堵住了。

我趴在地上往冰柜底下看。水泥地面积了一小滩半干的暗红色液体，边缘结了黑紫色的硬壳，臭猪肉混杂着84消毒水的怪味直冲鼻腔。

我抽了几张纸巾，把地上那滩暗红色的液体擦干净。纸巾染上一大片刺目的红褐色。多半是冰柜的制冷管老化漏了液，也可能是温言冻在里面的覆盆子果酱袋子破了。她每天守着花店已经够累了，回来还要照顾我这个废人，不能拿这种小事烦她。

我把脏纸巾团成一团，正准备撑着地板站起来，左手掌心突然按到了冰柜后方墙角的一块凸起。

那里的墙纸好像受潮翘起来了。

因为药物的作用，我的视线已经开始出现重影，脑袋昏沉得厉害，但我还是本能地想帮温言把翘起的墙纸按回去。我伸出手，掀开那巴掌大的一角米黄色墙纸，想看看里面是不是发霉了。

墙纸后面没有发霉。

破损过半的白灰墙面上，密密麻麻刻着几十道深浅不一的竖线，每道竖线旁都沾着干涸发黑的血迹。在最右边，有人用钝器在坚硬的水泥墙皮上拼命抠挖，硬生生抠出三个歪歪扭扭、只写了一半的汉字：

**快逃 她不**

那个“不”字的最后一捺拉得很长，深陷在墙灰里的沟壑尽头，死死卡着半片翻卷过来的、带着干涸肉丝的人类指甲盖。

我跪在冰柜旁边的冷气里，歪着头，盯着那半片发黄的指甲盖看了很久。然后，我慢慢抬起自己的右手，把那个没有指甲、只剩下一层暗红色嫩肉的食指指尖，凑到墙面上比划了一下。

大小、弯折角度，甚至连边缘断裂的锯齿形状，都分毫不差地咬合上了。

我呼吸猛地一滞，心跳骤然加快。汗水顺着鬓角滑下，滴在水泥地上。

天哪。裴医生，您听见了吗？

我现在终于明白温言为什么从来不在我面前提我刚出院时的样子了。我那时候的狂躁症和被害妄想症到底严重到了什么地步啊？我居然在自己的新房里犯了病，用手指头活生生把指甲盖抠断在墙里，写出这种恶毒的疯话来污蔑她！

她当时一定就站在这扇铁门后面，看着发狂抓挠墙面的我默默流泪。等我发作完昏过去，她没有怪我，也没把我送进精神病院，却买来新墙纸，一点一点妥帖地把抓痕糊上，再帮我把血淋淋的手指包扎好。

我真是个无可救药的混蛋。

我忍着食指指尖传来的刺痛，用大拇指把墙灰里那半片断甲抠了出来，塞进睡衣口袋，然后从抽屉里拿出一管固体胶，仔细地在墙纸背面涂满，一点一点把那三个字重新严严实实地贴好、压平，连半点缝隙都没留。

做完这一切，我几乎是手脚并用地爬回了床上。

舌根的苦味越来越浓，我的四肢彻底失去知觉，瘫软地陷在床垫里。就在我快要合上眼时，走廊外传来了熟悉的脚步声。

那脚步声很沉，一步一步踩在水泥台阶上，从上面慢慢往下走。

紧接着，卧室那扇没有内把手的厚重铁门外，传来了“咔哒、咔哒、咔哒”三声清脆的金属落锁声。最上面那道粗大的外插销被拉开了，门轴发出一声令人牙酸的吱呀声，一道刺眼的手电筒白光顺着门缝切了进来。

光线太亮，刺得我眼泪直流。我眯起眼，看见一个高挑的女人逆光站在门口。她没拿花，左腋下夹着一卷银灰色工业胶带，右手拎着一只沉甸甸的黑色塑料桶。桶里飘出的铁锈味，和冰柜底下一模一样。

她低头看着躺在床上的我，没有说话，先弯腰从门外捡起一把铁锤，叮叮当当地敲打着门槛边缘松动的木条。

“温言，你回来啦。”我努力扯动已经僵硬发麻的脸颊，对着那个模糊的黑影露出一副温和的笑脸，趁着她走过来抽走我手里的录音笔之前，对着麦克风说出了今天的最后一句话，“裴医生，我太太来接替您照顾我了，明天下午三点，我再向您汇报我的康复情况。”
