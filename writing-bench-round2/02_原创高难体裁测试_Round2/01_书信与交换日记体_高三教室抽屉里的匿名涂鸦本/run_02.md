# 四号自习室，靠窗第三张课桌

**[2月24日 午 · 封面内侧，极细的黑色水笔，笔划用力，几乎划破黄草稿纸]**
麻烦借用这张桌子的晚班同学注意一下卫生。
今天早上过来，桌洞最里面全是黑色的粉末，我的白校服袖子蹭黑了一大块，去洗手间用肥皂搓了十分钟都没洗干净。还有，桌面右上角那一圈黏糊糊的褐色印子是什么？如果是冰红茶，请走的时候用湿纸巾擦掉。高三时间很紧，我不想每天早读前先当十分钟保洁员。

**[2月24日 夜 · 第1页，4B铅笔，字迹宽扁潦草，末尾画了一个双手合十的火柴人]**
抱歉抱歉！
黑色粉末是柳木炭条的渣，昨晚赶着背文综，随手把速写板塞桌洞里了，没注意炭粉掉在里面。我已经用湿抹布把桌洞里外擦了三遍，右上角是昨晚喝剩的冻柠茶，也擦干净了。
左边笔槽里放了一块灰色的“可塑橡皮”（捏成正方体那个，不是嚼过的口香糖，别扔！），你校服袖子如果还有黑印，拿那个在布料上轻轻粘几下就能吸下来。如果还洗不掉，你把校服尺码写在这儿，我周末去校服店买件新的赔你。

**[2月25日 午 · 第1页，细尖黑色水笔，字迹比昨天平缓]**
不用赔。用洗洁精泡了一晚上，洗掉了。
那个灰色的泥巴我用了一下，确实把桌缝里的黑灰粘出来了，还放在原处。但今天桌洞里又多了一截断掉的美工刀片，直接散落在外面。你削铅笔能不能准备个笔刀盒？我早上伸手摸《五年高考三年模拟》，食指差点被划破。我要是右手受伤写不了字，你赔不起。

**[2月25日 夜 · 第1页反面，蓝色圆珠笔，夹着一张折成小方块的超市小票]**
我的错，刀片收走了，以后绝不在自习室削铅笔。
看你把这本学校发的黄皮草稿本垫在最底下当桌垫，我翻了一下，前面十几页都是空的，就借用半页写个留言。小票里包着两片创可贴，万一以后被试卷边缘割到手可以用（高三的卷子有时候比美工刀还快，我深有体会）。
另外，窗台缝里那盆快蔫死的铜钱草是你养的吗？昨晚十点半下自习的时候看它叶子全垂下来了，顺手倒了半瓶矿泉水。如果是做生物实验需要干旱对照组的，我先滑轨道歉。

**[2月27日 午 · 第2页，细尖黑色水笔]**
铜钱草是上届学姐留下的，没人管，你随便浇，别浇出蚊子就行。
创可贴收下了。作为交换，提醒你一句：昨天下午年级主任来四号自习室巡查，看到桌洞侧面贴着一张便利贴，上面画着他的秃头漫画，差点把我们白班的班长叫出去训话。我趁他转头的时候帮你撕下来吞进草稿本里了（夹在第15页）。
你们艺术班复读生晚上过来上课，巡堂老师不管的吗？

**[2月27日 夜 · 第2页，2B铅笔，漫画便利贴下方补画了一顶鸭舌帽]**
救命之恩！
老陈后脑勺那圈头发实在太有素描体积感了，昨晚听网课走神，没忍住画了一张。我们晚班是校外画室和学校合办的，七点进场，十一点熄灯，宿管大爷只管锁门，老陈一般八点半就回家遛狗了，没想到他白天还会突击检查。
作为封口费，今天不往桌洞里放垃圾了，放了一颗溜溜梅，青梅味的，在草稿本下面压着。

**[3月4日 午 · 第3页，细尖红色改错笔，字迹旁边有一道长长的尺子划痕]**
梅子太酸了，早读背古文的时候差点把牙酸倒，不过挺提神。
翻到第4页背面，看到你昨晚算的那道三角函数题。我实在没忍住——你诱导公式是怎么背的？
$\sin(\pi - \alpha)$ 怎么会等于 $-\sin\alpha$？奇变偶不变，符号看象限，第二象限正弦是正的！你第一步符号就弄反了，后面还认认真真通分算了大半页，最后算出一个 $\cos\alpha = \frac{\sqrt{5}}{2}$。
$\frac{\sqrt{5}}{2}$ 大于 $1$ 啊同学！余弦值域是 $[-1, 1]$，你算出个大于 $1$ 的数居然直接写“综上所述”了？

**[3月4日 夜 · 第4页背面，黑色记号笔，在红字批注旁画了一个抱头蹲防的小人]**
……别骂了别骂了，我把草稿写反面就是怕丢人，你怎么还往后翻啊！
我从去年七月去杭州集训画画，到今年二月底校考结束，整整八个月没碰过数学课本了。昨晚盯着那个 $\sin$ 和 $\cos$ 看了半小时，感觉它们像某种罗马柱的装饰花纹。
既然你都拿红笔批了，好人做到底，帮我看看第5页上面那道数列求和行不行？答案直接写了个 $S_n = (2n-1)\cdot 2^{n+1} + 2$，中间那步“错位相减”到底是怎么减出来的？我减了三次，多出来一串奇奇怪怪的尾巴。

**[3月5日 午 · 第5页，极细的蓝色水笔，字迹工整，每一步对齐得像印刷体]**
看右边空白处：
① $S_n = 1\cdot 2^1 + 3\cdot 2^2 + 5\cdot 2^3 + \dots + (2n-1)\cdot 2^n$
② $2S_n = 1\cdot 2^2 + 3\cdot 2^3 + \dots + (2n-3)\cdot 2^n + (2n-1)\cdot 2^{n+1}$
两式相减的时候，要把 $2$ 的同次幂对齐！你昨晚的草稿把第①式的第一项和第②式的第一项直接减了，指数都不一样怎么合并？
还有，相减之后中间是公比为 $2$ 的等比数列，但是注意**项数是 $n-1$ 项**，不是 $n$ 项。你把首项当成 $2^1$ 算了，前面那个 $2$ 是单独拎出来的。最后前面是个负号，移项过去要变号。
（顺便说一句，这是高二期中考试的基础题。你们离六月高考也就剩九十多天了，你这个进度有点危险。）

**[3月5日 夜 · 第5页下方，笔迹偏粗的黑色水笔，附带一张贴在页脚的自动贩卖机热饮收据]**
看懂了！原来是我对齐的时候错位了，我就说怎么每次都多出一个 $2^n$。不愧是白班火箭班的大神（我看桌角贴的座位条写的是一班，一班是理科实验班对吧？）。
作为数学家教费，本来想给你留瓶热牛奶，但我想着放到第二天早上肯定凉透了。我把楼下贩卖机的取货码写在收据背面了，你明天早上按那串数字就能掉出一盒热豆浆。机器里是恒温五十度的。
别嫌弃，总比溜溜梅强。

**[3月12日 午 · 第7页，细尖黑色水笔，纸张受潮发软，字迹有些洇开]**
回南天太讨厌了。这本草稿本纸质本来就差，今天早上拿出来跟咸菜干一样软塌塌的，写字稍微用力一点就戳个洞。
豆浆喝了，谢谢。这几天走廊的瓷砖都在往下淌水，一班有个男生早上端着洗脸盆跑过四号自习室门口，直接滑出去三米远。
你在桌肚里塞的那几张旧报纸挺管用，垫着书包底，帆布没受潮。你昨晚没来吗？我看第6页是空的，桌面上也没有橡皮屑。

**[3月13日 夜 · 第7页，2B铅笔，右下角粘着一小块干透的浅蓝色丙烯颜料]**
昨晚去广州拿画室的行李了，顺便去邮局寄了几个画筒，没赶上晚自习。
这天气确实要命，画室储藏间里的石膏像都在冒汗，大卫的鼻尖一直在往下滴水，像感冒了一样。我今天带了两包相机防潮箱里用的硅胶干燥剂，扔在桌洞最里面那个铁皮文具盒后头了，你别当成零食调料包扔了就行。
对了，今天来的时候发现靠窗这扇百叶窗的摇柄断了，玻璃页片合不上，晚上一刮风直往里灌湿气。我找了截铁丝从外面的防盗网扣住了，你白天要是觉得闷想开窗，把最下面那根铁丝往左拧半圈就行，小心别扎手。

**[3月19日 午 · 第9页，细尖黑色水笔，页面中间画了一个歪歪扭扭的圆圈和几根凌乱的线条]**
铁丝看到了，你手还挺巧。今天上午总算出了点太阳，对面的大榕树上有两只灰喜鹊一直在叫，吵得我立体几何都做不进去。
我想把那只鸟画下来，结果画出来像一只长了毛的拖鞋（见左图）。你们学画画的平时到底是怎么把一样东西画得像它本身的？

**[3月19日 夜 · 第9页，4B铅笔覆在黑色水笔线条上，几笔勾出鸟的脊背弧度与尾羽]**
哈哈哈哈哈哈“长了毛的拖鞋”！对不起，实在没憋住，差点在晚自习笑出声被班主任逮住。
其实你抓特征抓得挺准，灰喜鹊尾巴就是很长。你画不像主要是因为你一直在用写数学题的思维画“概念里的鸟”——你知道鸟有圆脑袋、尖嘴巴、两条腿，所以你就拼积木一样把它们凑在一起。
你看我用铅笔改的这几根线：别去想它是翅膀还是肚子，你就把它看成几个几何切面（你们理科生最熟这个了）。鸟蹲在树枝上的时候，重心是往前倾的，背部和尾羽其实是一条连贯的折线，夹角大概 $150^\circ$ 左右。
我在你那只“拖鞋”旁边画了三步分解图，明天灰喜鹊要是还来，你照着试一下。

**[3月20日 午 · 第10页，细尖黑色水笔，画了一只稍微像样点的鸟，旁边列了一道解析几何题]**
试了一下，好像真的没那么像拖鞋了！用几何切面去理解确实清楚很多。
礼尚往来，我翻了你昨晚留在第8页的椭圆大题。你联立直线和椭圆方程之后，算判别式 $\Delta > 0$ 是对的，但你韦达定理写错了：$x_1 + x_2 = -\frac{b}{a}$，你漏了那个负号。而且这种求弦长面积最大值的题，设直线为 $x = my + t$ 比设 $y = kx + b$ 算起来快一倍，还不用分类讨论斜率不存在的情况。
我把第二种解法写在小鸟尾巴下面了。你今晚自己重算一遍，不许抄我的步骤。

**[3月28日 午 · 第13页，纸面被圆规尖扎了十几个深浅不一的小孔，边缘贴着一张被撕碎又拼起来的物理答题卡一角，红笔写着“-12”]**
一模成绩出来了。
物理最后一道电磁感应大题，我把磁感应强度 $B$ 的方向看反了，左手定则用成了右手定则，整道题十八分扣得只剩六分。年级排名掉出前三十了。
班主任刚才找我谈话，问我是不是走读在家玩手机分心，让我妈下周开始每天中午来学校送饭盯着我。明明每天学到凌晨一点，连吃饭都在背英语单词，为什么看错一个箭头就要被怀疑是偷懒？
（对不起，把草稿本扎烂了，我明天带卷透明胶过来补。）

**[3月28日 夜 · 第13页背面，贴着一条米黄色的宽美纹纸胶带，完全盖住了圆规扎孔；正面空白处用2B铅笔画了四个戴安全帽的小人，正抬着创可贴去修补那个“-12”]**
不用带透明胶，透明胶贴在纸上时间长了会发黄变脆，我用画画封边用的美纹纸从背面粘好了，正面还能继续写字。
电磁感应我不懂，左手右手我现在还分不清（画速写的时候经常把人家的左手画成六根指头）。但我复读这一年，最怕听到的就是“你是不是没尽力”这种话。
去年联考，我色彩科目的水粉颜料盒在进考场前摔地上了，白色和柠檬黄混成了一坨脏泥，最后那张卷子只拿了68分。出来的时候所有人都觉得我是平时没练好。
看错一个箭头就是看错了一个箭头，跟偷不偷懒没关系。是一模又不是高考，现在把左手右手搞混了，六月份才不会混。
桌洞里放了一小盒草莓百奇，这次不是酸的。把答题卡撕了扔了吧，留着占地方。

**[3月29日 午 · 第14页，细尖黑色水笔，纸角沾着一点巧克力涂层淡淡的油脂印]**
百奇吃完了。昨天情绪有点失控，谢谢你的胶带，那几个安全帽小人画得很可爱，我用刀片裁下来夹进物理错题本里了。
你说得对，现在错总比六月错好。
看到你第12页背的文综历史时间轴了，你把“辛丑条约”和“马关条约”的赔款数额记串了。口诀给你写在这儿：“二亿马关四五辛”（马关条约两亿两，辛丑条约四亿五千万两）。
还有，你字写得太飞了，文综主观题现在都是电脑扫描阅卷，你那个“资产阶级”的“资”字下面写得像个“贝壳”的象形文字，阅卷老师一秒钟看一张卷子，绝对不会给你找得分点的。从今晚开始，你每天在这本草稿本上工工整整抄一段政治大题标准答案，我白天帮你检查字迹。

**[4月7日 夜 · 第17页，粗尖黑色水笔，一笔一划极其端正的政治术语，但在最后一行破功]**
“生产力决定生产关系，生产关系对生产力具有反作用；经济基础决定上层建筑……”
手快断了！我宁愿去画十张石膏像的明暗交界线，也不想写正楷字。你看今天这半页还能入眼吗？
对了，今天晚自习下课的时候下暴雨，四号自习室屋檐外面有只三花流浪猫一直在叫，浑身淋得像个拖把。我拿你的那盆铜钱草底下的塑料托盘给它倒了点火腿肠碎，它现在蹲在走廊储物柜最下面那格睡着了。明天早上你来的时候要是看见它，别被吓一跳。

**[4月8日 午 · 第17页下方，细尖红色水笔，圈出了三个错别字]**
字比上周好多了，给个“阅”字。但是“矛盾的普遍性与特殊性辩证关系”里，“辩证”是言字旁的“辩”，不是利刀旁的“辨”！罚写五遍。
猫我早上看到了，它居然还在储物柜里没走，我把早餐带的鸡蛋黄抠出来喂它了。它左耳朵有个小缺口，我们白班同学都叫它“半角”（像数学里的半角公式 $\tan\frac{\alpha}{2}$）。
天气预报说这周都是雷阵雨，我的折叠伞坏了一根伞骨，先放在桌子右下角的挂钩上备着，你晚上十一点走的时候要是还在下雨，直接拿去用，第二天挂回来就行。

**[4月15日 夜 · 第20页，钢笔蓝黑墨水，页面右侧有一道被雨水打湿又吹干的波浪形褶皱]**
伞今天派上大用场了。
晚上十点二十的时候突然打雷，整个高三教学楼跳闸停电了十分钟。你们白班没经历过吧？整栋楼黑漆漆的，所有班级都在走廊上起哄尖叫，不知道哪个班的男生在吹口琴，结果吹了两句就被老陈拿手电筒照着鼻子骂回去了。
停电的时候我就坐在咱们这张桌子前，借着外面路灯透过大榕树叶子的那点光，把伞骨上断掉的那个金属关节用回形针重新铆上了。现在撑开不会再往一边歪了。
就是你的伞太小了，印着一圈小碎花，我一个一米八几的人撑着走出校门的时候，保安大爷看了我三眼，眼神非常复杂。

**[4月16日 午 · 第20页，细尖黑色水笔]**
哈哈哈哈哈哈我能想象那个画面！那把伞是我初二买的，确实很小。伞骨居然修好了，我还以为要扔了呢，你简直是个五金店师傅。
这几天降温，我早上来的时候看桌面上有几个鼻涕纸团（虽然你扔进垃圾桶了，但有一团掉在垃圾桶外面的地板上）。你感冒了？
抽屉最里面给你留了两袋板蓝根颗粒，还有一小罐泰国青草膏。青草膏是涂太阳穴防困的，别往鼻孔里抹，会辣出眼泪。

**[4月17日 夜 · 第21页，粗尖黑色水笔，字迹有点飘]**
晚了。昨晚没看清你最后那句话，直接蘸了一点抹在人中上，辣得我灵魂出窍，政治大题背得比平时快了两倍。
确实有点低烧，淋了点雨，问题不大。
刚才做完一套数学模拟卷，选填居然只错了两个！虽然大题还是空了一半，但合起来居然有98分了！我复读以来数学从来没上过90！
你在第10页教我的那个椭圆设 $x = my + t$ 的方法今天考到了，我一分没扣全拿下了。真想请你吃顿海底捞啊，可惜连你长什么样都不知道。

**[4月18日 午 · 第21页，细尖红色水笔，在“98分”上面画了一朵小红花]**
98分很厉害了！保持这个势头，高考数学冲到110完全有可能。海底捞先记账上。
其实我昨天下午放学的时候，故意磨蹭到六点三十五分才走。走出教学楼大门的时候，正好看见几个背着画袋、穿着黑卫衣的晚班男生从校门口买完炒粉往里走。
其中一个特别高，手里拎着一杯柠檬茶，低头在看单词本，差点撞上门口的减速带。不知道是不是你。

**[4月18日 夜 · 第22页，2B铅笔，笔触很轻]**
差点撞减速带的那个不是我，那是我画室的死党，他近视六百度还不爱戴眼镜。
我昨天因为感冒去校医室量了个体温，六点五十才进的自习室。
不过，原来你一般六点半以后才走？我们晚班规定六点四十五分才能进教学楼，平时宿管会在六点三十到四十五之间清场锁门检查。我们之间居然只差了十五分钟。
说起来，我一直以为火箭班的女生都是那种戴着厚瓶底眼镜、走路都在背化学方程式的机器人。直到看到你画的那只“长毛拖鞋”，还有碎花小伞。

**[4月19日 午 · 第22页，细尖黑色水笔]**
谁是机器人啊！我不戴眼镜，两眼视力5.0。而且我也不喜欢背化学方程式，我最讨厌无机化学的工业流程题了，每天都在除杂、过滤、洗涤、干燥，烦都烦死了。
我爸妈非让我报临床医学或者金融，说女孩子学这个稳定。其实我一点都不想看病，也不想算账。每次下午四点半阳光斜着照进四号自习室，刚好切在咱们这张桌子的铅笔槽上，我就看着外面的云发呆，想着要是能去北方读个天文系或者地理系就好了。
但这话我不敢跟班主任说，说了她肯定又要叫家长。只能写在这本草稿本上了，反正你也不认识我。

**[4月19日 夜 · 第23页，黑色针管笔，整页画满了窗外的夜景：百叶窗的横条切割着远处的城市高楼灯火，大榕树的气根在风里飘着]**
那我就把晚上九点的窗外画给你看。
你们白班五点半就拉窗帘开日光灯了吧？其实到了晚上九点，把靠窗这一列的灯关掉一盏，从我们这个角度看出去，能看到很远的地方那座电视塔的红灯一闪一闪的。
我是为了考中国美院才复读的。去年专业课过了，文化课差了四分，滑档到了一个完全不想去的学校。当时家里人也劝我算了，说艺术生有个本科上就行，复读一年万一专业课也考砸了怎么办。
但我就觉得差那四分太不甘心了。
你想去北方看星星，那就去考。分数长在你自己手里，填志愿的时候输密码的也是你自己。

**[5月6日 午 · 第27页，细尖黑色水笔，夹着一片压扁的紫荆花瓣]**
立夏了。学校今天开始开空调了，咱们头顶这个出风口百叶坏了，冷风直直地往脖子上吹，我今天披了一整天校服外套。你晚上来的时候记得带件长袖，别感冒刚好又冻着。
二模成绩下来了，我回到了年级前十五。物理这次没看错方向。
你的数学怎么样了？第26页那道立体几何建系求二面角的题，你法向量算错了，但思路完全是对的。

**[5月6日 夜 · 第27页，粗尖黑色水笔]**
数学这次二模考了106！看到分数的时候我手都在抖，把你留在笔槽里的那块可塑橡皮捏成了八瓣。
头顶的空调风口我处理了一下——我用两张废弃的素描纸折了个导风板，用你上次剩下的美纹纸粘在出风口下面了，现在冷风是往天花板上吹的，不会直吹脑门了。如果明天白天老陈来检查嫌难看，你就把锅推给晚班。
离高考还有三十一天。草稿本只剩最后十页了，我们要不要省着点用？

**[5月15日 午 · 第31页，细尖黑色水笔，字迹略显仓促]**
不用省，写完了我还有三本新的。但我想把这一本留着。
今天上午拍了毕业照。全班站在大操场的台阶上，摄影师喊“一二三茄子”的时候，我突然想起你们晚班复读生好像是不拍毕业照的？
下午大家都在互相签同学录，闹哄哄的，我躲回四号自习室刷了一套理综卷子。看着桌子右上角被你擦掉冻柠茶印子后留下的一点点浅色木纹，突然觉得有点奇怪——我跟班里很多同学同窗三年，讲过的话好像还没跟你在这本草稿本上写的多。

**[5月15日 夜 · 第31页，2B铅笔，页面右下角用圆规和直尺画了一个极其标准的相机取景框]**
复读生确实不拍毕业照，去年拍过一次了，再拍就像留级生纪念大会一样。
不过今天来的时候，操场上的铁架子还没拆。我站在最上面那层台阶上吹了会儿风，假装自己也刚拍完。
要是能给你画张速写就好了。不用看正脸，就画你平时下午四点半看着窗外发呆的背影。

**[5月27日 午 · 第35页，细尖黑色水笔]**
倒计时十天。
学校发了通知，6月5号下午四点就开始封楼布置高考考场，我们四号自习室是第一考场，所有桌洞必须清空，连一张纸片都不能留。
这几天每次做完题抬起头，看着黑板右上角那个粉笔写的数字从“15”变成“12”，再变成今天的“10”，心里反而一点都不慌了，就是觉得时间过得好快。
第34页你背的那篇英语应用文范文，倒数第二句的定语从句引导词用错了，先行词是物，用 which 不用 who。最后十天，别在这种地方丢分。
