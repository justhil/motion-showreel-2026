# 零点过后的生态指标

凌晨一点出头，迎检办借调科员李卫东在“全县生态文明大决战工作专班”微信群里发出最后一条消息：“报告张主任，湿地公园一号观景台点位，两只重点引进禽类指标情绪稳定，状态良好。”

发完这条，他把手机揣进军大衣兜里，顺手拿起手电筒往芦苇荡里头的铁丝网里照了一下。

光柱穿过北方冬夜特有的干冷雾气，照在昨天下午刚喷过绿漆的枯草坪上。草坪中间的塑料食盆里还剩半盆玉米粒，但原本应该蹲在那里的两只蓝孔雀，只剩下了母的那只。公的那只——也就是拖着大半人长的华丽尾羽、承担着明天早上八点省暗访组视觉冲击核心任务的那只，不见了。

塑料绿网右下角豁开了一个洗脸盆大小的洞，几根带眼状斑纹的蓝绿色绒毛挂在铁丝倒刺上，在夜风里轻轻哆嗦。

李卫东的后脑勺当时就麻了。他扭头看向几步开外正对着柳树根撒尿的园林处临时工王建国，压着嗓子低吼：“王叔，裤子先别提了，出大事了。”

王建国抖了抖身子，不紧不慢地系上裤腰带，趿拉着那双开了胶的劳保棉鞋走过来，凑到笼子跟前探头一瞧，把嘴里的烟屁股吐在地上碾灭：“哟，越狱了。”

“这叫脱岗！不对，这叫国有租赁资产流失！”李卫东声音都劈了，手电筒的光柱在王建国脸上乱晃，“十一点半交接班的时候，张主任千叮咛万嘱咐，这两只孔雀是从邻市动物园按天租的，日租金一千五，押金五千！明天早上八点，省里的车队从高速路口下来，第一站就是咱们这儿！现在公的没了，留个母的在这儿，跟家里养的芦花老母鸡有什么区别？怎么体现咱们县生物多样性的跨越式发展？”

王建国双手插进袖筒里，缩了缩脖子：“李科长，话不能这么说。十一点半往里关的时候，是我摁着鸟脖子，是你拿铁丝拧的扣。我当时就说你那拧法是机关坐办公室的拧法，劲儿没吃上，你不听，非说要讲究美学，不能破坏原生态景观。”

“我不是科长，我就是个从农机局借调过来的办事员！”李卫东急得直跺脚，“老王同志，现在不是开展批评与自我批评的时候。你也是十几年老园林了，要是明天早上八点之前这鸟回不来，张主任头一个拿我是问，我回原单位转正的报告还压在他玻璃板底下；但你也跑不了，你们劳务派遣公司下个月的绿化维保尾款，还在财政局卡着呢！”

王建国顿了顿，从兜里摸出半包红梅，抽出一根点上，深吸了一口：“那依李科长的意思，现在给张主任打电话汇报？”

“汇报个屁！”李卫东一把按住王建国摸老年机的手，“现在一点二十，张主任刚在洗脚城做完足疗睡下。这时候打电话，那叫突发重大安全事故；要是咱们在六点天亮前把鸟抓回来塞进去，这就叫成功排查一起潜在隐患，实现了闭环管理。懂不懂什么叫闭环？”

王建国吐出一口烟：“懂。就是捂盖子呗。”

“这叫发挥主观能动性！”李卫东从旁边环卫三轮车上抄起一条装落叶的破麻袋，又给王建国塞了一把搂草的竹耙子，“刚才你撒尿的时候，听见动静往哪边去了吗？”

王建国指了指湿地公园东侧的围墙缺口：“刚才那边野猫叫唤了两声，估计是顺着老法院后墙，钻进‘盛世豪庭’后面那条道了。那地方暖气管道漏水，热乎，畜生都精着呢，哪儿暖和往哪儿钻。”

两人翻过围墙缺口，钻进了县城老街的背阴胡同。

凌晨两点，主干道上的迎检标语牌还亮着白光，写着“绿水青山就是金山银山，生态高阳欢迎您”。一拐进盛世豪庭洗脚城的后巷，地上全是结了冰碴的潲水，粉红色的霓虹灯牌坏了一半，只剩“盛世豪”三个字亮着。

李卫东捏着鼻子，拿着手电筒在垃圾桶后面乱照：“王叔，这孔雀也是国家二级保护动物吧？怎么一点高洁的习性都没有，往这种三俗场所钻？”

“在动物园里天天吃饲料，出来还不改善改善伙食？”王建国用竹耙子扒拉着一堆外卖盒，突然停住动作，下巴往头顶一扬，“李科长，往上照。”

李卫东抬起手电筒。二楼洗脚城包厢外的空调外机上，蹲着一团黑乎乎的东西。借着粉红的霓虹灯，能看清它脑袋上立着一撮呆毛，一大截尾羽顺着外机垂下来，尾端正好泡在底下装满麻辣小龙虾壳的塑料桶里。

那只蓝孔雀正歪着脖子，用尖嘴去啄空调排水管上挂着的冰溜子。

“祖宗哎！”李卫东差点叫出声，赶紧捂住嘴，“快，王叔，你踩着我肩膀上去，拿麻袋直接套它脑袋！千万注意动作规范，动物园签协议的时候写了，拔掉一根带眼儿的大毛扣两百块钱，这要是一嗓子惊飞了，五千块押金全得赔进去！”

“我这一百六十斤踩你肩膀上，孔雀没抓着，先把你腰踩折了算工伤啊？”王建国把竹耙子往墙根一靠，四下看了看，拖过两个绿色的塑料垃圾桶倒扣过来，踩着桶底晃晃悠悠地站上去。

李卫东在底下死死扶住王建国的大腿，仰着脖子小声指挥：“慢点，对，从侧后方包抄，讲究策略，别激化矛盾……”

王建国举着麻袋撑开袋口，离孔雀屁股不到半米远。一楼后厨的铁皮门“哐当”一声从里面撞开，一个穿粉色技师服、披着羽绒服的女人端着盆洗脚水出来，嘴里骂骂咧咧：“这三号房的胖子，脚底板太硬，搓得老娘手腕子疼……”

哗啦一声，热气腾腾的洗脚水泼在结冰的路面上。

空调外机上的蓝孔雀受了惊，脖子猛地伸长，发出一声极其凄厉、酷似拖拉机摇把子打滑的“嘎——”声。

那个女技师吓得一哆嗦，盆都扔了，抬头看见红光里有个长尾巴怪物扑腾着翅膀跳下来，旁边垃圾桶上还站着个老头举着麻袋，当场就要尖叫。

李卫东眼疾手快，一个箭步冲上去，在女人叫出声之前，把自己的工作证啪地拍在女人脸前，压低声音严肃喝道：“别喊！县委迎检办联合畜牧局搞夜间突发疫情演练！涉密工作，不许拍照，不许外传！赶紧回屋去！”

女技师被这阵势唬住了，愣愣地看着那个工作证，又看看扑腾着翅膀、迈着两条大长腿在潲水沟里狂奔的蓝孔雀，咽了口唾沫，捡起盆转身就跑，铁门摔得震天响。

“还愣着干啥！追啊！”王建国从垃圾桶上跳下来，脚底下一滑，差点劈了个叉。

蓝孔雀飞不高，但跑得飞快。它拖着那身五千块的尾羽，在窄巷子里左冲右突，溅起一路黑泥水。李卫东和王建国在后面玩命追，军大衣下摆甩得啪啪响。

追出后巷，前面是拆迁了一半的向阳路夜市。这个点，整条街只有老马家的“二十四小时全羊汤馆”还亮着灯。店门口支着口大铁锅，炉火烧得通红，白色的羊汤蒸汽直往房檐上蹿，肉香味顺着北风飘出老远。

那只蓝孔雀跑到这里，闻着那股热乎气，猛地停住，收拢翅膀，迈着方步大摇大摆地往羊汤锅旁边凑过去。

门口剁羊骨头的老马正打着哈欠，手里的砍骨刀举在半空，低头一看，一只浑身发蓝、拖着长尾巴的大鸟正凑在他的煤球炉子跟前烤火，还顺嘴啄了一口案板底下掉的碎羊油。

老马揉了揉眼睛，把砍骨刀往案板上一剁，冲屋里喊：“媳妇！快出来看！咱们家炉子成精了，招来只凤凰！”

屋里正在喝夜酒的三个纹身小青年闻声晃晃悠悠地站起来，隔着玻璃窗往外看，其中一个掏出手机就要开门：“卧槽，孔雀？这大冷天的哪来的野味？马哥，借你锅炖了，我出二百块钱加工费！”

不远处的电线杆子后面，李卫东吓得魂飞魄散。这要是让这帮喝高了的社会青年拍成短视频发到抖音上，配个“高阳县街头惊现孔雀”的标题，明天省暗访组一看手机，连湿地公园都不用去了，直接就能判定高阳县搞形式主义、弄虚作假！

“不能让他们拍！更不能让他们炖了！”李卫东从牙缝里挤出这句话，一把拽过王建国，“王叔，上！拿出咱们基层执法的气势来！”

两人从阴影里冲出来。那个拿手机的小青年刚推开门，李卫东已经一个滑步挡在了孔雀和镜头之间，背着手，挺起肚子，清了清嗓子：“把手机收起来！谁让你们拍的？”

小青年愣了一下，借着酒劲上下打量李卫东：“你谁啊？这鸟你家养的？”

“这不叫鸟，这叫实验样本！”李卫东面不改色，大脑以前所未有的速度运转，把这几年写材料背过的公文词汇全调动了起来，“这是省农科院跟咱们县联合培育的‘高寒抗病型观赏火鸡’，身上带有三种未查明的寄生虫和新型禽流感毒株！今天晚上做抗寒测试跑出来的。你们几个，刚才谁凑到它三步以内了？来，把身份证号报一下，明天一早去县传染病医院拉走隔离十四天！”

这话一出，空气瞬间凝固了。

老马手里的砍骨刀哐当掉在地上，吓得一哆嗦往后退了两步，拿围裙死命擦手：“领……领导，我可没碰它啊，它自己过来烤火的！我这锅羊汤刚熬好，可没掉毛进去！”

那三个小青年酒醒了一半，看看地上那只正歪着头打量他们的蓝孔雀，又看看李卫东身后拿着大竹耙子、一脸凶相的王建国，哪还敢拍视频，收起手机骂了句晦气，推门钻回屋里，把玻璃门从里面反锁上了。

“老马，把你门口这灯关两分钟，配合一下防疫工作。”李卫东背着手下达指令。

老马连滚带爬地进屋拉了电闸。

周围黑了下来，只有煤球炉子透出点暗红的光。王建国对李卫东竖起大拇指：“李科长，怪不得你能写材料呢，这瞎话编得跟红头文件没两样。”

“少废话，赶紧套！”

两人趁着黑，一左一右包抄过去。谁知那孔雀烤火烤舒坦了，警觉性极高，见黑影扑过来，翅膀一扇，带起一阵炉灰，直接蹿上了老马店门口的三轮车顶棚，紧接着借力一跃，飞过了马路，一头扎进了对面的“阳光生态新城”烂尾楼工地里。

李卫东吃了一嘴煤灰，呸呸吐了两口：“这畜生怎么专挑有‘生态’俩字的地方钻？那烂尾楼停工三年了，里头全是钢筋头子！”

凌晨三点半，是一夜里最冷的时候。

烂尾楼工地四周的铁皮围挡早让人偷卖得差不多了，只剩几块印着“打造宜居生态新标杆”的破布在风里呼啦啦响。为了应付明天的检查，县里前天刚雇人拿绿色防尘网把工地外立面遮了一层，远远看着一片绿。

李卫东和王建国深一脚浅一脚地在冻硬的泥坑里摸索。李卫东的皮鞋裹满泥浆，脚趾头冻得生疼。

“王叔，你说咱们图啥呢？”李卫东喘着粗气，手电筒的光已经有些发黄了，“省里那些专家，坐着考斯特中巴车，隔着玻璃往外看一眼，最多停留三分钟。为了这三分钟，咱们局里提前半个月就开始往枯树上绑塑料树叶，往臭水沟里倒净水剂。现在可好，半夜三更跟一只鸟在这儿打游击。”

王建国走在前面，用竹耙子探着路，防止掉进没盖板的窨井里：“图啥？你图你那张正式调令，我图我那三千块钱的死工资。人家省里领导也图个好看的报告，张主任图个提拔。大家都图点啥，最后就得苦了这只鸟，大冬天的不在暖气房里待着，非得拉出来充门面。”

正说着，二楼楼梯拐角处响起细碎的刮擦声，听着是硬物划过水泥地面。

两人对视一眼，同时关掉了手电筒。

借着远处主干道透过来的一点微光，他们看见那只蓝孔雀正卡在二楼半截没有护栏的平台上。那个平台原本是设计用来放中央空调机组的，三面是墙，只有一面朝外。孔雀长长的尾羽被两根生锈的螺纹钢筋夹住了，它正使劲往前挣扎，但越挣扎，钢筋咬得越紧。

“天助我也！”李卫东喜出望外，“瓮中捉鳖！王叔，这次听我口令，咱们搞个协同作战。我数一二三，你用耙子按住它脖子，我拿麻袋从屁股往脑袋套，千万别伤着毛！”

两人猫着腰，顺着没有扶手的水泥楼梯摸了上去。

离孔雀还有两步远的时候，李卫东伸出三根手指，在黑暗中比划：一、二、三！

王建国手里的竹耙子猛地拍下去，但他年纪大了，熬到后半夜眼花，这一下没按住孔雀的脖子，直接拍在了孔雀面前的砖头上，“啪”的一声脆响。

孔雀受到了极度的惊吓，求生本能彻底爆发。它根本不管屁股后面夹着的钢筋，双腿猛地一蹬水泥地，硬生生往外蹿了出去。

李卫东的麻袋正好在这时候扑空，整个人趴在地上。他眼睁睁地看着孔雀飞向半空，紧接着，为了防止孔雀掉下二楼摔死，跟在后面的王建国本能地伸出那只穿着开口劳保鞋的大脚，一脚踩在了孔雀还没完全抽出来的长尾巴上。

“刺啦——”

刺啦一声脆响，厚实的布料被生生扯裂，动静在空旷的烂尾楼里回荡。

孔雀惨叫一声，腾空而起，没了尾羽的平衡，歪歪斜斜地砸在一楼的沙堆上。李卫东连滚带爬冲下楼，趁孔雀摔懵了，拿麻袋把它死死罩住，整个人压了上去。

“抓住了！抓住了！”李卫东趴在麻袋上大口喘气，感觉怀里的孔雀还在突突直跳。

二楼平台上，王建国慢慢蹲下身，把脚挪开。他弯腰从钢筋缝里和自己的鞋底板下，捡起了一大把蓝绿相间、带着漂亮眼状斑纹的长羽毛。

他数了数。一共九根。

王建国拿着这九根羽毛走下楼，递到李卫东面前：“李科长，鸟是活捉了。就是这押金，怕是得扣一千八。”

李卫东打开手电筒，看着王建国手里那把华丽的羽毛，又摸了摸麻袋里明显小了一圈的孔雀屁股，一屁股坐在冰冷的沙堆上，半天没说出话来。

凌晨五点半，天边泛起一层灰白色。

湿地公园的管理房里，一盏落满灰尘的老旧灯泡亮着昏黄的光。

公孔雀被捆着两条腿，歪在办公桌底下。它原本拖地的华丽尾屏早没了影，屁股后头只挂着寥寥几根长毛，其余地方光秃秃地露着灰白底绒，跟菜市场刚拔完毛、随时准备下锅的乌骨鸡没什么两样。

李卫东坐在办公桌前，面前摆着那九根断掉的羽毛，还有他刚从巷口早点铺顺道买回来的五管“502”强力胶水。

“李科长，这能行吗？”王建国端着个搪瓷缸子，喝了一口刚烧开的沫子茶，“这胶水粘鞋底子还行，粘鸟毛，它能立得住？”

“立不住也得立！”李卫东眼睛熬得通红，手里拿把美工刀，正把断羽毛根部的软管削平，“现在去邻市调换来不及了。省里的车队八点准时到，他们不去一号笼子跟前，就在老远的观景台上拿望远镜扫一圈。只要这九根毛能挂在它屁股上撑过今天上午十点，咱们就算胜利完成任务！”

“那万一它开屏呢？一抖搂，毛全飞了，那场面可就壮观了。”

“所以不能让它开屏，不仅不能开屏，还得让它背对着观景台，一动不动！”李卫东咬开一管502胶水，眼神里透着一股绝望的狠劲，“王叔，过来按住它！把那三根没断的毛当承重梁，把这九根用胶水交叉粘在承重梁上！这就叫框架结构，懂不懂？”

王建国叹了口气，放下茶缸，蹲下身死死按住孔雀的翅膀。

接下来的一个小时里，管理房里充满了502胶水刺鼻的化学气味和孔雀低沉的咕噜声。李卫东拿出当年高考涂答题卡的精细劲儿，一根接一根地把羽毛粘回孔雀的尾端。他的手指头上粘满了胶水，好几次把自己的大拇指和食指粘在了一起，又生生撕开，带下一层白皮。

六点五十，天大亮了。

最后加工完成的蓝孔雀被重新放回了一号点位的塑料绿网里。为了防止它乱动把胶水崩开，王建国找了一根透明的钓鱼线，一头系在孔雀的两条腿上，另一头绑在草坪底下的水泥砖上，拉得死死的。孔雀的胸脯前面还用两根削尖的竹签子插在土里顶着，强迫它保持着一种昂首挺胸、背对观景台、面朝芦苇荡“眺望远方”的优美姿态。

远远看去，那九根用502粘上去的尾羽在晨霜中微微泛着白光，板板正正，甚至比原来还要整齐划一。

七点半，三辆黑色的帕萨特率先驶入湿地公园停车场。

迎检办张主任穿着一身笔挺的黑色呢子大衣，头发梳得油光水滑，快步走到一号观景台前。李卫东和王建国早就在路边站好了，两人都换下了沾满泥水的裤子，穿上了干净的绿马甲，手里拿着扫帚，扮演着辛勤的园区保洁员。

张主任举起望远镜，对准远处的芦苇荡仔细端详。

镜头里，绿油油的喷漆草坪上，公孔雀拖着华丽的尾羽，一动不动地凝望着冰封的水面，显得极为深沉、极其生态；母孔雀蹲在旁边吃玉米粒。

“不错。”张主任放下望远镜，满意地点了点头，走到李卫东身边，拍了拍他的肩膀，“小李啊，昨晚辛苦了。你看这孔雀，精神面貌多好，姿态多稳重！这就叫人与自然和谐共生。等这波迎检过去，你的调动手续，我亲自找编办主任去签。”

李卫东立正站好，被502胶水粘掉皮的手指头在裤缝边死死抠着：“不辛苦！都是张主任前期部署到位，我们就是落实了一下具体细节。”

快到八点的时候，警灯闪烁，两辆丰田考斯特中巴车平稳地滑进湿地公园，停在了红地毯前。

车门打开，几个穿着羽绒服、胸前挂着工作牌的省里专家走了下来。张主任立刻满脸堆笑地迎了上去，伸出双手：“欢迎省里的各位领导莅临指导！这边请，这就是我们县斥巨资打造的原生态湿地核心区，目前已经吸引了包括蓝孔雀在内的多种珍稀禽类常年栖息……”

一行人簇拥着走上观景台。

李卫东和王建国退到稍远处的柳树底下，屏住呼吸，死死盯着远处那只孔雀的后背。

北风顺着冰面吹过来，带着一股子刺骨的寒意。芦苇荡里，那只被钓鱼线绑住腿的公孔雀冻得实在受不了了，脖子缩了缩，屁股极其轻微地往左边扭了一下。

“啪。”

一声只有孔雀自己能听见的轻响。一根粘在最外侧的尾羽，因为502胶水在零下十度的低温里变脆，从根部直接断裂。

紧接着，一阵旋风刮过。那根足有大半人长、带着漂亮眼状斑纹的蓝绿色羽毛，顺着风势腾空而起，打着旋儿，越飞越高，越过了喷着绿漆的芦苇荡，越过了挂着防尘网的烂尾楼，慢悠悠地朝着观景台上那群正举着相机拍照的领导头顶飘了过去。

王建国眯着眼睛，看着天上那根羽毛，用手肘捅了捅身边的李卫东，小声说：“李科长，两百块钱飞了。待会儿散了场，咱们还去老马家喝羊汤不？”

李卫东仰着脖子，眼珠子随着那根羽毛上下移动，连眨都没眨一下：“喝。叫老马多放点香菜，记迎检办账上。”
