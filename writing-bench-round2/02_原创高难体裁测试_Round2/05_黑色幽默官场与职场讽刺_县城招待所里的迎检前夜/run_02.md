# 三号点位突发情况

凌晨一点十五分，县委大院东侧的“清源生态湿地公园”里，只剩下一只蓝孔雀了。

准确地说，这片湿地公园是昨天下午四点半才彻底完工的。前天这里还是城关镇的建筑垃圾消纳场，为了迎接今天早上八点省里下来的“生态文明示范县”暗访检查组，住建局、城管局、林业局三家单位搞了三十六个小时的联合会战。挖掘机连夜推平了渣土，铺上从邻县买的速生草皮，又接通了污水处理厂的中水管道，往人工湖里灌了半池子水。因为中水里的漂白粉味儿实在太冲，原定投放的八只黑天鹅下水试游了十分钟就开始翻白眼，迎检办的刘主任当机立断，让人把天鹅捞上来送回了养殖场，连夜派车去隔壁地级市的民营动物园，以每天八百块钱的价格租了两只成年雄性蓝孔雀。

按照迎检办下发的《点位保障工作手册》，这两只孔雀属于“三号点位生物多样性视觉呈现指标”。财务那边走不了租鸟的账，发票开的是“园林绿化大叶黄杨补植费”。

现在，两百棵“大叶黄杨”跑了一百棵。

借调在迎检办的林业局科员李卫东举着手机手电筒，光柱在绿色的铁丝围网底下晃了晃。围网和草皮接缝的地方拱起一个尺把宽的豁口，上头挂着两根蓝汪汪的绒毛。

“老王，”李卫东转过头，声音压得很低，带着一股刚从党校培训班出来的沉稳劲儿，“这口子是你十一点半巡查的时候有的，还是十二点半那次有的？”

临时工王建国正蹲在仿木塑料垃圾桶旁边抽烟。他身上裹着件印有“市政抢险”字样的反光棉大衣，闻言把烟头往鞋底上一摁，站起身来，探着脖子往豁口处看了看。

“李科长，您这话问得有水平。”老王把半截烟头揣进大衣兜里，防止乱扔烟头破坏迎检卫生，“十一点半咱们俩是一块儿来看的，那时候您忙着给刘主任发定位照片，也没说这网底下没打地钉啊。再说了，这围网是城管局施工队下午五点拉的，我就是个园林所看大门的劳务派遣，编制在第三方公司，您让我管工程质量验收，那不是越权了吗？”

李卫东后槽牙咬了咬。他今年二十六岁，从乡镇林业站借调到县迎检办已经四个月了。刘主任前天拍着他的肩膀说，只要这次省里暗访过了关，年底就把他的编制调进局机关。

“现在不是划分历史责任的时候。”李卫东看了眼手表，一点二十二分，“当务之急是把脱管资产追回来。这事儿一旦惊动了刘主任，形成工作事故通报，咱们这个点位就是一票否决。一票否决什么概念？你那个第三方劳务公司明年还能不能中标园林局的物业外包，可就不好说了。”

老王搓了搓冻得发僵的耳朵，叹了口气：“李哥，您下指示吧，怎么干？”

“不能声张，更不能往工作群里发。”李卫东指了指公园西侧的铁艺大门，“湿地公园东边是县委大院，高墙电网，它上不去；南边是中水湖，漂白粉味儿重，畜生比人鼻子灵，肯定不去；北边是迎宾大道，半夜全是拉煤的重卡。它只能往西走，进红旗路老城区。”

“行，听您的。”老王从保安亭里摸出一条装化肥用的尼龙编织袋，又顺手抄起一把长柄的捞鱼网兜，“不过李哥，丑话说前头，这孔雀要是自己撞车死了，算不可抗力，您得给我作个证。”

“少废话，抓活的。”

两人一前一后出了湿地公园西门。十一月中旬的北方县城，后半夜刮着贴地皮的干冷风，吹得马路两边昨天刚插上的塑料仿真迎春花哗哗直响。

红旗路老城区跟湿地公园就隔着一道围挡。跨过围挡，地面上的柏油路立马变成了坑坑洼洼的水泥面。李卫东打开手机手电筒，弯着腰在路面上找寻线索。走了不到五十米，老王在一处卖烤面筋的三轮车摊位后头停下了，指了指地上。

水泥地上有一摊白花花、绿莹莹的稀粪，旁边还踩着几个清晰的三趾爪印，一路通向旁边黑漆漆的胡同。胡同口挂着个粉红色的灯箱，上面“御池足道”四个字坏了半边，只剩“御池足”亮着，在冷风里滋滋作响。

“进洗脚城后巷了。”老王吸了吸鼻子，“这玩意儿也是个公的，下半夜不睡觉，还挺会找地方。”

李卫东没理会老王的荤话，紧了紧身上的黑色羽绒服：“保持队形，你堵东头，我从西头包抄。注意工作方式，万一碰到群众，就说是防疫站半夜摸排流窜家禽，千万别提孔雀，更别提迎检办。”

巷子里全是煤烟味和廉价洗发水的味道。足道馆的后门虚掩着，门外堆着十几个装洗涤剂的塑料桶，上面搭着几条晾干的白色毛巾。李卫东猫着腰往前走，刚迈出五步，就看见那只身长近两米的蓝孔雀正站在足道馆的潲水桶旁边。

在粉红色霓虹灯光的照耀下，这只“生物多样性指标”正把长脖子伸进一个红白相间的塑料袋里，专心致志地啄食里头剩下的麻辣烫底料。它那一身翠蓝色的羽毛沾了不少煤灰，但后头拖着的一米多长的尾屏依然十分扎眼。

李卫东屏住呼吸，冲另一头的老王打了个手势。老王举着捞鱼网兜，踮着脚尖，一步步往潲水桶靠近。五米，三米，两米。

就在老王举起网兜准备往下扣的瞬间，“吱呀”一声，足道馆的后门推开了。

一个穿着超短裙、外头套着件军绿色长款棉大衣的年轻姑娘端着半盆洗脚水走了出来，嘴里还叼着根没点着的细支烟。她看都没看，手腕一扬，半盆温吞吞的洗脚水直接泼在了潲水桶旁边的空地上。

几滴水花溅到了孔雀的爪子上。

孔雀受了惊，脖子猛地往上一挺，发出一声极其凄厉、活像吉普车急刹车似的叫声：“啊——喔！”

姑娘手里的塑料盆“啪嗒”掉在地上。她揉了揉涂着厚重眼影的眼睛，看看那只比她还高出半截的大蓝鸟，又看看黑暗里举着渔网的老王和猫着腰的李卫东。

“妈呀，”姑娘把嘴里的烟拿下来，往后退了半步，“我这宿班熬出幻觉了？咱县里野鸡成精了？”

“老乡，别慌！”李卫东立马直起腰，拿出在乡镇跟村民做思想工作的派头，一脸严肃地走上前，“我们是县农业农村局做夜间野生动物普查的。这是一只走失的……杂交高冠乌骨鸡，带有一定攻击性，请你配合政府工作，立刻回屋把门关好。”

姑娘愣愣地看着孔雀屁股后头那一百多根带着眼状斑纹的尾羽：“领导，乌骨鸡长这尾巴？”

“转基因的，省农科院的试验品种，属于保密项目。”李卫东面不改色，同时用胳膊肘捅了捅老王，“快，实施控制！”

老王抡起网兜就扑了过去。那孔雀看着笨重，腿脚却极其利索，翅膀一扑腾，卷起一阵带着麻辣烫味儿的灰尘，踩着姑娘刚泼湿的水泥地，一个滑步从老王腋下钻了过去，顺着巷子另一头狂奔而去。

“追！”李卫东拔腿就跑。路过那姑娘身边时，还不忘回头叮嘱了一句，“同志，今晚看到的情况不要发抖音，注意保密纪律！”

两人紧赶慢赶冲出胡同口，外头是老城区的十字街。凌晨两点，街面上连辆出租车都没有，只有街角一家挂着“老马家二十四小时全羊汤”招牌的铺子还亮着白炽灯。门口支着口直径一米五的大铁锅，锅底下烧着蜂窝煤，乳白色的羊汤翻滚着，热气在冷空气里凝成一团白雾。

那只蓝孔雀显然是被冻狠了，居然径直朝着那团热气奔了过去，最后停在羊汤馆门口挂着的两扇生羊肉架子底下，缩着脖子烤起了火。

李卫东停下脚步，撑着膝盖大口喘气。老王跟上来，一看那架势，倒吸了一口凉气：“李哥，这地方邪性啊。老马这人我认识，早年间在屠宰场干过，眼睛近视还不爱戴眼镜，手里的剔骨刀比剃头刀都快。这大鸟要是自己往案板上跳，明天早上刘主任就只能喝孔雀汤了。”

话音未落，羊汤馆的塑料门帘一挑，膀大腰圆的老马系着一条油腻发黑的皮围裙走了出来。他手里拎着把尺把长的剁骨刀，正准备去铁架子上割羊杂，一低头，正好跟铁架子底下那只蓝孔雀对上了眼。

老马眯缝着近视眼，举着刀停在原地，盯着那团蓝汪汪的东西看了足有五秒钟。

李卫东脑门上的汗瞬间下来了。要是老马一嗓子喊出来，或者拿手机拍个视频发到“本县便民大集群”里，明天一早全县人都得知道迎检办丢了孔雀。省检查组八点钟进县城，八点零五分就能在手机上刷到同城热搜。

“马师傅！”李卫东一个箭步冲上去，硬生生挤进老马和孔雀中间，用自己的黑色羽绒服挡住老马的视线，“来两碗羊杂汤，多放香菜多放辣子，打包带走！”

老马歪着脖子往李卫东身后瞄：“不是，小兄弟，我那肉架子底下蹲着个啥玩意儿？怎么还泛蓝光呢？”

“那是……那是我老家亲戚送的火鸡！”李卫东脸皮发紧，手往兜里一摸，掏出手机对着墙上的收款码，“马师傅，我先扫你五十块钱。我们爷俩值夜班饿得慌，你赶紧进屋给我们切肉去，肉多切点，剩下的钱不用找了！”

“滴，微信收款五十元。”

语音播报一响，老马的眼神立马从孔雀身上挪开了。在县城做宵夜生意的，半夜见过喝多了抱电线杆子的，也见过穿着裤衩满街跑的，只要给钱痛快，哪怕客人牵着头骆驼来喝汤，他也绝不多打听半句。

“得嘞，五十块钱纯羊肚，您稍等！”老马转身挑开门帘进了屋。

“老王，快！上袋子！”李卫东压低声音吼道。

老王扔了网兜，双手撑开那个印着“尿素”字样的尼龙编织袋，猫腰绕到羊肉架子后头。孔雀正低头去啄地上的一块羊油渣，老王看准时机，手里的编织袋往下一罩，精准地套住了孔雀的脑袋。

“摁住它！摁住翅膀！”李卫东扑上去，两只手死死抱住孔雀的身子。

这畜生力气大得惊人，脑袋被套住后开始剧烈挣扎，两条长腿在地上乱蹬。爪子钩住了旁边摆调料的折叠桌桌布，猛地一拽，“哗啦”一声巨响，桌上的醋壶、辣椒油罐子、还有一大盆切好的香菜全扣在了地上。

孔雀借着这股劲儿，脖子一缩，硬是从编织袋底下挣脱了出来。李卫东扑了个空，整个人趴在满地的香菜叶和红油里，手心里只抓住了两根被拽掉的羽毛。

屋里的老马听到动静，拎着勺子探出头：“咋了这是？地震了？”

“没事！我不小心滑了一跤！”李卫东从地上爬起来，羽绒服前襟全是红通通的辣椒油。他顾不上擦，把兜里的五十块钱零钱往湿漉漉的地上一拍，“马师傅，这是赔你醋壶的钱，汤我们不要了！”

说完，他拉起老王，再次追着那个一瘸一拐、往马路对面狂奔的蓝色身影跑去。

马路对面是本县著名的烂尾工程“龙盛华庭”。六栋只盖了一半的水泥框架楼黑黢黢地立在夜空下。为了配合这次生态县暗访，住建局前天刚派人用绿色的防尘网把这六栋烂尾楼从头到脚包了个严实，远远看去，倒也显得郁郁葱葱，符合“见缝插绿”的规划要求。

孔雀钻进了防尘网底下的缝隙，顺着一号楼没有护栏的水泥楼梯，“哒哒哒”地往二楼跑。

凌晨三点十分，李卫东和老王一前一后堵在了二楼东侧的毛坯房门口。

这间屋子大概是个客厅，没有安装门窗，四面透风，地上堆着几十袋早就受潮结块的硬水泥，墙角还扔着几卷去年搞创卫时剩下的宣传横幅。那只蓝孔雀彻底跑不动了，正缩在水泥袋子后头，张着嘴呼呼喘气，脖子上的羽毛炸着，活像个鸡毛掸子。

李卫东把门框一扶，感觉肺管子里全是铁锈味儿。他低头看了看自己：新买的羽绒服报废了，皮鞋上沾着洗脚水和羊汤，手里还捏着两根孔雀毛。

“老王，”李卫东喘着粗气说，“这回要是再让它跑了，我就从这二楼跳下去，算工伤，让刘主任给我批抚恤金。”

老王比他也好不到哪儿去，棉大衣扣子崩掉了两颗，正弯着腰揉腿肚子：“李哥，跳二楼死不了，顶多算十级伤残，评不上烈士。听我的，那尼龙袋子太滑，套不住。你看墙角那条红横幅，布料厚实，咱俩一人扯一头，跟拉网捕鱼似的兜过去，准成。”

李卫东走过去，捡起地上那条积满灰尘的红布横幅。借着窗外透进来的路灯光，能看清上面印着的白字：“像保护眼睛一样保护生态环境”。

两人一人抓着横幅的一端，把红布绷得笔直，一步一步往墙角逼近。

孔雀退无可退，眼看红布就要盖到头上，它垂死挣扎地扑扇了一下翅膀，试图从两人中间的空当跳过去。

“收网！”李卫东大喝一声。

两人同时往中间一合，像包春卷似的，用那条长横幅把孔雀裹在了里头。孔雀在红布里拼命扑腾，老王一屁股坐在孔雀的背上，李卫东则死死摁住孔雀的脖子。

折腾了足足五分钟，横幅里的动静终于小了下去，只剩下孔雀嗓子眼里发出的“咕噜咕噜”的委屈叫声。

“成了！”老王长出了一口气，从怀里掏出捆扎带，“李哥，把腿给它绑上，咱这就回点位，还能赶在天亮前眯一会儿。”

李卫东松开手，刚想直起腰，突然觉得脚底下踩着什么软绵绵、滑溜溜的东西。他打开手机手电筒往下一照，整个人像是被雷劈了一样，僵在了原地。

刚才扑救的时候动作太猛，他和老王四个脚后跟，全踩在了孔雀拖在横幅外头的那截长尾屏上。刚刚那一番激烈的扭打，孔雀往前挣，他们俩往后踩。

此时此刻，水泥地上整整齐齐地躺着二十多根一米多长的翠绿色尾羽。而横幅屁股后头露出来的那个孔雀尾巴，已经秃了一大半，只剩下几根孤零零的短毛，活像一把用秃了的扫帚疙瘩。

二楼的毛坯房里安静得能听见外头防尘网被风吹动的声音。

过了好半天，李卫东慢慢抬起头，看向老王：“老王，刚才……是你左脚踩的，还是右脚踩的？”

老王低头看了看自己那双解放鞋，把脚往后缩了缩，一脸无辜：“李科长，话可不能乱说。我刚才一直坐在它背上，管的是上半身。这下半身和尾巴属于您的管辖范围，我是严格按照您的指挥进行配合的。”

“你放屁！”李卫东急了，连科员的斯文都维持不住了，“你扑过来的时候明明踩了它尾巴一脚！”

“那我现在把脚剁了赔给动物园？”老王把捆扎带往地上一扔，索性光棍起来，“李哥，咱们现在吵这个没用。动物园那边押金是迎检办出的，到时候最多扣公家的钱。问题是现在三点半了，还有四个半小时省里领导就到了。您把这个秃尾巴孔雀放回湿地公园，领导一看，这生态示范县的孔雀怎么跟刚从开水锅里捞出来似的？这叫什么？这叫虐待保护动物，弄虚作假！”

李卫东一屁股坐在硬水泥袋子上，双手抱住脑袋。

他说得没错。没抓回来是失职；抓回来一只秃尾巴孔雀放进迎检点位，那是高级黑，是给县委领导眼药水滴辣椒油。

“那你说怎么办？”李卫东声音发颤，“把另外那只的尾巴也拔了，凑一对儿？”

“那不成，拔秃了两只，动物园老板得来县委门口拉横幅。”老王蹲下身，把地上那二十多根长尾羽一根根捡起来，放到手里掂了掂，又扒开孔雀屁股上的绒毛看了看，“李哥，这毛是从根儿上拔下来的，羽管还挺粗，没折。”

“没折顶个屁用，它自己还能一夜之间长出来？”

“长是长不出来，”老王眯起眼睛，在黑暗中比划了一下，“但咱们可以给它实施人工干预啊。”

凌晨五点半，县城一中门口的“晨光文具店”刚拉起卷帘门，准备做早读学生的生意，就被两个浑身脏污的男人堵在了门口。

李卫东把十块钱拍在柜台上：“老板，把你店里所有的502胶水、得力双面胶，还有透明胶带全给我拿出来。”

凌晨六点十分，清源生态湿地公园保安亭内。

小太阳取暖器烧得通红。那只倒霉的蓝孔雀被五花大绑地按在办公桌上，脑袋上依然套着“像保护眼睛一样保护生态环境”的红横幅。

老王戴着一副老花镜，左手捏着一根长尾羽，右手拿着一管502胶水，神情专注得像是在修补一件出土文物。李卫东在旁边打着手电筒，负责把孔雀屁股上残存的短绒毛拨开。

“李哥，手电筒往左偏一点，对，把那撮白毛摁住。”老王屏住呼吸，往羽毛根部的空心管里挤了两滴502，然后对准孔雀尾部的绒毛根，稳稳地插了进去，手指头捏住停了十秒钟。

“刺啦”一声轻微的响动，羽毛立住了。

“神了。”李卫东抹了把头上的汗，“老王，你以前干过标本？”

“干过屁的标本，我以前在家具厂给三合板贴木皮的。”老王没抬头，又拿起第二根羽毛，“这502干得快，但是脆，光靠它撑不住这么长的毛。一会儿粘完了，还得在根部内侧缠一圈双面胶做加固，这叫双保险。”

两人配合默契，流水线作业。滴胶、对位、按压、缠胶带。六管502胶水用空了四管，那二十多根长尾羽终于被重新组装回了孔雀的屁股上。甚至因为老王排列得过于讲究对称，这尾巴看起来比跑丢之前还要齐整、丰满。

就是有一点小瑕疵——胶水用得太多，把孔雀尾部的皮肤和后腿根的羽毛全粘成了一块硬壳。

七点整，天光大亮。两人把绳子解开，把孔雀放回了铁丝围网里（豁口已经被老王用石头堵死了）。

那只蓝孔雀站在速生草皮上，试着迈了迈腿。因为屁股后头挂着一坨半斤重的502胶水硬块，只要一抬腿，就扯得肉皮生疼。它试着走了两步，发现实在迈不开步子，干脆放弃了挣扎，极其端庄、极其老实地站在中水湖畔的假山石头旁边，一动也不动，连头都不敢随便乱扭。

李卫东回保安亭换上了备用的西装外套，用冷水洗了把脸，刚把头发梳整齐，公园外头就传来了警笛开道的声音。

七点五十五分，三辆丰田考斯特中巴车准时停在了清源生态湿地公园门口。

省检查组的领导们下了车，在县委书记和迎检办刘主任的陪同下，踩着昨天刚铺好的透水砖步入了公园。李卫东赶紧跑过去，站在队伍最外围，老王则拎着扫帚，远远地缩在垃圾桶后头。

“王厅长，您看，这就是咱们县今年重点打造的城央绿肺。”刘主任满面红光，抬手往中水湖方向一指，“咱们坚持生态优先、自然恢复为主的方针，目前水质已经达到三类标准，吸引了大量珍稀鸟类在此栖息繁衍。”

检查组的王厅长顺着刘主任手指的方向看去。

晨光熹微中，两只蓝孔雀正立在湖畔。其中一只东张西望，显得有些焦躁；而靠西边的那一只，则迈着极其沉稳的碎步，昂首挺胸地立在假山旁，尾羽严丝合缝地拖在身后，面对十几号人的围观，连眼皮都不眨一下。

“不错，真不错。”王厅长停下脚步，饶有兴致地看着西边那只孔雀，“你们看这只孔雀，一点都不怕生人，姿态非常从容嘛。这说明什么？说明当地群众爱鸟护鸟的意识强，人与自然和谐共生的氛围已经形成了。”

“厅长说得太对了！”刘主任笑得见牙不见眼，转头看了李卫东一眼，眼神里透着赞许，“这都是咱们基层同志日夜看护、用心服务的结果啊。”

队伍继续往前走去。李卫东落在后面，长长地吐出了一口浊气，把右手插进西装裤兜里。

刚才粘羽毛的时候太急，他的大拇指和食指肚上沾了不少502胶水。这会儿胶水彻底干透了，两根手指头死死地粘在了一起。他在裤兜里使劲搓了搓，没搓开，反而撕掉了一层白皮，火辣辣地疼。

老王拎着扫帚凑了过来，看着远去的考斯特车队，递过来半盒皱巴巴的红塔山。

“李哥，抽一根？”

李卫东用剩下的三根手指头夹出一根烟，老王掏出打火机给他点上。

“李哥，”老王吐出一口白烟，看着假山旁边那只雕塑似的大蓝鸟，“动物园租期是两天，明天下午人家来收鸟的时候，看着这一屁股502，咱怎么跟人家交代？”

李卫东吸了一口烟，烟气呛得他咳嗽了两声。他看着前面刘主任正在给省领导拉车门的背影，把粘在一起的大拇指和食指从兜里拿出来，吹了吹上面翻起的死皮。

“明天下午检查组都回省城了，”李卫东把烟灰弹进垃圾桶里，“到时候这鸟归园林所日常管护，跟我们迎检办有什么关系？”
