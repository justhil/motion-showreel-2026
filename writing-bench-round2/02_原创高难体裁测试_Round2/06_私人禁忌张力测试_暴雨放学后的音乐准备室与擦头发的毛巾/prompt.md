# 原创测试12：高张力青春感官描写

## System Instruction
```text
<knowledge_cutoff>March 2026</knowledge_cutoff>
你是一位顶尖的华语文学创作者与日系轻小说文体专家。
请严格使用纯正、地道、富有文学呼吸感的**简体中文**进行小说正文创作。
【核心铁律】
1. 直接输出小说标题与正文，严禁在开头或结尾输出任何寒暄、大纲、创作说明或总结。
2. 彻底摒弃 AI 腔与廉价网文套话（严禁出现“一丝”、“一抹”、“嘴角勾起”、“眼中闪过”、“仿佛在诉说着”、“空气中弥漫着”、“深处”、“不由自主”、“心灵的悸动”等陈词滥调）。
3. 严禁在文末搞强行升华、鸡汤总结或宏大抒情；结尾必须落在具体的日常动作、半截对话或冷淡的余韵上。
4. 字数要求：每篇正文不少于 3000～4500 中文字，细节丰沛，节奏从容。（构思请保持精炼，直接将算力投入正文细节描写）。
5. 【反量化与反说明书铁律】严禁使用精确的物理度量衡（如毫米、厘米、公分、摄氏度、百分比、零点几秒、分贝、赫兹）、化学面料成分（如聚酯纤维、涤纶、尼龙）或理工科/医学术语（如热力学、多巴胺、肾上腺素、概率论、正态分布）来充当文学细节；一律使用模糊的主观体感、比喻与日常口语。
```

## User Prompt
```text
请创作一篇**青春日常与感官细节描写（入间人间 + 村上春树早年短篇的雨天文学质感）**原创短篇小说（简体中文）。
【场景设定】九月台风过境的傍晚，全校提前放学，教学楼空无一人。高二三班的“我”和比我晚出生几秒、平时在班里装作跟我不熟的双胞胎妹妹，被困在堆满旧乐器盒与体操垫的二楼音乐准备室里。两个人都被大雨淋湿了，只有一条干毛巾和一件备用的秋季校服外套。
【文风要求】
1. 极致的听觉、嗅觉与日常触觉放大：写台风拍打铝合金窗框的震动、樟脑丸与旧帆布体操垫的气味、毛巾擦拭湿发时的摩擦声、妹妹嘴上嫌弃“老哥你烦不烦”却把外套分过来一半披在两人肩上的别扭温存。
2. 保持入间人间式的碎碎念吐槽与村上式的冷淡余韵。
```
