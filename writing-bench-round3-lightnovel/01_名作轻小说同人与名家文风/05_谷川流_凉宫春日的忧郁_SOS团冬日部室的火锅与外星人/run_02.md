# 热力学第二定律的叹息

如果十九世纪的德国物理学家克劳修斯先生泉下有知，看到我们北高文艺部活动室里正在发生的景象，大概会气得从棺材里跳出来，把那条著名的热力学第二定律塞进某个女人的嘴里吧。

按照物理课本上的说法，热量总是自发地从高温物体流向低温物体，绝不可能反过来而不引起其他变化。说得通俗一点，就是十二月中旬的早晨，当你把脚从温暖的被窝里伸出来的那一刻，全宇宙的恶意都会化作冰冷的空气，贪婪地抽走你身上那点可怜的卡路里。至于熵增定律什么的我就不懂了，反正我的直观感受是，只要到了冬天，人类这种恒温动物就应该像狗熊一样缩在洞里冬眠，而不是顶着能把鼻毛冻硬的寒风，气喘吁吁地爬上北高前面那道堪称魔鬼训练营的漫长坡道。

然而，世界上总有那么一两个例外，完全无视物理法则与生物本能，在气温跌破十摄氏度的严冬里依然散发着过剩的卡路里。

更不幸的是，我认识的那个例外，正好是我的同班同学，兼某个莫名其妙社团的团长。

最后一节课的下课铃声刚响过半秒，原本趴在桌上处于假死状态的我还在思考宇宙的终极热寂问题，坐在我身后的凉宫春日就已经像装了弹射座椅一样蹿了起来。等我慢吞吞地收拾好书包，拖着灌了铅似的双腿走到旧馆三楼尽头，拧开那扇冰凉的黄铜门把手时，迎接我的并不是往常那种好歹能挡挡风的室内温室，而是一阵迎面扑来的西伯利亚寒流。

我差点以为自己推开了通往纳尼亚传奇里那个雪之女王老家的衣柜。

“唔哇，好冷！”

我条件反射地缩起脖子，把下巴埋进围巾里，眯起眼睛打量着活动室内的惨状。

朝南的那扇铝合金窗子被推开了整整一半，十二月中旬的凛冽北风正毫无阻挡地灌进这间狭小的屋子，把窗帘吹得像海盗船上的破帆一样猎猎作响。而在活动室正中央的地板上，赫然摆着一台极其眼熟、但绝对不属于二十一世纪的古董家电。

那是一台方方正正的旧式双管石英电热炉。原本应该是薄荷绿的铁皮外壳已经锈迹斑斑，好几处地方掉了漆，露出底下暗褐色的铁胎；前面的金属防护网凹陷了一大块，像是曾经被什么大型犬类一脚踹翻过；底下还垫着两本过期的少年周刊，用来垫平它那少了一个橡胶脚垫的残缺底座。

而把这玩意儿弄进来的始作俑者，此刻正双手叉腰站在窗边，任由寒风吹拂着她那头黑色长发和手臂上鲜红的“团长”袖章，脸上挂着一副哥伦布刚发现新大陆时的傲慢表情。

“阿虚！你迟到了两分半钟！”春日转过头，食指像枪管一样直戳我的鼻梁，“作为迟到的惩罚，待会儿的极地越冬模拟训练，你的口粮配给减半！”

“在讨论口粮之前，能不能先解释一下为什么大冬天的要把窗户打开？”我一边随手把门关上，一边把书包扔在长桌上，“你是打算把这间活动室改造成天然冷库，用来走私北海道的冻螃蟹吗？”

“哼，真是缺乏危机意识的发言呢，阿虚。”春日双手抱胸，用一种看草履虫般的怜悯眼神看着我，“听好了，从今天放学后开始，SOS团正式进入‘冬季耐寒模拟训练’阶段！你想想看，万一明天外星人突然在地球轨道上展开巨型遮阳伞，或者我们一不小心掉进了通往冰河世纪的时空裂缝，甚至是被神秘组织流放到西伯利亚的冻土带，平时温室里长大的现代人肯定撑不过三天就会全灭！为了不在那种紧急事态下拖后腿，我们必须从现在开始锤炼肉体和精神的抗寒极限！”

我叹了口气，呼出的白气在半空中打了个旋儿，瞬间被穿堂风吹散了。

“既然是耐寒训练，那地板上那台像是从昭和年代的垃圾堆里刨出来的电热炉又是怎么回事？我怎么看它都像是用来取暖的吧。”

“那可不是普通的取暖器！”春日啪地打了个响指，得意洋洋地踩了踩电热炉旁边的地板，“那是暴风雪山庄或者南极科考站里的‘生命之火’！你想啊，不管是阿蒙森还是斯科特，在冲击南极点的时候，帐篷里总得有个煤油炉吧？要是没有那种‘明明有火源却依然冷得要命’的绝境感，模拟训练就缺乏真实性了！这可是我刚才去校舍后面的旧仓库里翻了半个小时，跟管理大爷软磨硬泡才借来的战利品！”

我敢打赌，她所谓的“软磨硬泡”，绝对包含了不少可以写进刑法胁迫罪条例里的言行。再说了，拿英国人斯科特举例实在太不吉利了，那位老兄最后可是全员冻死在南极冰原上的啊。

“呜……那个，凉宫同学，水、水好像烧开了……”

从活动室里侧的茶水柜旁，传来了朝比奈学姐带着哭腔的微弱声音。

我转过头看去，只见我们SOS团的吉祥物兼专属女仆，正穿着那套万年不变的黑白女仆装——万幸的是，今天春日总算发了点善心，允许她在外面套了一件米白色的厚毛衣开衫——缩着肩膀站在电水壶前。因为冻得手指发僵，朝比奈学姐在捏起铝制茶叶罐的盖子时手一滑，盖子当啷一声掉在托盘上，吓得她整个人像受惊的仓鼠一样跳了一下。

“我来吧，朝比奈学姐。”我连忙走过去，从她手里接过茶叶罐，“您去桌子那边坐着就好，这里正好在风口上。”

“谢、谢谢你，阿虚同学……”朝比奈学姐双手捧着自己冻得通红的耳朵，感激地仰头看着我，眼眶里似乎已经有生理性的泪水在打转了，“今天……真的好冷呢。我的手指好像都不听使唤了……”

看着被寒风吹得直哆嗦的朝比奈学姐，我心里的义愤顿时达到了顶点。要是因为这种愚蠢的耐寒训练导致学姐患上重感冒，我绝对饶不了春日。

至于房间里的另外两位团员——

我一边往茶壶里舀着煎茶茶叶，一边用眼角的余光扫视了一圈。

古泉一树正端端正正地坐在长桌旁，身上穿着整洁的冬季制服，脖子上甚至还围着一条看起来就很贵的深灰色羊绒围巾。即便身处这堪比山顶洞人遗址的低温环境里，这家伙脸上依然挂着那副仿佛用强力胶粘上去的人畜无害的微笑。察觉到我的视线，他甚至还余裕十足地冲我点了点头。

而在距离窗户最远的那个角落里，长门有希正一如既往地坐在折叠椅上。

她身上只穿着标准的北高女生冬季水手服，连件毛衣都没加。灌进屋里的冷风吹起她额前短短的刘海，也把她膝盖上那本厚得像砖头一样的精装书吹得哗啦啦直响。但长门连眉毛都没动一下，只是用纤细白皙的食指按住书页边缘，保持着每分钟翻一页的精确频率，整个人安静得就像博物馆里的石膏像。

“好！既然全员到齐了，那就点火吧！”

春日完全无视了室内冰火两重天的诡异气氛，抓起电热炉后面那根黑乎乎、表面还缠着两圈绝缘胶带的电源线，大步流星地走到墙角，啪地一下插进了插座里。

紧接着，她弯下腰，握住电热炉侧面那个塑料旋钮，用力一拧。

咔哒。

伴随着一声令人牙酸的机械摩擦声，电热炉里传出了一阵极其微弱的“嗡嗡”声。

我和古泉、朝比奈学姐同时屏住呼吸，盯着那个凹陷的金属防护网。

三秒钟后，上下两根石英管里，位于下方的那一根开始慢吞吞地泛起暗红色的光芒，就像快要咽气的萤火虫；而上方的那一根则彻底保持着沉默，黑漆漆的一片，显然里面的电阻丝早在泡沫经济破裂那会儿就已经寿终正寝了。

不仅如此，随着那一根独苗石英管温度升高，屋子里顿时飘起了一股陈年灰尘混合着铁锈被烤焦的古怪气味。

“……喂，春日。”我端着放好茶杯的托盘走过来，低头看着这台半身不遂的电器，“上面那根管子根本没亮啊。而且这玩意儿该不会漏电或者爆炸吧？”

“啰嗦！只要有一根能亮，就说明它的灵魂还没熄灭！”春日不服气地拍了拍电热炉的铁皮顶盖，结果拍起了一小团灰尘，呛得她自己咳了两声，“这叫节能模式！在极地探险的时候，燃料可是要省着用的！来，大家都围过来，体验一下在暴风雪中依靠微弱火源求生的悲壮感！”

真是够了。为什么要放着好好的燃气暖炉不用，非要在这个破电热炉前演一出《卖火柴的小女孩》的真人版啊？

不过，违抗团长的命令只会招来更可怕的灾难——比如她可能会一气之下把剩下的那扇窗户也卸下来。我只好认命地叹了口气，把托盘放在桌上，给每个人分了一杯滚烫的绿茶，然后拉开椅子，在古泉旁边坐了下来。

“来，朝比奈学姐，趁热喝吧。”

“哇啊，太感谢了……”朝比奈学姐像抱住救命稻草一样，双手紧紧捧着没有把手的粗陶茶杯，小口小口地吹着热气，脸上总算恢复了一点血色。

我把脚伸到桌子底下，试图从那台半死不活的电热炉那里汲取一点热量。遗憾的是，那根发红的石英管散发出的热辐射，在距离它三十厘米以外的地方就已经被窗外灌进来的寒风彻底抵消了。我的小腿正面稍微有点温乎气，小腿肚却冷得像贴着冰块，这种违背人体工学的受热方式让人浑身难受。

“真是别有一番风味的体验呢。”

旁边的古泉捧着茶杯，笑眯眯地用只有我能听见的音量搭话。

“如果你是指这种脚趾头快要冻掉、鼻腔里全是烤灰尘味的体验，那我宁可不要。”我没好气地白了他一眼，“你也别光顾着笑啊，赶紧想个办法劝劝她把窗户关上。”

“这恐怕很难办到。”古泉苦笑着耸了耸肩，优雅地抿了一口茶，“毕竟凉宫同学现在兴致很高。而且在我看来，这种程度的‘严酷环境模拟’已经算是非常温和的消遣了。”

又来了。每当古泉摆出这副高深莫测的哲学家表情时，准没好话。

“此话怎讲？”我压低声音问。

“这只是我个人的推测，”古泉把茶杯放回桌面，手指轻轻摩挲着杯沿，目光越过袅袅升起的水蒸气，看向正蹲在地上研究电热炉旋钮的春日，“最近这段时间，无论是‘闭锁空间’的产生频率，还是其他超越常理的现象，都处于一个相当平稳的低谷期。从我们‘机关’的角度来看，这当然是求之不得的和平日子；但对于凉宫同学的潜意识而言，过于平淡的日常反而会积累某种焦躁感。”

“你是说，她因为太闲了，所以在没话找话？”

“可以这么理解。如果她觉得‘冬天不够冷，不够刺激’，并且把这种不满积压在心里，说不定明天早上我们醒来的时候，整个城市就会真的被埋在十米深的积雪下面，或者地球的自转轴直接偏转三十度。相比之下，只是打开一扇窗户、点亮一台坏了一半的旧电热炉，就能让她的探索欲得到满足——你不觉得这是一笔非常划算的交易吗？”

我盯着古泉那张写满了“请务必体谅我们辛苦的中间管理层”的俊脸，半晌说不出话来。

合着我在这里吹冷风、闻焦糊味，还成了拯救地球免遭冰河世纪毁灭的壮举了？这种把高中女生的间歇性抽风和世界末日直接挂钩的唯心主义物理学，不管听多少遍都让人觉得荒谬绝伦。

就在我准备回敬古泉两句酸话的时候，一直蹲在地上跟电热炉较劲的春日突然站了起来。

“唔——不行！完全不够味！”

春日双手叉腰，不满地撅起嘴，俯视着围坐在桌旁瑟瑟发抖的我们（当然，长门除外）。

“怎么了，凉宫同学？”古泉立刻切换成营业用的温和表情，“是电热炉的温度不够吗？需要我去总务科借一台新的来吗？”

“正好相反！”春日斩钉截铁地挥了挥手，“就是因为待在屋子里太安逸了，又有热茶喝，又有椅子坐，大家的求生本能根本没有被激发出来！看看你们那副懒散的样子，要是这时候突然有雪怪破窗而入，你们连逃跑的力气都没有！”

要真有雪怪出现在日本的县立高中里，我第一件事绝对不是逃跑，而是把你推出去跟它单挑。我在心里默默吐槽道。

“所以，第一阶段的室内适应性训练到此结束！”春日转身走到窗边，探出半个身子往下看了一眼，然后回过头，眼睛亮得像探照灯，“现在进入第二阶段——野外极地巡逻！我听说只要气温降到一定程度，学校后山或者体育馆背阴处的土里就会长出高达十厘米的霜柱，说不定还能找到冬眠失败而产生变异的奇怪生物！实玖瑠，把热水壶带上当作行军补给！古泉，你负责打头阵！”

“咦？咦咦——？！要、要去外面吗？！”朝比奈学姐捧着茶杯，发出了绝望的悲鸣。

“非常乐意效劳。”古泉倒是爽快地站起身，整理了一下围巾，“那么阿虚同学，你也一起来吧？”

“我就算了。”我把半截身子往椅子里一瘫，指了指脚边那台还在散发着暗红色光芒的古董电热炉，“总得有人留下来看着这玩意儿吧？要是我们全走了，这台连生产厂家都看不清的破炉子突然短路起火，把旧馆烧成白地，学生会那帮家伙绝对会借机把SOS团就地正法的。再说了，这可是团长千辛万苦借来的‘生命之火’，怎么能随便关掉呢？”

我这番有理有据、甚至还顺带拍了一下团长马屁的借口，显然起到了绝佳的效果。

春日摸着下巴思考了两秒，居然深以为然地点了点头：“说得也是！探险队在外出考察的时候，确实需要留一个人在大本营看守火种，防止被北极熊偷袭！好吧，阿虚，大本营的防御任务就交给你了！我和有希……唔，有希也留下来当后援好了！”

她看了一眼角落里雷打不动的长门，大概也知道要把这位沉默的读书家拽去挖霜柱实在是太费劲了，于是非常干脆地抓起朝比奈学姐的手腕。

“走吧，实玖瑠！去寻找冬天的不可思议！”

“呜哇——阿虚同学，救命啊——”

伴随着朝比奈学姐凄惨的呼救声和古泉礼貌的道别声，活动室的门被砰地一声关上了。紧接着，走廊上传来了春日风风火火的脚步声，并很快消失在楼梯口的方向。

世界瞬间安静了下来。

我维持着瘫在椅子上的姿势，等了大概十秒钟，确认那股名为凉宫春日的台风已经彻底远离了这栋建筑后，立刻站起身，三步并作两步地冲到窗边。

哗啦——咔哒！

我毫不犹豫地把那扇大开的铝合金窗户死死拉上，并且顺手拧上了月牙锁。

呼……活过来了。

挡住了外面呼啸的北风，活动室里残存的冷空气虽然还很冻人，但至少不再像刀子一样往骨头缝里钻了。

我搓了搓冻得有些发木的脸颊，慢吞吞地走回长桌旁，重新坐进椅子里。茶杯里的绿茶已经凉了一半，我端起来一饮而尽，然后把双脚挪到那台破旧的电热炉前。

说来也怪，刚才开着窗的时候觉得这玩意儿纯粹是个摆设，现在把门窗一关，那根孤独燃烧的石英管散发出的微弱热量，居然真的开始一点点温暖起桌子底下这一小片空间来。暗红色的光芒映在我的鞋尖上，烤灰尘的味道也渐渐淡去，变成了一种老旧电器特有的、让人莫名安心的干燥暖意。

房间里静悄悄的，只有电热炉偶尔因为金属热胀冷缩而发出的“啪嗒”轻响，以及角落里每隔一分钟就会准时响起的、极其轻微的翻书声。

我托着下巴，转过头看向角落里的长门。

夕阳已经沉到了西山脊背后面，窗外的天色迅速呈现出一种十二月特有的铁青色。活动室里还没开日光灯，光线有些昏暗，只有电热炉的那一点红光在阴影里明明灭灭。长门低垂着眼帘，长长的睫毛在苍白的面颊上投下浅浅的影子，仿佛周围温度的升降、人员进出的喧嚣，全都与她所处的次元毫无关系。

不过，再怎么说是外星人制造的资讯统合思念体终端，这副身体在构造上应该也是和普通人类一样的吧。刚才被冷风对着吹了那么久，真的没问题吗？

“喂，长门。”我忍不住开口打破了沉默，“你那边离电热炉那么远，不冷吗？要不要坐到桌子这边来？”

长门按在书页上的手指停顿了一下。

她没有立刻回答，而是先把那一页剩下的几行字看完，然后才慢条斯理地把一张白纸书签夹进书里，合上那本厚重的精装书，抬起头看向我。

那双毫无波澜的暗褐色眼眸在昏暗的光线里静静地注视着我，随后，她的视线往下移动了大概三十度，落在了我脚边那台只亮了一半的旧电热炉上。

长门从折叠椅上站起身，迈着毫无声息的步子走到长桌旁。不过她并没有拉开椅子坐下，而是微微俯下身，伸出右手食指，在电热炉侧面那个生锈的铁皮外壳上轻轻敲了一下。

本当に、只是像敲门一样，极其轻微的“笃”的一声。

紧接着，不可思议的事情发生了。

电热炉里原本一直装死的上方那根石英管，突然闪烁了两下，然后“嗡”的一声，以比下面那根管子还要明亮得多的橘红色光芒，精神抖擞地亮了起来。

原本只有半死不活的温度瞬间翻倍，一股货真价实的滚烫热浪扑面而来，烤得我的裤腿一阵发烫，连整个昏暗的活动室都被这团温暖的橘光映亮了不少。

“……喂喂，”我目瞪口呆地看着那台突然满血复活的昭和古董，又抬头看了看面无表情地收回手指的长门，“你刚才干了什么？难道这玩意儿也归资讯统合思念体管辖吗？”

长门居高临下地看着我，轻轻摇了摇头，短发随着她的动作微微晃动。

“接触不良。”她用那副万年不变的平淡嗓音简短地说道，“稍微修正了一下钨丝的物理连接。”

那不还是动用了超能力进行微观层面的焊接吗！要是被电器街的修理大叔看到这一幕，绝对会跪下来拜你为师的吧。

不过，看着那两根并排散发着橘红色光芒的石英管，感受着从脚底一路蔓延到全身的暖意，我决定把到了嘴边的吐槽重新咽回肚子里。毕竟，在十二月中旬寒冷的放学后，能有一台火力全开的电热炉烤脚，实在是一件让人提不起劲去深究科学原理的幸福事。

长门没有再回她那个寒冷的角落，而是顺势拉开了我对面的椅子——也就是刚才古泉坐过的那个位置——安安静静地坐了下来，重新翻开了手里的硬壳书。橘红色的暖光从桌子底下透上来，在她总是显得有些冰冷的脸庞上染上了一层淡淡的暖色。

我把双手揣进兜里，整个人往椅背上一靠，听着电热炉尽职尽责的嗡鸣声，觉得眼皮开始有点发沉。

就在我快要被这股暖洋洋的困意彻底俘虏的时候，坐在对面的长门没有抬头，只是视线依然停留在书页上，嘴唇微微动了动。

“脚，离得太近。”

“嗯？”我迷迷糊糊地应了一声。

“会烤焦。”

我低头一看，这才发现自己的鞋尖不知什么时候已经快要贴到那个凹陷的金属防护网上了，橡胶鞋底正散发出一股微妙的受热气味。

“……哦，多谢提醒。”

我老老实实地把脚往回缩了十厘米，重新找了个舒服的姿势，在春日带着她那支倒霉的极地探险队杀回来之前，心安理得地闭上了眼睛。
