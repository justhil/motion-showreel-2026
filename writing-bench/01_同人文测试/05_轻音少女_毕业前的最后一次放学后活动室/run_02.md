# 茶梗立起来的傍晚

走廊尽头的窗户没关严，二月底的风顺着轨道缝隙钻进来，吹得布告栏上的毕业生离校日程表哗啦作响。

中野梓抱着吉他的硬壳琴盒，一步两阶地跨上通往三楼的木制楼梯。扶手栏杆上的黄铜小兔子被擦得锃亮，摸上去像一块块冰凉的硬币。高二年级刚刚结束第六节英文课，而自由登校的高三学生本该在上午就离开学校了。

推开音乐室的木门时，最先扑面而来的不是预想中的吉他在音箱里轰鸣的失真声，而是一股混杂着煤油味、大吉岭红茶与烤柑橘皮的甜香。

“啊，梓喵来啦！”

平泽唯正蹲在教室中央的旧式圆筒煤油暖炉旁，身上那件米色针织开衫的袖口挽到了手肘，双手插在膝盖窝里，整个人团成一颗蓬松的球。听见开门声，她连鞋后跟都没提好，趿拉着室内鞋就扑了过来，把两只烤得滚烫的手掌直接贴在了梓被冷风吹得发僵的脸颊上。

“好冰——梓喵的脸像刚从冰箱里拿出来的果冻一样。”

“痛痛痛……唯前辈，太烫了啦！”梓往后缩了缩脖子，把琴盒顺势立在墙边，目光越过唯毛茸茸的脑袋，看向教室里的另外三个人，“你们从中午就一直待在这里吗？明明昨天在短信里说好，今天下午要从头到尾把曲目顺一遍的。”

“本来是这么打算的嘛。”田井中律反坐在塑料折叠椅上，下巴搁在椅背边缘，额前的刘海被黄色发箍箍得老高，露出光洁的脑门。她手里转着一根鼓棒，鼓棒啪嗒一声掉在木地板上，滚到了秋山澪的脚边，“结果吃过午饭，小紬说想试试看在暖炉上烤橘子，我们就稍微做了一下实验。”

暖炉顶部的铁丝防护网上，正整整齐齐地趴着五只温州蜜柑。底部接触铁网的果皮已经烘出了焦黑的斑点，热气顶开橘络，发出极其细微的“滋滋”声。

琴吹紬坐在长桌旁，双手捧着腮帮子，一双粗眉毛因为专注而微微蹙起，蓝眼睛一眨不眨地盯着那几只橘子：“真的好厉害哦。刚才律酱说，橘子烤过之后里面的酵素会发生变化，吃起来就像罐头一样甜。我还是第一次亲眼看到橘子皮鼓起来呢！”

“那只是因为里面的水分煮沸了吧，跟酵素一点关系都没有。”澪叹了口气，弯腰帮律捡起鼓棒，顺手在律的脑袋上轻轻敲了一下。她今天没穿校服外套，只在白衬衫外套了件深蓝色的背心裙，正站在窗边的水族箱前，用拇指和食指捻起一点绿色的饲料颗粒，撒进水里。

水箱里的过滤水泵发出“咕噜、咕噜”的低沉声响。猪鼻龟小吨划动着四肢，慢吞吞地浮上水面，张嘴咬住一颗漂浮的饲料，水花在玻璃壁上溅起一圈透明的水痕。

“总之，快点准备练习吧。”梓把书包放在空椅子上，蹲下身，啪嗒啪嗒地拨开黑色琴盒的金属搭扣，“距离毕业典礼只剩不到一周了，如果今天不合奏的话……”

她的话音顿了一下，没有继续往下说，只是低头从红色丝绒内衬里抱出那把野马吉他。

“好——全员就位！”律立刻从椅子上跳起来，抓起澪手里的鼓棒，大步流星地跨进架子鼓的包围圈里，一屁股坐上鼓凳，右脚踩了踩底鼓踏板，发出“咚”的一声闷响，“来吧来吧，今天要把琴弦弹断为止！”

“鼓手根本没有琴弦可以弹断吧。”澪小声嘀咕了一句，但还是走到角落，背起了她那把左撇子专用的三色日落渐变贝斯。

唯也慢吞吞地站起身，拍了拍百褶裙上的灰尘，去拿立在琴架上的吉太。紬则掀开合成器上的防尘布，将布料折成豆腐块大小，端端正正地放在窗台上。

五个人各自站到了熟悉的方位。

夕阳正从西侧的高窗斜切进来，将五把乐器和五个女孩的影子拉得很长，交错着投射在打过蜡的浅色木地板上。灰尘在光柱里缓慢地翻滚。

唯弯下腰，抓起地上的黑色连接线，准备插进马歇尔音箱的输入孔。就在金属插头碰触到插孔外圈的瞬间，音箱里传出一阵刺耳的“刺啦——”电流杂音，时断时续，接着彻底没了动静，只有面板上的红色电源指示灯还亮着。

“咦？”唯歪过头，晃了晃手里的线材，“吉太感冒了吗？声音出不来了。”

“那是接触不良吧。”梓背着吉他走过去，半跪在音箱前检查了一番，“插头这边的焊点好像松了。律前辈，备用的连接线放在哪里？”

“啊，备用线的话，应该在准备室靠门那个纸箱里。”律把鼓棒夹在腋下，掀开连接准备室的门帘，“我去找找看。”

里面传来了翻箱倒柜的动静，纸箱摩擦地板的沙沙声，还有铁盒掉在地上的清脆响声。过了好一会儿，律才双手捧着一个塞得满满当当的瓦楞纸箱走了出来，鼻尖上沾了一点灰。

“找到了找到了。不过这箱子怎么这么重啊，里面全是些乱七八糟的东西。”律把纸箱搁在茶水桌的空位上，从最上面扯出一根盘成圆圈的黑色音频线丢给唯，随后低头往箱子里瞅了一眼，“哇，这不是我们高一那会儿买的空白录音带吗？”

听到这句话，原本已经把手按在琴颈上的澪、紬和唯，像被吸铁石吸住一样，齐刷刷地背着乐器围到了长桌边。

梓手里还捏着水滴形的拨片，站在原地眨了眨眼：“那个……调音还没……”

“哇啊，真的耶！”唯连连接线都忘了插，伸手从箱子里捞出一个透明塑料盒，里面装着一盘贴着粉红色标签的磁带，上面用歪歪扭扭的圆体字写着《轻音部合宿·咖喱后半夜》，后面还画了一个长着猫耳的笑脸，“这是去小紬的别墅合宿那次录的吧？当时小律非要半夜起来讲鬼故事，结果把澪吓得钻进被窝里哭了。”

“我、我才没有哭！”澪的脸腾地红到了耳根，跨前一步想要去抢那盘磁带，背在身上的贝斯琴头差点撞到桌角，“那种黑历史快点扔掉啦！”

“我看看下面还有什么。”紬兴致勃勃地挽起袖子，把双手伸进纸箱底层，摸索着掏出一叠用橡皮筋捆住的卡片，“这是……商店街福引抽奖的纸巾兑换券？已经过期两年了呢。”

“还有这个！”律像变魔术一样抽出一本边缘卷曲的蓝色B5笔记本，高高举过头顶，“秋山澪大师的绝密作词笔记第一卷！”

“田井中律！”

“哇哈哈哈，让我念念看——‘轻飘飘的时间，棉花糖般的云朵’……痛！”

澪的拳头结结实实地落在了律的头顶。律捂着脑袋蹲下去，手里却还死死攥着那本笔记不肯撒手。

梓背着吉他站在三步之外，看着那四个人挤在狭小的长桌旁闹作一团。唯身上的吉他和澪身上的贝斯偶尔会随着她们的动作轻轻碰撞，发出木头与金属护板摩擦的细碎声响。

她低头看了看自己怀里的野马吉他，又看了看墙上的挂钟。分针已经跨过了四点半的刻度。

“真是的……”梓小声嘟囔了一句，松开背带，把吉他重新放回支架上。她走到桌边，伸手把那个快被翻乱的纸箱往自己这边拉了拉，“既然要找东西，就趁现在把准备室的杂物整理一下吧。反正高三的各位，这周五之前必须把社团教室里的私人物品全部清空对吧？”

话音落下的瞬间，桌边的吵闹声像是被按下了静音键，骤然停顿了片刻。

律揉着脑袋的手停在半空，随即哈哈笑了两声，用力拍了拍纸箱的侧壁：“说得也是呢！要是不收拾干净，下一任部长大人可要生气了。”

“我才不会因为这种事生气。”梓低下头，避开律的视线，伸手进纸箱里，把散落的录音带一盒盒按大小码齐，“这种公用的连接线、节拍器，还有保养指板用的柠檬油，留在柜子最上层就可以了。至于备用琴弦，因为型号不一样，唯前辈和澪前辈还是带走比较好。”

“柠檬油的用法，梓喵已经完全掌握了吗？”澪把抢回来的歌词本塞进自己书包夹层，声音放得很轻，走到梓的身侧，“涂太多的话，玫瑰木指板会受潮变形的。”

“我知道的，每次看澪前辈保养的时候我都记下来了。”梓用手指勾起一卷还没拆封的背带，放进旁边的塑料收纳筐里，语速比平时快了一点，“还有小吨换水的日子，冬天是每隔十天抽掉小半缸水，过滤棉每个月拆下来洗一次，加热棒的旋钮也要一直对准温水那格刻度。这些我都写在备忘录里了，完全没问题。”

“连茶具的收纳位置也是哦。”紬笑眯眯地从茶水柜里拿出一个扁平的锡罐，推到梓面前，“这罐大吉岭是昨天刚开封的，我特意多买了一倍的分量。底下那一层抽屉里还有方糖和搅拌棒，如果小梓和小忧、纯酱一起喝茶的话，足够喝到夏天呢。”

“我们不会每天放学都光顾着喝茶的，我们是正经的轻音部。”梓合上锡罐的盖子，指尖在冰凉的马口铁表面摩挲了一下，然后迅速缩回手，抓住自己的校服毛衣袖口往下扯了扯，遮住半截手背，“而且……茶壶的滤网怎么洗，我也早就学会了。”

“唔——梓喵好能干啊。”

唯还背着那把沉甸甸的吉太，突然从侧面探过身子，把下巴直接搁在了梓的左肩上。

温热的呼吸拂过梓的耳廓，唯身上那股淡淡的、像晒过太阳的棉被一样的味道笼罩过来。因为背着吉他的缘故，唯压过来的分量比平时更重一些，琴身冰凉的包边刚好抵在梓的胳膊外侧。

“怎么了，唯前辈？很重耶，快点把吉他放下来啦。”梓僵着肩膀没有动，眼睛盯着纸箱底部的碎纸屑。

“不放。”唯用脸颊蹭了蹭梓扎成双马尾的发根，声音懒洋洋的，“因为梓喵一直低着头整理东西，都不看我。明明刚才橘子已经烤好了。”

“啊，橘子！”紬惊呼一声，赶紧拿起桌上的隔热手套，转身去救暖炉上的那五只蜜柑。

果皮已经被烤得发黑发脆，一剥开，滚烫的白汽就裹着浓郁的柑橘酸甜味冒了出来。紬把剥好的橘子放在五个白瓷小碟子里，又拎起暖炉旁保温壶里的热水，重新为大家冲了一壶红茶。

五个女孩最终还是卸下了身上的乐器，重新围坐到了铺着格子桌布的长桌旁。

谁也没有再提练习的事。五把乐器安静地待在各自的角落里，琴弦在逐渐暗下来的天光里泛着细如蛛丝的银亮光泽。

窗外的云层染上了厚重的紫红色。操场那边原本隐约传来的管乐部练习长号的声音，不知什么时候已经彻底停了，整栋教学楼安静得只能听见水族箱水泵“咕噜咕噜”的抽水声，以及暖炉里煤油燃烧的微弱嗡鸣。

“嘶——好烫！但是真的变甜了！”律往嘴里塞了一瓣橘子，烫得直哈气。

“对吧对吧？”紬开心地眯起眼睛，端起红茶杯准备喝一口，动作却突然顿住了。她低下头，盯着梓面前的那只骨瓷茶杯，眼睛一下子亮了起来，“啊！小梓，你看杯子里面！”

梓低头看去。

琥珀色的红茶液面中央，一根细小的茶梗正吸饱了水分，笔直地竖立在茶水里，随着桌面的微小震动轻轻摇晃。

“茶梗立起来了！”唯立刻凑过来，脑袋差点撞上梓的额头，“是好兆头耶！会有好事发生哦！”

“是因为小紬买的茶叶等级很高，里面混进嫩茎的概率本来就很小，所以立起来更是超级罕见的事呢。”澪也探头看了一眼，神色柔和下来，“梓，快点许个愿吧。”

“那是迷信啦，只是植物纤维吸水沉底的速度不均匀而已……”梓嘴上这么说着，手指却圈住了温热的瓷杯外壁。

她看着那根立在红茶里的细小茶梗，又抬起眼，看了一圈围在桌边的四个人。律正忙着把橘子皮拼成一个小人的形状，澪在拿纸巾擦拭律弄脏的桌面，紬正满眼期待地望着自己，而唯已经把整颗烤橘子塞进了嘴里，腮帮子鼓得像只花栗鼠。

鼻腔里突然涌上一股酸胀的痒意，像是被烤橘子的热气熏到了。

梓赶紧低下头，端起茶杯，连同那根立起来的茶梗一起，小口地抿了下去。温热的茶水滑过喉咙，带着大吉岭特有的果香和微涩。

就在这时，校园广播的扬声器里传来了“滋”的一声电流音，紧接着，五点半的闭校音乐《重归苏莲托》慢悠悠地回荡在空旷的校舍走廊里。

“呜哇，已经这个时间了？”律猛地抬头看向窗外，天色已经变成了深邃的藏青色，“惨了惨了，今天真的连一个音都没弹成啊！”

“都怪小律把那个旧纸箱搬出来啦。”唯咽下橘子，理直气壮地推卸责任。

“哈？明明是唯自己说音箱不出声的好不好！”

“好啦，快点收拾东西，巡逻的老师马上就要上来锁门了。”澪站起身，拿起水槽边的抹布，拧干水，熟练地擦拭起桌面。

紬把洗好的茶杯倒扣在沥水架上，用洁白的茶巾一只只擦干。律走过去，把煤油暖炉的旋钮拧到底，“咔哒”一声，橘红色的火苗缩了回去，屋子里的温度立刻以肉眼可见的速度降了下来，只留下一股熄灭后的煤油味。

梓蹲在马歇尔音箱前，伸手按下了那个红色的船型开关。

啪。指示灯熄灭了。

她把各自的乐器收进琴盒，背起书包，五个人排成一列走出音乐室。作为留守的二年级生，现在的社团钥匙已经交到了梓的手里。她站在门外，把钥匙插进锁孔，转动了两圈。

走廊里没有开灯，只有楼梯口的应急灯散发着幽绿的光。

下楼的时候，谁也没有说话，只有五双室内鞋踩在木制台阶上的“哒、哒”声，在空荡荡的楼道里叠在一起。

走到二楼拐角平台时，走在最前面的唯突然停下了脚步，转过身来。

“怎么了，唯？忘拿东西了吗？”澪问。

“不是。”唯双手抓着吉他琴袋的背带，仰起脸看着高她两级台阶的梓，呼出的白气在昏暗的走廊里散开，“那个，梓喵。明天放学后，我们把那根修好的连接线插上，再来弹琴吧。”

梓站在台阶上，右手还揣在制服外套的口袋里，紧紧捏着那串贴着吉太贴纸的黄铜钥匙。钥匙的锯齿硌着掌心，已经被体温捂热了。

她点了点头，把下巴埋进格纹围巾里：“嗯。明天见，唯前辈。”
