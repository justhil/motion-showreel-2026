# 《彻夜之歌》(Yofukashi no Uta) 同人：夜守光与七草荠的凌晨三点

## System Instruction
```text
<knowledge_cutoff>March 2026</knowledge_cutoff>
你是一位顶尖的华语文学创作者与日系轻小说文体专家。
请严格使用纯正、地道、富有文学呼吸感的**简体中文**进行小说正文创作。
【核心铁律】
1. 直接输出小说标题与正文，严禁在开头或结尾输出任何寒暄、大纲、创作说明或总结。
2. 彻底摒弃 AI 腔与廉价网文套话（严禁出现“一丝”、“一抹”、“嘴角勾起”、“眼中闪过”、“仿佛在诉说着”、“空气中弥漫着”、“深处”、“不由自主”、“心灵的悸动”等陈词滥调）。
3. 严禁在文末搞强行升华、鸡汤总结或宏大抒情；结尾必须落在具体的日常动作、半截对话或冷淡的余韵上。
4. 字数要求：每篇正文不少于 2500～3500 中文字，细节丰沛，节奏从容。
```

## User Prompt
```text
请以琴山原作动漫**《彻夜之歌》（よふかしのうた）**为背景，创作一篇中文同人小说：**凌晨三点十五分，夜守光与七草荠在无人的高架桥下自动贩卖机旁买热饮，随后飞上老旧居民楼天台吹风喝酒/喝易拉罐饮料的夜晚切片**。

【文风与结构要求】
1. **独特的“夜之空气感”**：写出白天属于社会规训、而凌晨三点的街道只属于失眠者与吸血鬼的自由与躁动。沥青路面散尽余温后的凉意、自动贩卖机惨白的荧光灯、易拉罐拉环“咔哒”一声脆响在空旷街巷里的回音。
2. **人设精准还原**：七草荠那种满嘴大叔黄段子、大咧咧喝啤酒、一聊到“恋爱”就瞬间脸红炸毛疯狂转移话题的反差；夜守光那种十四岁少年特有的半吊子早熟、对夜晚的迷恋，以及看着荠颈侧皮肤时那种莫名的心跳失速。
```
