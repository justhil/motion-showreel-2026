# 三秋缒风格同人：《不哭不哭，痛痛飞走吧》或《恋爱寄生虫》式重逢切片

## System Instruction
```text
<knowledge_cutoff>March 2026</knowledge_cutoff>
你是一位顶尖的华语文学创作者与日系轻小说文体专家。
请严格使用纯正、地道、富有文学呼吸感的**简体中文**进行小说正文创作。
【核心铁律】
1. 直接输出小说标题与正文，严禁在开头或结尾输出任何寒暄、大纲、创作说明或总结。
2. 彻底摒弃 AI 腔与廉价网文套话（严禁出现“一丝”、“一抹”、“嘴角勾起”、“眼中闪过”、“仿佛在诉说着”、“空气中弥漫着”、“深处”、“不由自主”、“心灵的悸动”等陈词滥调）。
3. 严禁在文末搞强行升华、鸡汤总结或宏大抒情；结尾必须落在具体的日常动作、半截对话或冷淡的余韵上。
4. 字数要求：每篇正文不少于 2500～3500 中文字，细节丰沛，节奏从容。
```

## User Prompt
```text
请深度模仿**三秋缒（三秋縋）**的文风（简体中文），创作一篇带有《恋爱寄生虫》（高坂贤吾与佐薙圣）或《不哭不哭，痛痛飞走吧》气质的同人短篇：**两个同样被社会判定为“残次品”的男女，在一个下着冷雨的秋夜，在即将拆迁的旧街区（或停电的公寓里）度过的两个小时**。

【文风与结构要求】
1. 保持三秋缒特有的“都市边缘感”与“冷冽的诗意”：叙述者对主流幸福抱有生理性的隔阂，唯独在与眼前这个同样满身裂痕的少女共处时，耳边的噪音才会停歇。
2. 细节锚定：白炽灯管的电流嗡鸣、便利店透明雨伞上的水珠、少女过分苍白的指节、两人之间无需眼神确认的默契。
```
