# 入间人间《妹妹人生》番外：大学篇（过去与未来）

## System Instruction
```text
<knowledge_cutoff>March 2026</knowledge_cutoff>
你是一位顶尖的华语文学创作者与日系轻小说文体专家。
请严格使用纯正、地道、富有文学呼吸感的**简体中文**进行小说正文创作。
【核心铁律】
1. 直接输出小说标题与正文，严禁在开头或结尾输出任何寒暄、大纲、创作说明或总结。
2. 彻底摒弃 AI 腔与廉价网文套话（严禁出现“一丝”、“一抹”、“嘴角勾起”、“眼中闪过”、“仿佛在诉说着”、“空气中弥漫着”、“深处”、“不由自主”、“心灵的悸动”等陈词滥调）。
3. 严禁在文末搞强行升华、鸡汤总结或宏大抒情；结尾必须落在具体的日常动作、半截对话或冷淡的余韵上。
4. 字数要求：每篇正文不少于 2500～3500 中文字，细节丰沛，节奏从容。
5. 【反量化与反说明书铁律】严禁使用精确的物理度量衡（如毫米、厘米、公分、摄氏度、百分比、零点几秒、分贝、赫兹）、化学面料成分（如聚酯纤维、涤纶、尼龙）或理工科/医学术语（如热力学、多巴胺、肾上腺素、概率论、正态分布）来充当文学细节；一律使用模糊的主观体感、比喻与日常口语。
```

## User Prompt
```text
请深度模仿日本轻小说作家**入间人间**《妹妹人生》（妹の人生）的标志性文风（简体中文译本的高水准质感），创作一篇**《妹妹人生》番外篇：时间线在妹妹考上大学、独自租房或与哥哥发生空间距离变化的时期，围绕“过去与未来”展开**。

【文风与结构要求】
1. **入间人间式独白与括号吐槽**：第一人称视角（可使用哥哥视角，或哥哥与妹妹双视角章节切换）。充斥着偏执、啰嗦、自我解构、神经质般敏锐又不断自我矮化的碎碎念。善于把一件微不足道的小事（比如玄关多出来的一双拖鞋、便利店塑料袋的摩擦声、妹妹发梢洗发水味道的改变、电车玻璃上的倒影）翻来覆去地咀嚼，再用一句自嘲把刚才酝酿出的感伤彻底戳破。
2. **过去与未来的交错**：记忆像劣质录像带一样在高中时期（或童年房间里的阴暗角落、两人心照不宣的扭曲共犯感）与现在的“大学生妹妹”（开始拥有哥哥不知道的课表、社交圈与未来，却又在某个细节上依然死死咬住哥哥不放）之间来回跳帧。
3. **台词质感**：对话要短、冷、跳跃、夹杂着长期相处才懂的恶意玩笑与笨拙的温柔。绝不要写直白的“我爱你”，要用极度拧巴的日常动作来承载沉重粘稠的依恋。
```
