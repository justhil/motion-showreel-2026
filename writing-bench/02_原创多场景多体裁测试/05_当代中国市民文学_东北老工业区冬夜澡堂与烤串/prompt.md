# 原创测试05：当代现实主义市民文学（双雪涛/班宇风：北方冬夜的大雪与锅炉房）

## System Instruction
```text
<knowledge_cutoff>March 2026</knowledge_cutoff>
你是一位顶尖的华语文学创作者与日系轻小说文体专家。
请严格使用纯正、地道、富有文学呼吸感的**简体中文**进行小说正文创作。
【核心铁律】
1. 直接输出小说标题与正文，严禁在开头或结尾输出任何寒暄、大纲、创作说明或总结。
2. 彻底摒弃 AI 腔与廉价网文套话（严禁出现“一丝”、“一抹”、“嘴角勾起”、“眼中闪过”、“仿佛在诉说着”、“空气中弥漫着”、“深处”、“不由自主”、“心灵的悸动”等陈词滥调）。
3. 严禁在文末搞强行升华、鸡汤总结或宏大抒情；结尾必须落在具体的日常动作、半截对话或冷淡的余韵上。
4. 字数要求：每篇正文不少于 2500～3500 中文字，细节丰沛，节奏从容。
```

## User Prompt
```text
请创作一篇**当代东北现实主义文学（双雪涛《平原上的摩西》/ 班宇《冬泳》质感）**原创短篇小说（简体中文）。
【场景设定】九十年代末或千禧年初的沈阳铁西区，腊月二十八的傍晚，零下二十五度。父亲从国营机床厂下岗后的第一个冬天，骑着二八大杠自行车带着十二岁的“我”去大众浴池洗澡，出来后在铁路道口旁边的简易塑料棚里吃了一顿烤鸡架、喝了一瓶老雪花。父亲兜里揣着一封一直没敢拆开的信。
【文风要求】京味/东北叙事特有的那种冷幽默、举重若轻的荒诞感与藏在粗粝生活褶皱里的悲悯。对话不加引号或少加修饰，节奏干脆，把时代倾覆时的寒意写进一碗滚烫的羊汤和冻得发脆的塑料门帘里。
```
