# 荒铺铜铃

嘉靖三十一年，十一月廿七。宣府镇往北四十里，野狐铺。

雪下了整三天。官道早就没了踪影，天地间只剩下这间半塌的土坯驿站，像一口倒扣在白面缸里的破瓦盆。

火塘里的干马粪已经烧成了白灰，只在最底下埋着两块暗红的炭核。炭核上温着半锡壶烧刀子，酒是三天前剩下的，兑了三成雪水，闻着有一股子铁锈和烂席子的味道。火塘边摆着一只豁了口的粗瓷碟，里头盛着二十来颗盐水花生，早就冻成了石子，拿手指头一拨，当啷乱响。

驿站里只有两个人。

靠墙根坐着的老卒姓戚，身上那件号衣的红毡早就褪成了猪肝色，领口磨得发亮，结着一层厚厚的油垢。他把右手揣在怀里取暖，偶尔伸出来拨弄炭火时，能看见那只手缺了小指。齐根断的，疤痕像一朵捏瘪了的干菊花。

他怀里抱着一口刀。刀鞘是拿两片老槐木拼的，外头用粗麻绳死死缠了七道。

火塘对面坐着个十七岁的姑娘。她没穿棉袄，只在青布窄袖衫外头套了件半旧的羊皮褂子。她进屋已有两个时辰，额前那几缕碎发上的冰碴子才刚刚化了一半，水珠顺着眉骨往下淌，流到腮帮子上，又被屋里的寒气冻得发僵。

她背后斜背着一口乌木剑匣。剑匣长三尺九寸，四角包着黑铁皮，接缝处糊着猪血调的生漆，从来没开过封。

老戚伸出那只只有四根手指的右手，从碟子里捻起一颗花生，扔进嘴里。他没嚼，先用舌头裹着，等那层盐霜化了，才用后槽牙咔嚓一声咬碎。

“生漆封匣，猪血打底。”老戚嚼着花生，声音像两块粗砂石在磨，“这是南边兵仗局封存样剑的法子。姑娘从南京来？”

姑娘没低头，眼睛盯着火塘里那点快要断气的红光：“大同。”

“大同没这么讲究的漆匠。”

“人是从南京逃出来的，死在大同。”姑娘说，“死前把匣子封上了。”

老戚点点头，拿过锡壶，往自己嘴里倒了一口酒。兑了水的烧刀子不辣嗓子，只有一股苦味，顺着食道滑下去，非但没暖和，反而激得他肩膀抖了一下。

他把锡壶递过去。姑娘没接。

“喝一口吧。”老戚把壶顿在炭灰里，“外头冻得生铁都要裂，你不喝，待会儿手伸不直。”

姑娘看着老戚的右手：“你少了一根指头，手伸直了也没用。”

老戚把右手摊开，掌心朝上。他的虎口处有一层铜钱厚的黄茧，但最厚的一块茧子不在虎口，而在无名指根部和掌根连着的地方。

“行家啊。”老戚把手指一根根蜷起来，“使刀的规矩，拇指食指管方向，无名指和小指管收发。小指没了，刀劈出去就收不回来。收不回来，就容易把自己的手腕子震断。”

“那你还带着刀？”

“所以我改了练法。”老戚用左手拍了拍刀鞘上的七道麻绳，“我不劈了，我改捅。把刀柄抵在肋骨上，用腰顶着走。人老了，胳膊没劲，借点脚底下的力气，还能凑合用。”

姑娘的目光从他手上移开，落向那扇用破门板顶死的木门：“你在这儿等谁？”

“我不等人，我押镖。”老戚指了指墙角那只空了一半的麻袋，“大同总兵府采办的三十斤川盐，送到前头威远堡。雪封了路，我的骡子前天夜里冻死了，肉让我割下来埋在后院雪里了。你呢？”

“我等人。”

“等谁？”

“不知道名字。”姑娘抬起左手，用冻得通红的指腹擦掉脸颊上的冰水，“我爹死前说，只要我背着这个匣子往北走，自然会有人来找我。来的人要是使枪，我就把匣子给他；要是使别的，我就杀了他。”

老戚乐了，嗓子眼里发出呼噜呼噜的痰音：“你连匣子都没开，拿什么杀？”

姑娘没答话。

因为门外的风雪声里，忽然夹杂进了一点别的声音。

叮——叮、叮——

是铜铃。

不是商队骆驼脖子上挂的那种扁桶铃，也不是驿站急递铺的双耳脆铃。那是边军夜不收马胸前挂的八角响铜铃，铜壁厚，声音闷，穿透力却极强，顶着西北风也能传出二里地。

老戚嘴里的半颗花生停住了。他没动，脖子却往衣领里缩了半寸，整个人像一只团起来的刺猬。

“一长两短。”老戚听着那铃声，“马的左前腿有毛病，要么是掌铁掉了，要么是马背上左边的分量比右边重了三十斤以上。”

姑娘慢慢站起身。

她坐了两个时辰，腿脚却没有半点发麻的迹象。起身的时候，她的膝盖没有往前顶，而是脚后跟先发力，胯骨往后一坐，整个人像被一根绳子从头顶提了起来。

她走到火塘左边三尺远的地方停下。那里的地面塌下去一块，露出底下干硬的黄土，没有积雪化开的烂泥。她把两只脚分开，与肩同宽，鞋底在干土上碾了碾，找准了落脚的实处。

“他没带枪。”老戚听着越来越近的马蹄声，说，“枪长九尺，骑马背在身上，风吹过枪缨子会有哨音。外头只有铃声。”

姑娘把右手搭在了肩膀前的鹿皮带子上。那根带子连着背后的乌木剑匣。

“老丈。”姑娘看着门板，“这事与你无关，你往墙角退。”

老戚没动，反而把怀里的刀往外拔了一寸。

不对，他没拔刀。他的左手搭在刀鞘最上头那道麻绳的绳结上，手指轻轻一勾。

那是水手捆纤绳用的活扣。

“我往哪儿退？”老戚叹了口气，“夜不收出塞，向来不留活口。他要是看见我这身押镖的皮，顺手就把我脑袋割下去充军功了。大同镇今年欠了朝廷三百颗鞑子首级，拿汉人脑袋刮了胡子充数，一颗也能换五两银子。”

门外的铜铃声停了。

紧接着是一声闷响，像是一袋冻肉从马背上滚下来，砸进了门外的雪窝里。马打了个响鼻，没有走远，就在门外原地打转。

没人敲门。

顶门的木棍嘎吱酸响。门外的人没有硬踹，只将一把宽刃铁器顺着门缝探进来，不偏不倚地抵住顶门棍的卡槽，往上轻轻一撬。

木棍滑脱，哐当砸在地上。

两扇破木门往里开了尺许，一股夹着马尿味和血腥气的暴风雪猛地灌了进来，火塘里那点红光瞬间被吹得暗了下去，屋里黑了一半。

门口站着个人。

这人头上戴着顶狗皮帽子，帽耳朵垂下来，遮住了大半张脸，只露出一截满是冻疮的下巴和两撇结了冰的八字胡。他身上披着件反穿的老羊皮袄，羊皮袄底下露出半截深青色的布面铁甲，甲上的铁钉锈了一半。

他手里拎着个还在滴黑血的帆布口袋，随手往门边一扔。口袋落地的声音很沉，骨碌碌滚了半圈，停在老戚脚边。

这就是马背左边多出来的那三十斤分量。

来人没看姑娘，先低头看了看地上的烂泥，然后迈步进屋。

他穿的是一双鹿皮快靴，靴底很薄。左脚踩在门内的烂泥里，只陷下去薄薄一层，鞋印边缘干净利落；右脚落下去的时候，却比左脚深了足足半寸，泥水从靴子两侧挤出来。

他的重心全压在右半边身子上。

“野狐铺的驿丞呢？”狗皮帽子开口了，嗓子干得像劈柴，说话时带着一股浓重的山东口音。

“上个月就逃荒去了。”老戚缩在墙角，把那只断了小指的右手藏进袖筒里，“军爷，借个火？”

狗皮帽子没理他，慢吞吞地转过身，目光落在了姑娘背后的乌木剑匣上。

他的眼睛很小，眼白发黄，眼角有一道被箭簇豁开的旧伤，一直扯到耳根。

“沈百户的闺女？”狗皮帽子问。

姑娘没说话，连呼吸的起伏都看不见。她的胸口是瘪着的，气全沉在肚脐眼底下三寸的地方。

“沈百户是个讲究人。”狗皮帽子往前走了两步，靴底在泥地里发出吧唧一声响。他停在火塘边，低头看了看那半壶酒，又看了看那碟花生，“大同兵变，他不肯跟着那帮乱兵砍总兵的脑袋，自己带着兵仗局的账册和那把御赐的番刀往北跑。跑了三百里，一口气没上来，死在左卫城外的破庙里了。”

他指了指地上的帆布口袋：“我把他脑袋割下来的时候，眼睛还睁着呢。沈姑娘，账册在哪儿？”

姑娘的右手手指动了一下，扣紧了胸前的鹿皮带子：“在匣子里。”

“胡扯。”狗皮帽子笑了一声，鼻孔里喷出两道白气，“那匣子只有三寸宽，装不下兵仗局的生铁叶账册。账册在你贴身的羊皮褂子里。至于这匣子……”

他的右肩忽然往下沉了半寸。

这一沉极快，毫无征兆。他那件宽大的老羊皮袄右边袖口里，猛地滑出一截乌黑的铁器。

不是刀，也不是剑。是一根长二尺四寸、粗如儿臂的竹节铁鞭。

这才是他右脚鞋印比左脚深半寸的缘故。这根实心生铁铸的鞭子少说也有十八斤重，一直用牛皮套子挂在他右肘内侧。

铁鞭一出袖口，他根本没有往后拉架势，直接借着右脚蹬地的力道，腰胯猛地一拧。十八斤的铁鞭带着风声，不砸姑娘的脑袋，直接横着扫向姑娘的左肋。

边军战阵上的搏命招数，不讲虚招，上来就是打断肋骨，震碎内脏。

屋里地方太窄，从火塘到姑娘站的地方只有四尺。铁鞭长二尺四寸，加上手臂的长度，姑娘根本退无可退。

姑娘也没退。

在铁鞭滑出袖口的那一瞬间，她的左手在胸前的鹿皮带子卡扣上一拍。

啪的一声脆响，浸泡过桐油的鹿皮带子从中断开。她没有去拔剑，而是左脚为轴，整个人向右后方猛地旋身，同时右手抓着剑匣顶端的铁环，顺着转身的腰力，把那口连木头带铁剑重达二十五斤的乌木剑匣，当成了一根大杵，迎着铁鞭硬生生撞了过去！

当！

铁鞭砸在乌木剑匣的包角铁皮上，震得房梁上的积雪哗啦啦往下掉。火塘里的白灰被气浪掀起来，扑了满屋子。

狗皮帽子显然没料到这姑娘是个练横练硬功的路数，更没料到她根本不开匣，直接拿剑匣砸人。

剑匣上的生漆被这一鞭震裂了三寸，木屑乱飞。姑娘借着这一撞的反震之力，双脚在干硬的黄土上犁出两道浅沟，身体顺势贴到了左侧的土墙上，卸去了大半力道。饶是如此，她握着铁环的右手虎口还是裂开了，血顺着冻僵的手腕往下淌。

而狗皮帽子这一鞭用老了。

沉甸甸的铁鞭砸在死沉的硬木匣子上，往回弹了半尺。他右手手腕发麻，为了稳住重心，右脚顺势往火塘边的烂泥里又跺了一下。

烂泥太滑。他的鹿皮靴底往外溜了半寸。

练武的人，脚底下溜半寸，身上的架子就散了三分。他当即提起右肋，好把重心拉回来。

就在他右肋提起的那一刹那，墙角的老戚动了。

老戚没有站起来。人老了，腿脚慢，站起来再出刀，黄花菜都凉了。

他的左手猛地一扯刀鞘上的麻绳活扣。七道麻绳瞬间松脱，两片拼在一起的老槐木刀鞘啪嗒一声掉在炭灰里，直接露出了里头那口三尺二寸长的雁翎刀。

省去了拔刀出鞘的三寸时间。

老戚那只缺了小指的右手死死攥着刀柄，刀柄的铁护手紧紧抵在自己的右肋骨上。他整个人像一只贴地乱窜的老蛤蟆，左脚蹬着墙根的土坯，右脚在烂泥里一趟，连人带刀，贴着地面蹿了出去。

刀尖没有一点花哨的晃动，借着他全身一百三十斤的分量和后腿蹬墙的冲力，从下往上，贴着狗皮帽子那件老羊皮袄的下摆钻了进去。

边军的布面铁甲，胸背都有铁片，唯独腋下和肋部为了活动方便，留着三寸宽的麻布空当。

噗嗤。

声音很轻，就像是用烧红的铁钎子捅进了一块冻猪油里。

雁翎刀从狗皮帽子的右肋空当刺入，斜着往上，刀尖直接顶穿了肺叶，卡在了左侧的琵琶骨底下。

老戚没有松手，反而把整个身子都挂在了刀柄上，用自己的体重把刀往下压。

狗皮帽子嘴里喷出一口带着泡沫的红血，手里的十八斤铁鞭再也握不住，当啷一声砸在装满盐水花生的粗瓷碟上。碟子碎成了四瓣，冻硬的花生滚得满地都是。

他低头看着老戚，左手伸出来，想去抓老戚的脑袋。但他肺里灌满了血，一口气提不上来，那只戴着露指皮手套的大手在老戚头顶晃了两下，最后只抓住了老戚领口那层油腻的红毡。

老戚就这么抵着刀柄，抬头看着他的下巴，两人鼻子尖离着不到三寸。

过了大概五息的工夫，狗皮帽子喉咙里发出一声像拉风箱一样的漏气声，膝盖一软，顺着火塘边滑了下去，仰面靠在了顶门的木柱上。

屋里重新安静下来。只听见门外那匹夜不收的战马还在雪地里刨蹄子，铜铃偶尔响一声：叮——

老戚松开刀柄，一屁股坐在烂泥里，张着嘴大口喘气。他的右手手腕肿得老高，刚才那一撞，虽然借了肋骨的力，还是把他的老骨头震得够呛。

姑娘从墙根走过来。她的呼吸稍微急促了一点，胸口一起一伏，右手虎口的血滴在青布衫的袖口上，很快冻成了暗红色的硬块。

她走到狗皮帽子尸体旁，蹲下身，没有去看那个装着她爹脑袋的帆布口袋，而是先伸手探进狗皮帽子的怀里，摸出了半块干硬的杂面饼子，还有一袋火镰火石。

“你不看看你爹？”老戚喘匀了气，弯腰从炭灰里捡起那两片木头刀鞘。

“看过了，就走不成了。”姑娘把杂面饼子揣进自己怀里，站起身，弯腰去捡地上那根长长的麻绳，递给老戚，“他的马归你，我的盐归我。”

老戚愣了一下：“什么你的盐？那是总兵府的官盐。”

“你杀了夜不收，威远堡你是去不了了。”姑娘指了指墙角那半袋川盐，“给我抓两把，我有用。”

老戚看了看尸体的脸，苦笑一声，没反驳。他握住刀柄，右脚踩在狗皮帽子的胸口上，腰一弓，噗的一声把雁翎刀拔了出来。

他甚至没拿布擦刀上的血，直接在死人的羊皮袄上蹭了两下，然后把两片木头刀鞘往刀身上一合，用左手接过麻绳，一圈一圈地往上缠。

姑娘走到墙角，解开麻袋，抓了满满两大把粗盐。她没有把盐收起来，而是走到门边，提起那个滴血的帆布口袋，解开绳子，把两把粗盐全撒了进去，然后重新系紧，挂在了自己的腰带上。

老戚缠到了第五道麻绳：“你往哪儿走？”

“往南。”姑娘重新把那口裂了一道漆缝的乌木剑匣背回背上，拿断成两截的鹿皮带子在胸前打了个死结，“回南京。”

“两千多里地，大雪封山，你怎么走？”

“骑你的马走。”

“那明明是他的马。”老戚把第七道麻绳系成活扣，拍了拍刀鞘，站起身。

他走到火塘边，低头看了看。粗瓷碟碎了，但那半锡壶兑了水的烧刀子居然没倒，还稳稳地立在炭灰里。

老戚弯腰从泥地里捡起一颗滚落的花生，在衣服上擦了擦泥，扔进嘴里。

姑娘已经走到了门口。风雪扑在她脸上，她眯起眼睛，伸手去牵门外那匹马的缰绳。

“喂。”老戚在屋里喊了一声，“匣子里到底有没有剑？”

姑娘抓着缰绳的手停了一下，偏过头，看着屋里昏暗的炭火：“你猜。”

她没等老戚回答，翻身上了马。那匹左前腿微跛的战马打了个响鼻，转过身，一步一步踩进深及马腹的积雪里。

叮——叮、叮——

铜铃声顺着风传回来，越来越远。

老戚站在破门框底下看了一会儿，转身走回火塘边，拿起那半壶酒，仰头灌了一大口。酒水顺着他缺了小指的右手流下来，滴进已近全黑的炭灰里，连一点白气都没冒出来。
