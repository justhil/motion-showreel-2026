# 苦水驿

嘉靖二十七年冬，大雪把野狐岭往北的官道封死了三天。

苦水驿的屋顶塌了半边，梁木上积着两尺厚的雪。风从破洞里灌进来，贴着地面打旋，把火塘里最后一点松柴吹得明灭不定。

火塘边搁着半壶烧刀子，一个缺口的粗瓷碟。碟子里剩着十一颗盐水花生，冻得梆硬，泛着灰白。

老卒坐在离火塘最近的一块残砖上，拿右手去捏碟子里的花生。他的右手没有小指，齐根断去的，茬口处长着一层厚实的紫红色冻疮。他用大拇指和无名指夹起一颗花生，往槽牙里一塞，咔的一声，不知道是花生碎了，还是牙裂了。

老卒嚼得很慢，腮帮子上的肉一鼓一瘪。他的左膝盖上横着一口腰刀，鲨鱼皮的刀鞘早就磨秃了，木胎裂开一道长缝，用手指粗的生麻绳死死缠了七道。麻绳上浸透了常年积攒的汗碱和猪油，在暗淡的火光下泛着黑亮的光。

火塘对面坐着个少女。

她今年十七岁。这是三天前她进门时自己说的。那时候她还会说话，到了第二天晌午，她就发现张嘴说话会漏掉胸口那点热气，于是闭上了嘴。

她坐在一张断了半截横枨的条凳上，腰背挺得笔直，因为她背上缚着一口四尺长的乌木剑匣。剑匣吞口处贴着一张盖了朱印的桑皮纸封条，封条上刷过一层黄亮亮的鱼鳔胶。塞外的寒气重，鱼鳔胶冻得起了白霜，却没有裂，说明这匣子打从贴上封条起，就没人动过里面的东西。

屋里太冷，火塘的热气烘不到三尺外。少女垂在耳畔的几缕发梢上，还挂着三天前带进来的冰碴。她呼吸很轻，每吸一口气，锁骨才微微往上一抬，耳边的冰碴连晃都不晃一下。

老卒把嚼碎的花生咽下去，伸手拎起那个锡酒壶，晃了晃。里头传出稀里哗啦的水响。

“喝一口？”老卒问。

少女眼皮没抬，盯着地面：“掺了雪水，越喝越冷。”

“昨天掺的。”老卒拔开木塞，往自己嘴里倒了一口，喉结上下滚了滚，“不掺水，前天夜里就喝光了。酒喝光了，人就没个念想。塞外死人，往往不是冻死的，是等死的。”

少女终于抬起眼睛看了他一下：“你在等什么？”

“等雪停。”老卒把酒壶放回火塘边的热灰里，“雪停了，把后棚那头老骡子牵出来，回宣府交差。你呢？”

“我也在等雪停。”

“雪停了往哪走？”

“往北。”

“往北没有驿站了，只有马市和鞑子的尖哨。”老卒用那只断了小指的右手在火塘边烤着，虎口处有一块铜钱大小的老茧，因为天干，老茧正中间裂开了一道深口子，露出里面发黑的肉，“你背着这么个死沉的木头匣子，往北走不出三十里，脚底板就得冻成两块生铁。”

少女没接话，只是把双脚往条凳底下缩了缩。她穿的是一双青布棉鞋，鞋帮子已经湿透了，又被寒气冻硬，踩在驿站夯土的地面上，发出硬邦邦的摩擦声。

“你师父没教过你，出门在外，匣子里的家伙得先拿出来喂喂风？”老卒瞥了一眼她背上的乌木匣，“鱼鳔胶在南边好使，到了塞外，冻硬了比生铁还脆，可要是粘在木头榫卯里，你一时半会儿抠不开。”

“师父说，见了人才能开匣。”少女的声音很平，一板一眼，“不见人，剑气就漏了。”

老卒喉咙里发出一声短促的冷哼，不知是笑，还是被烟呛着了。

“剑气？”老卒伸出右手，翻过来，把那个齐根断掉的小指茬口对着火光，“隆庆元年……不对，是嘉靖十九年，我在大同左卫当夜不收。那时候有个江南来的剑客，在军中教武艺，也爱说这两个字。后来在野狐岭碰上五个骑马的马贼，他拔剑的时候，手指头冻僵了，没抓稳剑柄，被人一刀连手带剑全剁了下来。”

老卒顿了顿，把右手收回来，按在缠了七道麻绳的刀鞘上。

“使刀的人，食指要松，小指要紧。小指是刀柄尾端的秤砣，管着刀尖的去向。我这根小指头，就是那回替他挡刀的时候留下的。没了小指，刀劈出去就收不回来，只能拿虎口硬顶着护手，往死里走。”

少女看着他虎口上那道裂口：“那人后来活了吗？”

“死了。”老卒说，“血淌在雪地上，一盏茶的工夫就冻成了红冰坨子。我把他的剑捡回来，换了二斤烧刀子和一袋盐。”

少女不再说话。她把下巴往领口里埋了埋，发梢上的冰碴碰到粗布衣领，发出一声极细微的轻响。

就在这时候，风声里夹进了一点别的声音。

叮——啷。

声音很闷，是从北边的风雪里传过来的。

少女脊背猛地绷紧。原本平缓的呼吸骤然一滞，再吸气时，气息没能沉入丹田，全堵在胸口，带着双肩微微耸起。

老卒没有动，连眼皮都没抬，只是搭在刀鞘上的右手大拇指，轻轻摩挲了一下第一道麻绳的绳结。

“别慌。”老卒声音很低，“是个挂了铜铃的马。铃铛舌头被湿雪糊住了，所以响得发闷。”

叮——啷。叮——啷。

铜铃声越来越近，中间还夹杂着马蹄踩在积雪上的声音。

不是脆响，是噗嗤、噗嗤的闷响。

“马跑得很慢。”少女盯着那扇用麻绳拴着的破木门，右手已经悄悄往左肩上方抬，指尖离乌木剑匣的吞口只有三寸，“雪太厚了。”

“不是雪厚，是马背上的人沉。”老卒听着门外的动静，耳朵微微动了动，“这匹马左前蹄有点跛，每走四步，铜铃就乱一下。人在马背上没有随着马颠，说明他裤裆里夹着铁器，而且下盘坐得很死。是个练家子，也是个老跑边塞的人。”

马蹄声在驿站门外停住了。

风雪呼啸了一声，门外安静了大概三次呼吸的时间。

来人没有直接推门。因为苦水驿的门轴早就锈断了一半，硬推会把整扇门推塌，懂规矩的过路人，都会先托住门板下沿，往上提半寸，再往里推。

吱呀——

木门被人往上提了半寸，稳稳地推开了一道一人宽的缝。

一股夹着马汗味和碎雪的寒风猛地灌进屋里，火塘里那点残存的火苗狠狠往南边扑倒，险些当场熄灭。

一个穿油鹿皮袄的男人低着头，从门缝里挤了进来。

他生得高大，肩宽背厚，头上戴着一顶翻毛狗皮帽，帽檐上结满了白霜。进门之后，他没有急着打量屋里的人，先反手把门板重新提起来，死死扣进门框里，这才站在门口，重重跺了两下脚。

啪、啪。

两块冻硬的雪泥从他的牛皮钉靴底下震落下来，掉在夯土地面上。

男人抬起手，摘下狗皮帽，在膝盖上拍打着雪沫子。他的腰间悬着一口制式雁翎刀，铁护手，刀柄上缠着黑丝绳，绳子磨得起了毛，正好贴合着五根手指的印子。

他的目光先掠过火塘，看了一眼那个锡酒壶，然后落在了少女背上的乌木剑匣上。

“从居庸关到这里，一共二百四十里。”男人开口了，嗓音沙哑粗粝，“你走路，我骑马。大雪封山之前，你居然比我早到了半个时辰。老头子挑徒弟，别的没挑好，脚力倒是挑了个顶好的。”

少女没有说话。她的右脚往后撤了半步，鞋底在地面上蹭了一下。

老卒眼角的余光扫过少女的脚底。

火塘周围三尺之地，烤了三天火，冻土早已化作黑泥。三尺之外，地面依旧冻得梆硬。少女这一撤步，右脚脚跟踩在冻土上，前脚掌却留在了火塘边的烂泥里。

前滑后硬，重心已经偏了二分。

老卒没吭声，重新从碟子里捏起一颗冻花生，放进嘴里，这次他没咬，只是拿舌头顶着，化着上面的盐粒。

穿鹿皮袄的男人迈步往火塘边走。他的牛皮钉靴踩进烂泥里，发出吧唧一声轻响，留下一道三分深的鞋印。他在距离火塘四步远的地方停下了，正好踩在冻土与烂泥的交界线上，双脚分立，与肩同宽，右手很自然地垂在雁翎刀的刀柄旁。

“十月二十二，老头子在京城咽的气。”男人看着少女，“咽气之前，他把这口匣子交给你，让你往北走，把东西扔进大漠里，对不对？”

少女的手指已经搭上了剑匣的吞口，指节因为用力而发白：“师父说，这口剑不能留在关内。”

“那是他糊涂。”男人摇了摇头，把狗皮帽夹在左腋下，“他跟锦衣卫北镇抚司的人赌命，输了半招，自己抹了脖子。人死了，债还没平。千户大人要见这口剑，见不到剑，就得见你的脑袋。”

“你可以试试。”少女说。

“我不试。”男人看了一眼她搭在剑匣上的右手，“你今年才十七，练剑顶多六年。你手掌心里的茧子是软的，虎口上连道血口子都没有。老头子把剑封在匣子里，根本就不是为了藏什么剑气，他是怕你路上忍不住拔剑，跟人动手送了命。”

少女的呼吸猛地粗重了一下，耳边的冰碴终于晃了晃，啪嗒一声掉在她的锁骨上，碎成了两半。

男人不再看她，转过头，看向坐在残砖上的老卒。

“定远镖局的？”男人目光落在老卒那只断了小指的右手上。

“早散伙了。”老卒吐出嘴里那颗化掉了盐味的花生核，“现在给宣府的茶商押点零碎生活。”

“刀鞘缠七道麻绳，是老大同卫的法子。”男人盯着那口破腰刀，“木鞘裂了，不换新的，反而缠上生麻绳。跟人拼刀的时候，拿刀鞘去架对方的刃，麻绳一卡，就能把对方的刀咬死半息。你这把年纪，还在用这种搏命的玩意儿？”

“穷，换不起新鞘。”老卒拿起锡酒壶，把最后一点掺了水的烧刀子全倒进嘴里，仰脖子咽了下去，“这位爷，公门里的事，我一个跑脚的不掺和。你在火塘那边办你的差，我在火塘这边烤我的火。天亮雪停，各走各的路。”

“走不了了。”男人淡淡地说。

老卒拿着空酒壶的手停在半空：“怎么说？”

“我的马在山道上崴了左前蹄，蹄叉裂了，明天翻不过野狐岭。”男人指了指驿站后院的方向，“我进门之前绕去后棚看了一眼，里头拴着一头青骡子，还有一匹瘦马。瘦马是这丫头的，扛不住我这身分量。我得借你的骡子一用。”

屋里一下子静了下来，只听见火塘里最后一块松柴咔吧裂开的声响。

在塞外的雪山里，把牲口借给别人，就等于把自己留下来喂狼。

老卒低下头，看着手里的空锡壶，看了很久。然后他把锡壶轻轻放在脚边的烂泥里，发出噗的一声。

“那头骡子跟了我八年。”老卒慢慢把右手放在了腰刀的刀柄上，四根手指一根接一根地收拢，虎口那道裂开的厚茧，死死地抵住了生铁护手，“牙口虽然老了，可认得回宣府的路。给了你，我这把老骨头就得交代在这儿。”

“你可以吃那匹跛马的肉，能撑十天。”男人说，“十天之后，说不定有商队过来。”

“商队今年不走这条道了。”老卒说，“而且我牙不好，咬不动马肉。”

话音未落，对面的少女动了。

她没去撕剑匣上的封条。鱼鳔胶早冻硬了，手指根本抠不开。她双手一把攥住胸前的皮背带，猛地沉腰转身，抡起背上的乌木剑匣，带着风声径直砸向男人的面门。

这一砸用上了全身的力气，可她忘了自己右脚前掌还踩在火塘边的烂泥里。

发力的一瞬间，她的鞋底在烂泥上往后滑了半寸。

高手相争，差半寸就是差了十万八千里。原本奔着男人鼻梁去的乌木剑匣，因为这半寸的打滑，力道泄了三成，准头也往下偏了三寸，砸向男人的左肩。

男人连躲都没躲。他站在冻土上，脚底稳得像生了根，左肩只是微微往后一卸，啪的一声大响，乌木剑匣重重地撞在他的肩胛骨上。

冻脆了的鱼鳔胶和桑皮纸封条，在这一撞之下同时崩裂。

少女借着反弹的力道往后退，右手顺势往匣口里一探，握住了剑柄。

冰冷的黄铜剑柄粘住了她手心里的汗，她猛地往外一拔，掌心撕掉了一层皮。一口三尺长的青钢窄剑从匣中抽了出来，因为抽得太急，剑尖在空中抖了三抖，才斜斜地刺向男人的咽喉。

太慢了。

男人甚至还有空低头瞥了一眼少女的脚步。他右手搭上雁翎刀柄，拇指一弹护手，刀身出鞘，发出一声沉闷的铁锈摩擦声。

他不闪不避，直接往前迈了一大步，右脚钉靴重重地踩进火塘边的烂泥里，溅起一片黑水。他整个人撞进少女的怀里，手里的雁翎刀顺着少女的剑身往上一撩，刀背贴着剑脊，带起一串刺耳的酸响，直接削向少女握剑的右手手腕。

少女脸色煞白。她的重心已经在刚才那一滑里丢干净了，此时后退无路，只能眼睁睁看着那片雪亮的刀光到了自己腕子前。

就在刀刃即将碰到少女皮肤的刹那，一根缠着生麻绳的破木鞘，从斜刺里捅了过来。

老卒根本没有起身。那双老寒腿早已伸不直，他只从残砖上往前一扑，贴地滚出，左膝直接跪进滚烫的火塘灰烬里，火星四溅。

他左手攥着刀鞘，精准无比地插进了雁翎刀与少女手腕之间那两寸宽的空隙里。

咔！

男人的雁翎刀何等沉猛，一刀劈在木鞘上，直接斩断了第一道麻绳，刀刃顺着滑腻的木鞘往下猛滑，眼看就要顺势削掉老卒抓着刀鞘的左手四指。

然而滑到三寸处，刀刃撞上了第二道浸透了猪油和冻泥的生麻绳。

麻绳极韧，死死咬住了锋利的刀刃。

男人的刀势硬生生顿了半息。

就是这半息的工夫，老卒的右手拔刀了。

他没有把刀完全拔出来。因为木鞘裂了，全拔出来反而慢。他那只没有小指的右手，用大拇指、食指、中指和无名指死死箍住刀柄，虎口裂开的老茧猛地往前一顶护手，只把刀身推出来了八寸。

八寸雪亮的刀肚，自裂开的木鞘侧面滑出，贴着男人的刀盘，横抹过去。

男人脸色剧变，想要抽刀后撤，可他的右脚钉靴正陷在火塘边三分深的烂泥里，拔脚的时候带起了一团沉重的泥浆，身形慢了极其微小的一瞬。

噗嗤。

老卒那八寸长的刀刃，结结实实地抹过了男人的右手手腕。

没有用刀尖，纯粹是靠着虎口顶住护手，用全身往前扑的体重，硬生生把刀刃压进肉里的。

大股温热的血喷了出来，溅在火塘里，发出一阵刺鼻的焦臭味，把最后一点火星彻底浇灭了。

屋里顿时陷入了一片昏暗，只有门缝和屋顶破洞里透进来的一点雪光。

男人的右手腕筋断了，五指一松，雁翎刀当啷一声掉在泥地里。他闷哼了一声，果然是个狠角色，左手毫不停留，从腋下松开狗皮帽，五指成爪，直接去抓老卒的天灵盖。

可他忘了旁边还有一个十七岁的少女。

少女手里的青钢剑虽然偏了，但人还没有倒。她看着近在咫尺的男人胸口，甚至忘了师父教过的那些剑招，只是双手死死攒住黄铜剑柄，把剑尾抵在自己的小腹上，合身往前一撞。

噗。

窄剑的剑尖穿透了油鹿皮袄，从男人的左肋下扎了进去，一直没入了一尺多深，直到剑尖撞上后面的土墙，才停了下来。

男人举到半空的左手僵住了。

他垂着头，借着幽冷的雪光，盯着插在自己肋下的那柄剑，随后才抬起眼，望向跪在火塘灰里、正呼哧呼哧喘着粗气的老卒。

“……好快的刀。”男人喉咙里咕噜了一声，嘴角溢出一股黑血，“你不是定远镖局的……你是当年左卫军法司……专门砍人脑袋的……”

老卒没有回答他。老卒还保持着双手持刀的姿势，右手虎口上的裂口彻底崩开了，血顺着生铁护手往下滴，和男人手腕上的血混在一起。

男人的膝盖软了下去，整个人顺着土墙滑坐在地上，脑袋往旁边一歪，不动了。

屋里重新安静下来。

门外的风还在刮，后院偶尔传来一两声老骡子打响鼻的声音。

少女松开剑柄，连退三步，跌坐在那张断了横枨的条凳上。她右掌心被黄铜剑柄撕破了皮，往外渗血，浑身剧烈发抖，大口喘着粗气，吐出团团白雾。

老卒在火塘的冷灰里跪了好一会儿，才左手撑着刀鞘，一点一点地把那双僵硬的膝盖挪出来，重新坐回那块残砖上。

他低头看了一眼自己的腰刀。

刀身还卡在裂开的木鞘里，露在外面的八寸刀刃上全是血和油脂。刀鞘上缠着的七道麻绳，被刚才那一刀斩断了两道，剩下的五道也松垮了，垂下几根毛糙的麻线。

老卒伸出那只只有四根手指的右手，把刀慢慢推回鞘里，然后拉过那两根断掉的麻绳头，用大拇指和无名指捏着，在刀鞘上重新绕了一圈，系了个死结。

系完绳子，他在火塘边的烂泥里摸索了一阵，找到了那个粗瓷碟子。

碟子没碎，里面还剩着十颗冻硬的盐水花生，只是上面溅了几点血星子。

老卒捡起一颗花生，在自己脏兮兮的袄袖上擦了擦，扔进嘴里。

咔。

他一边嚼着，一边抬头看了一眼对面的少女：“手破了？”

少女低头看着自己流血的掌心，嗓子发干，过了好半天才挤出一个字：“嗯。”

“抓剑抓得太死。”老卒嚼着花生，声音在昏暗的屋里显得有些含糊，“虎口要顶住，手指头要活。去，把那人身上的鹿皮袄扒下来，盖在身上。火灭了，下半夜更冷。”

少女没有动，看着地上那具渐渐变冷的尸体，又看了看插在尸体肋下的那口名贵窄剑：“剑……还拔出来吗？”

“拔出来干什么？”老卒把双手拢进袖筒里，往身后的土墙上一靠，闭上了眼睛，“堵着窟窿正好，省得血流一地，明天早上冻住了，还得拿铁锹铲。”
