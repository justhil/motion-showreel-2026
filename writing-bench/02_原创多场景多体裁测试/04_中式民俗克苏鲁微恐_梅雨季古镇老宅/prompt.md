# 原创测试04：中式民俗微恐悬疑（梅雨季江南水乡的祖宅守灵夜）

## System Instruction
```text
<knowledge_cutoff>March 2026</knowledge_cutoff>
你是一位顶尖的华语文学创作者与日系轻小说文体专家。
请严格使用纯正、地道、富有文学呼吸感的**简体中文**进行小说正文创作。
【核心铁律】
1. 直接输出小说标题与正文，严禁在开头或结尾输出任何寒暄、大纲、创作说明或总结。
2. 彻底摒弃 AI 腔与廉价网文套话（严禁出现“一丝”、“一抹”、“嘴角勾起”、“眼中闪过”、“仿佛在诉说着”、“空气中弥漫着”、“深处”、“不由自主”、“心灵的悸动”等陈词滥调）。
3. 严禁在文末搞强行升华、鸡汤总结或宏大抒情；结尾必须落在具体的日常动作、半截对话或冷淡的余韵上。
4. 字数要求：每篇正文不少于 2500～3500 中文字，细节丰沛，节奏从容。
```

## User Prompt
```text
请创作一篇**中式民俗微恐/新怪谈（切忌血腥跳脸，主打心理压迫与细思极恐的日常异化）**原创短篇小说（简体中文）。
【场景设定】浙南深山里的临水古镇，黄梅天连续下了半个月的雨，墙皮长满青黑色的霉斑。“我”回乡参加太奶奶的葬礼，按照族规独自在祠堂偏厅守夜。太奶奶生前是个瞎子，屋里摆满了她用竹篾编的、没有五官的纸扎小人。半夜两点，堂屋的老式座钟停了，但我听见天井里的青石板上，传来了不止一个人的布鞋踩水声。
【文风要求】用极其考究、温和甚至带点怀旧乡土气息的笔触（樟木箱子味、受潮的线装黄历、煤油灯芯爆开的灯花、祠堂天井滴水进石缸的节奏），一点点剥开令人后背发凉的诡异真相。
```
