# 樟溪镇守夜

从丽水转乘了两趟中巴车，再踩着松动的矴步石过溪时，这场的黄梅天已经在樟溪镇连绵了整整半个月。

溪水涨成了浑浊的浓茶色，紧贴着两岸吊脚楼的石基往山外滚。镇子陷在浙南深山的褶皱里，四面是终年不散的白雾，雾气吸饱了水，沉甸甸地挂在马头墙的翘角上。只要伸手往祠堂粉墙上一蹭，指腹就能蹭下一层滑腻的灰浆。那些白灰墙皮早已被雨水泡得发胀、起鼓，从墙根往上蔓延着大片青黑色的霉斑，形状像是群山，又像是无数张挤在一起的、模糊的侧脸。

我是赶回来送太奶奶最后一程的。

太奶奶活了九十四岁，按族里的规矩算是喜丧。白日里祠堂办流水席，天井上头扯着硕大的蓝白塑料布遮雨，积水顺着塑料布的折痕哗哗往下淌。族里的叔伯姑婆们穿着高筒黑雨靴或是绿胶鞋，踩着满地泥水进进出出，端着粗瓷碗喝滚烫的豆腐娘。席间没人掉眼泪，都在大声议论今年的杨梅怕是要烂在树上了。

唯独到了傍晚收席时，原本嘈杂的祠堂一下子空得极快。不光是旁支的亲戚，连我爸和堂叔他们也匆匆披上雨衣，赶在天彻底黑透前迈出了祠堂高高的石门槛。

按照樟溪林氏的老规矩，老辈人落棺的头一晚，必须留一个未婚的本家男丁在祠堂“守偏厅”。我在城里读完书工作，算上今年，统共也才回过三次老家，这差事便落在了我头上。

“夜里凉，莫去堂屋乱晃，就守着这盏灯。”

临走前，三叔公拎着一把扁嘴锡壶，往偏厅八仙桌上的老式玻璃煤油灯里添满了油。他今年七十出头，左腿早年上山砍毛竹被滚石砸伤过，走起路来左脚总要在青砖地上拖出“嚓”的一声轻响。

偏厅与停放黑漆棺木的堂屋只隔着六扇镂空的花格木门。三叔公蹲在堂屋门口，打开一口掉了漆的樟木箱子，从最底下摸出一双黑面千层底布鞋，扔在我脚边。箱盖掀开的瞬间，一股浓烈的老樟木味混杂着放了数十年的生漆、潮湿草纸的气息扑面而来，呛得人鼻腔发酸。

“把你脚上那双皮鞋换了。”三叔公弯着腰，用火柴点亮煤油灯，把灯罩扣上，“外国胶底鞋踩在砖上吱扭吱扭响。你太奶奶耳朵尖，听不得这种生分动静。”

我低头看了看那双布鞋。鞋面是粗棉布的，纳底的麻线因为受潮泛着陈旧的灰黄，尺码看着比我的脚略大一圈。我脱下湿透的运动鞋，把脚伸进布鞋里。布料贴着袜子，又冷又潮，像是刚从阴凉的地窖里挖出来的。

三叔公提着马灯走了。祠堂厚重的两扇黑漆大门在外面落了锁，铁链碰撞的哗啦声很快被密集的雨声吞没。

我端着煤油灯，在偏厅里慢慢环视了一圈。

这间东偏厅，太奶奶生前住了六十多年。她二十八岁那年害了一场热病，烧退之后，一双眼睛就彻底瞎了，眼珠子蒙着一层灰白翳子，平日里总是半阖着。因为看不见，她极少出祠堂的门，成天就坐在偏厅靠窗的矮竹椅上，手里握着一把磨得雪亮的弯头篾刀，没日没夜地劈竹篾、扎纸人。

如今她躺进了堂屋的樟木棺材里，这屋里却还满满当当地留着她的手艺。

靠墙的条案上、粮斛里、甚至是那口大樟木箱子的顶上，密密麻麻地摆着上百个一尺来高的小人。这些小人全是用刮去青皮的细竹篾编出骨架，外头糊着一层本地土产的粗糙桑皮纸。太奶奶的手极巧，竹篾被她干枯的指腹摩挲得如同旧象牙一般温润，小人的肩背、手脚、乃至衣襟的褶皱都扎得活灵活现，有的微驼着背，有的双手拢在袖子里，有的右肩高左肩低。

但没有一个纸人是有脸的。

它们脖颈顶端的竹圈上，只平平地蒙着一张白纸。没有点睛，没有画眉，也没有拿红纸剪出嘴唇。在昏黄摇晃的煤油灯光下，这一百多个白茫茫的纸脑袋齐刷刷地朝向八仙桌的方向，像是一群站在浓雾里沉默听戏的看客。

我在八仙桌旁的木椅上坐下。屋里太静了，静得只能听见门外天井里的滴水声。

白日里遮雨的塑料布已经撤掉了，雨水顺着祠堂四面的滴水瓦流下来，汇成水线，不偏不倚地砸在天井中央那口大肚青石水缸里。水缸早就满了，水面上浮着一层厚厚的绿萍，水珠砸进去，叩出沉闷而有节奏的声响。

咚——咚——咚——

像是有个人蹲在天井里，用手指一下一下地弹着湿木头。

为了驱散身上的寒气，我把煤油灯往怀里拉了拉。桌面一角放着一本巴掌宽的线装老黄历，封皮的蓝布已经烂得不成样子，露出里头起毛的草纸。书页受了潮，摸上去软绵绵、凉津津的，像是刚出笼又放凉了的荷叶饼。

我随手翻开黄历。里头除了印着“宜安葬、忌嫁娶”的朱砂字迹外，每隔几页，就夹着一张剪成脚掌形状的毛边纸。

这是农村妇人做鞋用的“鞋样”。

我捏起一张凑到灯下细看。这鞋样约莫是七八岁孩童的尺码，奇怪的是，纸片上没有用墨笔写名字，而是被人用缝衣针扎出了许多细密的孔洞。那些针眼大多集中在脚后跟和前脚掌内侧，深浅不一，摸上去扎手得很，倒像是盲人用来记事的暗码。

我一页页往后翻。这本厚厚的黄历里，竟然夹了不下几十张鞋样。有窄长秀气的女式鞋样，有宽肥粗笨的男式鞋样，上面无一例外都布满了密密麻麻的针眼。有的针眼在左脚尖格外密集，有的则在右脚外侧划出一道长长的破痕。

煤油灯的灯芯吸饱了掺水的劣质火油，顶端结出一个黑红的焦疙瘩，忽然“啪”地爆开一朵粟米大的灯花。

火星子跳了一下，落在桌面上。借着陡然亮起的光，我看见桌角还压着一个没做完的篾骨小人。

那小人的竹篾还是青绿色的，显然是太奶奶咽气前几天才刚劈出来的料子。桑皮纸只糊到了胸口，两条竹篾编成的腿还露在外头。而在小人脚边，平放着一张崭新的、尺码颇大的男式鞋样，纸面上干干净净，一个针眼也没有，只压着一枚生了褐锈的粗缝衣针。

我盯着那张空白的鞋样，后背的汗毛微微竖了起来。我把脚从桌子底下伸出来，将脚上的黑布鞋与那张纸片隔空比划了一下。

分毫不差。正是我现在脚上穿的这个尺码。

我想起小时候回乡，有一次在祠堂天井里跑跳，不小心摔破了膝盖。那时候太奶奶就坐在偏厅的门槛后头，她没有起身来扶我，只是侧着耳朵，那双灰白的瞎眼对着空茫的雨幕，枯瘦的手指在膝盖上一拍一拍地打着拍子。

当时三叔公在旁边笑着说：“莫怕，你太奶奶不看人，她听脚音。谁家娃儿脚重，谁家大人走路拖泥带水，只要在天井青石板上走一遭，她手里的篾刀就能把人的骨头架子给削出来。”

原来那些没有五官的纸人，根本不需要脸。在太奶奶六十多年的黑暗里，活人是没脸的，活人只是一串串轻重缓急各不相同的脚步声。

堂屋里传来“咔哒”一声轻响。

那是摆在供桌正中央的老式五福座钟。我抬起手腕看了眼表，正好是凌晨两点整。按照钟摆的惯性，这时候它该敲响两下沉闷的铜簧声了。

然而并没有。那座上了足弦的座钟像是被什么湿冷的东西突然掐住了喉咙，发出一声极其短暂的齿轮摩擦声后，彻底停摆了。

连带着，天井里“咚、咚、咚”滴进石缸的水声，也突兀地断了。

偏厅里的煤油灯火苗猛地往下缩成一团豆大的蓝火。我屏住呼吸，手掌死死扣住八仙桌的边缘，指甲抠进了潮湿发软的木头缝里。

就在这片死寂中，天井的青石板上，响起了第一声踩水声。

啪嗒。

不是白天亲戚们穿的硬底胶鞋，也不是雨靴踩进泥坑的闷响。那是吸饱了雨水的千层底布鞋，结结实实地踏在积着浅水的青石板上的声音。棉布鞋底被水泡发之后，落脚时带着一种特有的、绵软而沉重的粘滞感。

紧接着，是第二声。

啪嗒、啪嗒。

那脚步声是从天井东南角的排水沟那边传来的，走得很慢，每一步都拖着长长的水音。还没等这一个人的脚步走到水缸边，西厢房的屋檐下、祠堂大门的门廊后，同时响起了第二个、第三个、第五个人的脚步声。

啪嗒。嚓、啪嗒。啪嗒啪嗒。

不止一个人。短短十几息的工夫，狭窄的四方天井里像是挤满了人。

没有半点说话声，没有咳嗽，甚至听不见衣服布料摩擦的窸窣声。只有几十双湿透的布鞋，在青石板的积水里来回走动。水花被鞋底趟开，发出细碎的“哗啦”声。

我僵在木椅上，一动不敢动，耳朵却不受控制地去分辨那些声音。

走得最慢、每迈出左脚就要在石板上拖出“嚓”一声水响的，是三叔公的步子；步幅极小、脚尖习惯性往里扣，走起来急促如碎雨的，是住在村尾的二姑婆；还有那个脚后跟砸得极重、每走一步都要顿一下的，分明是我爸白日里抬棺材时的步态。

他们白日里明明都穿着胶鞋离开了祠堂，可现在，属于他们的脚步声却全留在了这片黑漆漆的天井里，穿着太奶奶记忆里几十年前的千层底布鞋，绕着那口长满绿萍的青石水缸，一圈又一圈地打着转。

偏厅里忽然飘起一股浓重的泥腥气，那是天井石缝里的百年青苔被水泡烂后的味道。

我艰难地转动僵硬的脖颈，借着昏暗摇曳的灯光，望向靠墙条案上的那排纸人。

只见那些原本干爽洁白的桑皮纸小人，从脚踝往下两寸的地方，不知何时已经彻底湿透了。青黑色的污水正顺着粗糙的纸纤维一点点往上洇，纸人细小的竹篾脚掌下，正滴滴答答地往条案上渗着混浊的雨水。

最左边那个左腿微跛的纸人，鞋底还粘着一片从天井水缸里带出来的绿萍。

天井里的脚步声停了。

几十双湿布鞋先后迈上堂屋前的三级石阶，跨过门槛，鱼贯进入了停放棺材的堂屋。堂屋地面铺的是干燥的方砖，湿鞋底踩上去，发出一连串黏腻的“唧、唧”声。那些声音围绕着太奶奶的黑漆棺木走了一遭，最后齐刷刷地停在了偏厅的六扇花格木门外。

一门之隔。

透过花格门底部一寸宽的缝隙，我看不见任何裤管或脚踝，只能看见门外的青砖地上，凭空洇开了一排排深色的湿脚印。水迹顺着砖缝蔓延，一直流到了我的脚尖前。

门外所有的脚步声都消失了，整个祠堂仿佛在等待着什么。

桌上的煤油灯芯又爆了一下，灯油即将耗尽，火苗剧烈地跳动起来，将桌角那个半成品的青篾小人的影子拉得极长，斜斜地投在花格门上。

我浑身冰凉，双腿因为长时间的紧绷而发起抖来。为了稳住身形，我不小心把右脚往后撤了半寸。

脚上那双三叔公给的大号黑布鞋，鞋底蹭过地面受潮的青砖，磨出一记极细碎的摩擦声。

“沙——”

几乎是在这声响落下的同一刹那，堂屋的黑漆棺材里，似乎传出一记极轻的、老太太喉咙里叹气般的咕哝。

紧接着，我眼睁睁地看着八仙桌上那枚生锈的缝衣针，没有任何外力触碰，自己翘起针尾，在空白的毛边纸鞋样上，直直对准右脚后跟的位置，狠狠扎了下去。

噗。

针尖刺穿受潮的纸面，扎进底下腐朽的桌面木纹里，尾端还在微微颤动。

煤油灯在这时彻底熬干了最后一滴油，“啵”地一声轻响，火苗熄灭，四周陷入伸手不见五指的浓黑。

黑暗中，我听见桌角那个只糊了一半白纸的青篾小人，发出了一阵细碎的竹篾弯曲声。它从桌面上站了起来，跳落到青砖地上，迈开两条光秃秃的竹篾腿，踩着和我刚才一模一样的步幅，一步一步走出偏厅，汇入了门外那群看不见的湿布鞋里。

……

天亮的时候，雨还是没有停。

祠堂外头响起了铁链开锁的哗啦声，紧接着，两扇黑漆大门被推开，灰白的天光混着湿冷的山雾涌了进来。

三叔公披着塑料雨衣，脚上套着那双沾满黄泥的高筒绿胶鞋，手里提着一篮子刚出锅的白米发糕，一瘸一拐地走进了偏厅。他的左脚胶鞋蹭在地面上，发出沉闷的“嚓、嚓”声。

“醒了？”三叔公把发糕篮子放在八仙桌上，伸手摸了摸已经冰凉的煤油灯罩，“昨夜雨大，没冻着吧？”

我坐在木椅上，嘴唇发白，半晌没能吐出一个字。

三叔公像是早就习惯了守夜人的这副模样，也没多问。他转头看了一眼条案上那些纸人——天光下，纸人们脚底的水迹已经干了，只留下一圈淡淡的灰黑色水渍；而桌角原本放着半成品青篾小人的地方，此刻端端正正地坐着一个已经糊好全身桑皮纸、同样没有五官的新纸人。

三叔公走过来，弯腰拔起桌上那枚扎进木头里的锈针，别在自己衣襟上。随后，他拿起那张已经布满了细密针眼的鞋样，吹了吹上面的木屑，顺手夹进了那本潮湿的线装老黄历里。

“行了，把鞋脱了吧，待会儿八点钟就要起棺上山了。”三叔公指了指我的脚下。

我低下头。

我脚上那双昨晚还没沾过水的黑面千层底布鞋，此刻已经彻彻底底地湿透了，白色的鞋底边缘沾满了天井里才有的绿萍和青苔泥，正往干燥的青砖地上，一滴一滴地渗着黑水。
