# 守偏厅

樟溪镇的黄梅天，雨是从端午那日晌午落下来的，一连下了十六天。

溪水涨平了石埠头，浑黄的水沫子裹着上游冲下来的烂竹叶，整日拍打着祠堂后墙的条石。祠堂是乾隆年间起的砖木老屋，常年不见日头，这半个月的水汽闷在屋脊下，白灰墙皮鼓起一片片水泡。水泡破了，就长出青黑色的霉斑，顺着墙根往上爬，远远看去，高低错落，晦暗湿冷。

太奶奶是前天夜里咽气的，享年九十九。在浙南山里，这算得上顶大的喜丧。

按照林氏的族规，百年归老的宗妇停灵三日，头两日由本家叔伯轮流坐夜，到了出殡前的最后一晚，必须由族里最年轻、且未曾婚配的嫡亲晚辈独自守在祠堂偏厅。我刚从杭州开车赶回来，辈分最小，这桩差事便顺理成章落在了我头上。

“正堂有我和你几个堂叔盯着，你只管待在偏厅，把那盏油灯看牢就是。”

吃夜饭的时候，三叔公夹了一块霉干菜焖肉放进我碗里。肥肉炖得极烂，筷子一碰就颤巍巍地塌下去，泛着股陈年老卤的咸香。八仙桌上坐着七八个族里的老人，都没怎么动筷子，只端着粗瓷碗喝黄酒。

我低头扒饭，余光瞥见桌底下的青砖地。傍晚过来时明明还在落大雨，可三叔公和四姑婆他们进祠堂时，手里都没拿伞，蓑衣也没披一件。这会儿他们坐着，脚上那双黑面千层底的布鞋却在往外渗水，每个人脚跟底下都洇湿了一小团深色的水迹。

“偏厅里没拉电线？”我问了一句。

“拉过，前几年村里改电路的时候扯了一根进去，你太婆嫌那光太硬，刺得慌，让人剪了。”四姑婆用袖口擦了擦嘴角，声音像是两片干枯的竹叶在刮擦，“再说，电灯烤干了屋里的东西，不好。还是煤油灯养人，油烟软，受潮的东西熏一熏才不会散架。”

她说完，三叔公从灶披间端出一碗黑褐色的汤水递给我：“把这碗石斛草决明喝了。你在城里整天盯着电脑看，眼火旺。偏厅里那些物件忌讳生人拿硬眼珠子直勾勾地瞧，喝了它，降降火，夜里坐着也安神。”

汤水半凉不热，入口带着股土腥气。咽下去后，舌根慢慢泛起甜味。

到了亥时末，正堂里的哭丧声和铜钹声歇了下来。帮忙的乡邻各自散去，三叔公提着一盏马灯，领着我穿过天井，推开了东侧偏厅的木门。

门轴转动的声音又涩又沉。一股浓烈的樟木箱子味混着陈年纸灰的潮气扑面而来，呛得我打了个顿。

太奶奶自打三十岁那年害了一场红眼病，借了郎中几帖草药没敷好，一对招子就彻底瞎了。往后的六十多年里，她几乎没迈出过这间偏厅的门槛。

屋子不大，靠北墙并排摆着两口掉漆的大樟木箱，箱盖半支着，里头塞满了裁好的毛边纸和桑皮纸。正中的长条案、东墙的五层木架，乃至八仙桌的半边桌面上，密密麻麻地摆满了竹篾编的纸扎小人。

这些小人都只有一尺来高，拿后山砍来的三年青竹破成细篾，扎出头颅、脊梁和四肢的骨架，外头糊上两三层发黄的桑皮纸。最古怪的是，满屋子百来个纸人，全都留着一张光秃秃的白纸脸——没有点墨的眼珠，没有胭脂画的嘴唇，连鼻梁的隆起都没有，只有平坦圆滑的一团惨白，齐刷刷地朝向偏厅门口。

三叔公把马灯留在门外，摸黑走到八仙桌旁，划了一根火柴，点亮了桌上那盏带玻璃罩的旧煤油灯。

豆大的火苗蹿了一下，“啪”地爆开一朵暗红灯花。昏黄灯光下，那些没有五官的纸人背后拉出一道道细长黑影，随着火苗晃动，在长满青黑霉斑的墙皮上轻轻摇晃。

“竹篾刀和樟木油布都在桌角，你太婆生前每晚都要拿油布擦一遍竹骨。”三叔公站在阴影里，大半张脸被昏暗的光线切开，看不清神色，“夜里要是听见外头有什么动静，莫开门，也莫拿手电筒往天井里照。守到天亮，听见头遍鸡叫，你就能出来了。”

他交代完，转身跨出门槛，随手将两扇花格木门合拢。

木门外头并没有落锁，只是虚掩着。随着三叔公的脚步声消失在正堂方向，四周顿时静得只剩下天井里的雨声。

祠堂天井正中摆着一口明代留下的青石太平缸，缸口积满了绿茸茸的青苔。屋檐四角的水流汇成细线，高高低低地砸进满溢的石缸里——“咚、哒、咚、哒”，节奏极其缓慢沉闷。

我在八仙桌前的竹椅上坐下。屁股底下的竹篾已经被太奶奶坐得滑腻发亮，透着股经年累月的油脂感。

刚坐了不到半个钟头，白日里开车的困倦便涌了上来，眼皮开始发沉。眼角还隐隐泛起温热的酸胀，眼珠子表面蒙了一层水翳。我揉了揉眼睛，再抬头看条案上的纸人时，发现原本清晰的竹篾接缝处变得模糊，边缘散开一圈毛茸茸的白光。

为了强打精神，我伸手把灯芯挑高了一点，目光落在了桌角那本用来垫茶壶的线装老黄历上。

黄历的封皮早已脱落，露出里头被水汽泡得发胀的毛边纸页，书脚卷曲成了波浪状，散发着一股酸腐的浆糊味。我随手拿起来翻了翻，想找点古怪的吉凶批注打发时间。

翻到立秋那一页时，书页间夹着的一张红纸条掉了出来。

我捡起纸条凑到煤油灯下。纸条是裁剩下的春联纸，已经褪成了浅粉色，上头用极细的狼毫小楷写着一行字，墨迹被潮气晕得有些发毛：

“癸亥年五月廿三，樟溪发大水，冲垮南岸石坝。林长贵，年三十四，溺于深潭。取后山苦竹七寸为脊，桑皮纸三层糊面，纳气归堂。”

我捏着纸条的手指僵住了。

林长贵，是三叔公的本名。

可三叔公今年分明已经七十七了，就在两个钟头前，他还坐在我对面喝了半碗黄酒，夹了一块焖肉到我碗里。

煤油灯的灯芯又“啪”地爆了一下，溅起一星黑灰，落在我的手背上，没有半点温度。

我低下头，指尖发着抖，去翻那本返潮的线装黄历。吸饱了水汽的纸页粘连在一起，揭开时伴着细碎的撕裂声。几乎每隔三四页，里头就夹着一张同样的浅粉纸条，或是直接在书页天头的空白处写着小字。

“丙寅年六月初四，后山滑坡。林淑华，年二十九，折骨而亡。取苦竹六寸半，桑皮纸四层……”林淑华，是刚刚教我用煤油灯的四姑婆。

“戊辰年五月十九，山洪入村。林根生，年四十二……”

“庚午年五月廿八，雷火烧山……”

一页页翻过去，整本黄历里密密麻麻记了六十七个人的名字、生辰，以及死于非命的时辰。最早的一个是在六十年前，正是太奶奶瞎掉眼睛的那一年；最近的一个是在五年前的黄梅天，名字叫林建平，是我那个常年在镇口摆修车摊的远房堂叔。

整个樟溪镇林氏宗族里，凡是今晚留在祠堂里吃席、烧纸、冲我点头寒暄的长辈，名字全都在这本烂黄历里。

我猛地合上黄历，抬头看向满屋子的无脸纸人。

因为眼睛愈发酸涩模糊，隔着几步远的距离，那些原本只有一尺高的小纸人，在昏黄摇曳的灯光里竟然显得有些高大。我的视线顺着长条案一排排扫过去，忽然发现靠东侧的七八个纸人有些不对劲。

往年太奶奶活着的时候，每晚都会用樟木油布擦拭竹骨，再用煤油灯烘烤纸面。可太奶奶已经死了三天，偏厅里三天没人点火，加上外头连下十六天的暴雨，水汽早已浸透了砖墙。

那七八个纸人的胸口和裙摆处，桑皮纸已经被潮气泡得软塌下来，死死贴在里面的青竹篾上，显出一根根细篾的凸起。更让人头皮发紧的是，纸人那惨白的肚腹上，正透出一团团绿豆大小的青黑色霉斑——和我进门时在祠堂墙皮上看到的一模一样。

我脑子里轰的一声，猛然想起吃夜饭时的一幕。

席间，四姑婆一直在低声咳嗽，一边咳，一边拿手掌按着自己的左胸口，冲三叔公抱怨说：“今年这梅雨下得太毒了，我这前胸的骨头缝里发毛，又酸又软，喘气都费劲。”

当时三叔公怎么回她的？

三叔公看了我一眼，端起酒碗抿了一口，慢吞吞地说：“熬过今晚就好了。阿明回来了，偏厅里的灯一点起来，骨头就硬朗了。”

冷汗顺着我的鬓角滑下来，滴进衣领里，冰凉刺骨。

原来这六十多年里，樟溪镇早就死绝了大半。太奶奶瞎了眼，看不见生死，便用这门扎竹糊纸的邪门手艺，把一个个横死在梅雨天里的族人留在了阳间。只要偏厅里的纸人竹骨不烂、桑皮不破，那些死去的人就能顶着活人的皮囊，在镇上挑水、种地、烧火做饭，年复一年地活下去。

可纸糊的东西，最怕黄梅天的潮气。

太奶奶一死，没人给这些纸人擦油烘火，镇上那些“活人”的身子，就要随着偏厅里的纸人一块儿发霉、泡烂了。

就在这时，隔壁正堂里突然传来了老式座钟的报时声。

“当——”

第一声钟鸣极为沉闷，声响发暗发堵。按照往常，半夜两点应当敲响两下。然而那座上了年纪的机械座钟在敲完第一声后，里头的发条突然发出一声刺耳的“咔哒”轻响，紧接着，钟摆彻底停了。

余音散尽，祠堂里陷入了一片死寂。

屋檐水滴进天井石缸的声音再次浮了上来：“咚、哒、咚、哒。”

我屏住呼吸，手掌死死按在八仙桌的边缘。没过多久，那规律的滴水声忽然乱了。

天井的青石板上，毫无征兆地响起了一声“啪叽”。

那是吸饱了水的千层底布鞋，重重踩在积水石板上的声音。

紧接着，是第二声、第三声、第十声……

“啪叽、啪叽、啪叽……”

声音从祠堂大门口的廊下传来，从东西两侧的厢房暗弄里传来。不止一个人，足有几十个人。他们没有打伞，也没有说话，就这么排着队，迈着僵硬缓慢的步子，一点点踩着天井里的积水，围拢到了石缸四周。

借着偏厅窗格透出去的微弱灯光，我看见刷着桐油的窗户纸上，映出了一排排密密麻麻的黑影。

他们就站在外头的暴雨里，肩膀挨着肩膀，雨水顺着他们的发梢和衣角往下淌，汇成水流灌进石缸。一股浓重的、混杂着河泥腥气与陈年湿桑皮纸的味道，顺着门缝丝丝缕缕地钻进偏厅。

木门外，有人轻轻抬起手，指甲刮擦着门板，发出“刺啦”一声轻响。

随后，三叔公那沙哑漏风的声音，隔着一层薄薄的木板传了进来：

“阿明啊，外头雨大，叔公身上的纸快泡透了……”

“阿明，我左边第三根竹篾断了，你拿篾刀帮姑婆削一根新的换上吧……”

“阿明，油灯的火苗小了，屋里太潮，你快拿樟木油给我们擦一擦……”

门外的声音此起彼伏，有男有女，全都是我叫得出名字的长辈。他们没有推门，只是将身体轻轻靠在木门和窗棂上，木头发出不堪重负的“吱呀”声，整间偏厅阴冷幽闭，彻底断了生路。

我想要站起身往后退，可双腿沉重僵麻，根本迈不开步。与此同时，眼眶里的酸胀感骤然加剧，两行滚烫的泪水不受控制地涌了出来。

我抬手去擦眼泪，等再睁开眼时，屋里的一切都变了样。

原本还能看清轮廓的樟木箱子、长条案、发黑的霉墙，此刻全都化成了一片灰蒙蒙的白雾。那碗石斛草决明汤的药力彻底发作了——它根本不是什么降火的凉茶，正是当年让太奶奶瞎掉双眼的药方。

只有瞎了眼，看不见纸人脸上那片惨白的空洞，才能把它们当成活生生的人。

在近乎全盲的灰白视野里，煤油灯那团橘黄色的火苗成了唯一清晰的光点。更诡异的是，当我彻底看不清细节之后，长条案上那上百个一尺来高的纸人，在我模糊的余光里，竟然真的变成了一个个端坐在堂屋里的族人，正安静地垂着手，等我过去伺候。

桌上的煤油灯“啪”地又爆开一朵灯花，火苗矮下去半截。

门外，布鞋踩水的声音停了。几十道粗重而潮湿的呼吸声贴在门缝上，静静地等着屋里的动静。

我坐在竹椅上，剧烈的心跳持续了许久，最终一点点平息下来。

借着眼前最后那点将熄的黄光，我伸出右手，顺着粗糙的八仙桌面慢慢摸索过去。指尖先是碰到了冰凉的瓷碟，接着，摸到了那块浸满了樟木油的粗布，以及那把被太奶奶摩挲得温润光滑的竹篾刀。

我将竹篾刀握进掌心，尺寸刚好贴合我的虎口。

“知道了，”我朝着虚掩的木门方向应了一声，声音在潮湿的偏厅里显得有些发闷，“三叔公，你们在廊下稍微站一站。我先把灯芯挑亮，再给你们挨个儿擦骨头。”
