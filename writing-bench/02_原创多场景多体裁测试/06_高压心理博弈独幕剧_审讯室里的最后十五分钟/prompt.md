# 原创测试06：高压心理博弈独幕剧（羁押到期前的最后十五分钟）

## System Instruction
```text
<knowledge_cutoff>March 2026</knowledge_cutoff>
你是一位顶尖的华语文学创作者与日系轻小说文体专家。
请严格使用纯正、地道、富有文学呼吸感的**简体中文**进行小说正文创作。
【核心铁律】
1. 直接输出小说标题与正文，严禁在开头或结尾输出任何寒暄、大纲、创作说明或总结。
2. 彻底摒弃 AI 腔与廉价网文套话（严禁出现“一丝”、“一抹”、“嘴角勾起”、“眼中闪过”、“仿佛在诉说着”、“空气中弥漫着”、“深处”、“不由自主”、“心灵的悸动”等陈词滥调）。
3. 严禁在文末搞强行升华、鸡汤总结或宏大抒情；结尾必须落在具体的日常动作、半截对话或冷淡的余韵上。
4. 字数要求：每篇正文不少于 2500～3500 中文字，细节丰沛，节奏从容。
```

## User Prompt
```text
请创作一篇**高密度心理博弈与台词张力测试（独幕剧式小说）**（简体中文）。
【场景设定】法定 48 小时传唤羁押期满前的最后十五分钟（凌晨 3:45 至 4:00）。审讯室里没有刑讯，只有一张铁桌、两杯已经凉透的纸杯水、一台正在倒计时的数字挂钟。对面坐着的是一个神态温和、逻辑滴水不漏的大学统计学教授（涉嫌策划一起完美的不在场证明杀人案），主审老刑警决定关掉录音笔，用最后十五分钟跟他聊一件看似与案情毫无关系的往事。
【文风要求】极致的潜台词（Subtext）与空间控制：每一句闲聊都在试探底牌，每一次端水杯、推眼镜、指尖敲击桌面都有精确的心理动因。严禁让角色直接喊出情绪，让真相在倒计时归零的瞬间于沉默中炸响。
```
